## 为什么不入库

GitHub 单文件硬限制 100MB，`常泰长江大桥.p3d`（244.9MB）远超此限。处理方式（2026-09-23 执行）：

1. `.gitignore` 增加 `*.p3d` 规则（已跟踪的 `雪峰湖大桥.p3d` 不受影响，继续跟踪）；
2. 用 `git filter-repo` 将 `P3D文件/常泰长江大桥.p3d` 从全部历史移除；
3. 本地文件保留不动——`.p3d` 是二进制工程文件，丢失即无法重建，**请勿删除本目录文件**。

## 使用方式

BIMBase 中「打开工程」选择对应 `.p3d` 即可；工程引用的参数化组件来自本仓库各组件库目录，改动组件代码后需重启 BIMBase 再打开工程。

## 注意事项

- 新增 `.p3d` 默认被 gitignore 忽略；若确需共享小型工程文件（远小于 100MB），用 `git add -f` 强制添加；
- 大工程文件建议通过网盘等渠道另行分发，并在本 README 补充说明。
