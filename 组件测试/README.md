# 组件测试 —— 参数化几何组件试验场

基于 pyp3d 的参数化几何组件试验场：**4 个基础几何体 + 5 个按真实工程图纸（PDF/DWG）参数化的桥梁构件**，另含 4 个用 ezdxf 生成三视图 DXF 图纸的独立脚本。

用途：

1. 验证 BIMBase Python SDK 环境是否正常；
2. 作为 CADBoard 画板图纸识别、AI 智能建模的目标组件与测试用例；
3. 为桥隧病害识别的「面投影」提供真实构件（引桥桥墩/门式桥墩/承台及桩基）。

## 关键技术栈

- **BIMBase Plugin SDK 1.6.2** + **pyp3d**（唯一几何库）：`Component/Attr/@export/place/TwoPointPlace/Cube/Cone/Section/Sweep/Loft/Combine/translate/scale/rotate/mirror_yoz`
- **ezdxf**：DXF 三视图图纸生成（`ezdxf.new("R2010")`，单位 cm），独立桌面脚本，不依赖 pyp3d
- **Pillow**：面板图标生成（`Picture/_generate_icons.py`）
- **几何参考源**：`数据参考源/` 下的 PDF 与 DWG 图纸
- **单位约定**：基础几何体与工字钢组合梁用 **mm**；门式桥墩/承台及桩基/索塔锚块/引桥桥墩及全部图纸脚本用 **cm**（各文件 docstring 有注明）

## 核心机制（技术说明）

### 1. 统一组件模式

所有组件遵循同一套写法（以 `正方体.py:11-23` 为最小样板）：

```python
class 某组件(Component):
    def __init__(self):
        self['边长'] = Attr(100, obvious=True)   # 参数：属性面板可见可改
        self['实体'] = Attr(None, show=True)      # 几何输出
    @export
    def replace(self):
        self['实体'] = scale(...) * Cube()         # 按参数重建几何
```

属性面板改参数 → 自动触发 `replace()` → 模型实时重生成。

> 通俗说：组件就是一张「参数表 + 一段按参数画图的函数」，BIMBase 负责在你改参数时自动重画。

### 2. 关键几何技巧与坑（用教训换来的）

- **圆柱没有 `Cylinder`**：用 `Cone(p1, p2, r, r)`（上下等径圆锥）代替；`圆柱.py` 另有 32 边形逼近圆截面 `Section + Sweep` 的写法；
- **多几何体并集用 `Combine()` 而不是 `+`**（历史 bug：`+` 导致点击按钮无反应）；
- **布尔减不稳定要兜底**：门式桥墩空心柱 `outer - core` 包 try/except，布尔失败退化为实心柱（`门式桥墩.py:96-101`）；索孔等细节直接用红色小圆柱实体表示，不做布尔；
- **颜色存字符串**：`self['颜色'] = Attr("200,200,200,255")`，replace 末尾解析后 `geom.color(*vals)`——pyp3d Attr 只能存标量/字符串；
- **变截面空心八边形柱**：倒角八边形截面 + 底/顶截面 `Loft` 放样，系梁长度按所在高度柱身宽度线性插值自适应（`门式桥墩.py`）；
- **复杂盖梁**：外轮廓减内轮廓的截面 `Sweep` 出带斜边/凸起的盖梁（`引桥桥墩.py`）。

### 3. DXF 三视图图纸生成

`生成*图纸.py` 系列脚本把参数化构件「画回」工程图纸：手工投影——正视图 x-z / 侧视图 y-z / 俯视图 x-y 三个 origin 布局；4 个图层（轮廓/中心线/标注/文字）；`add_linear_dim` 标注用 `dimscale=25.0` 放大默认样式保证 1:1 大图幅可读。

> 通俗说：组件脚本负责「图纸 → 模型」，图纸脚本负责「参数 → 图纸」，两边参数靠注释约定手工保持一致。

## 使用说明

- **放置组件**：BIMBase 功能区「组件测试/基本图元」点按钮（正方体/圆柱/门式桥墩…）→ 视图中点击放置 → 属性面板改参数实时重生成；
- **生成 DXF 图纸**：本机 Python（已装 ezdxf）直接运行，如 `python 组件测试/生成门式桥墩图纸.py` → 同目录输出 `门式桥墩.dxf`（三视图 + 标注 + 图例，cm，1:1）；改参数需手工同步脚本顶部常量与组件 .py；
- **验证环境**：BIMBase Python 控制台执行
  `exec(open(r"...\组件测试\_test_components.py", encoding="utf-8").read())`，逐项看 `[OK]`/`[ERR]`。

## 报错与调试

- **排查顺序**（组件无反应时）：查 BIMBase 命令行输出 → 用 `正方体.py` 验证环境 → 跑 `_test_components.py` 定位 → **删 `__pycache__` 防旧代码缓存** → 检查参数是否为正数；
- **历史修复记录**（`docs/测试文档.md`）：Cylinder→Cone 与 `+`→Combine 修复放置无反应；2026-06-22 按 `6.22--A1.dwg` 精确重建引桥桥墩全部关键尺寸；
- **ezdxf 缺失**：`pip install ezdxf PyMuPDF`；
- **文档/代码漂移注意**：`索缆锚锭.py` 实际实现的是「索塔锚块」（锚块异形 Sweep + 承台 + 7 对 14 根底柱），与 `docs/功能说明.md` 中旧的"梯形锚碇+索孔"描述不符；`索缆锚锭.dxf`、`引桥桥墩.dxf` 产物未生成（脚本未跑）。
