# 组件测试 - 基础几何体与组合结构测试

本模块包含一系列基础参数化几何体和简单组合结构，用于：

1. 验证 BIMBase Python SDK 环境是否正常。
2. 作为 CADBoard 和 AI 智能建模的组件创建测试用例。
3. 后续桥梁病害识别模块也会引用这些基础组件。
4. 存放基于工程图纸参数化的测试组件（如索缆锚锭、引桥桥墩）。

## 测试组件

| 组件 | 文件 | 说明 |
|---|---|---|
| 正方体 | `正方体.py` | 边长参数化的立方体 |
| 长方体 | `长方体.py` | 长/宽/高参数化的长方体 |
| 圆柱 | `圆柱.py` | 半径/高度参数化的圆柱 |
| 直角三棱柱 | `直角三棱柱.py` | 直角三角形截面拉伸 |
| 工字钢混凝土组合梁 | `工字钢混凝土组合梁.py` | 较复杂的钢-混组合梁 |
| 索缆锚锭 | `索缆锚锭.py` | 基于 PDF 图纸参数化的索缆锚锭 |
| 引桥桥墩 | `引桥桥墩.py` | 基于 PDF 图纸参数化的引桥桥墩 |
| 门式桥墩 | `门式桥墩.py` | 基于 DWG 图纸参数化的门式桥墩（空心八边形变截面双柱） |
| 承台及桩基 | `承台及桩基.py` | 基于 DWG 图纸参数化的承台 + 桩阵列 |

> 注意：`model.py` 与 `直角三棱柱.py` 内容相同，`model.py` 可作为模板或备用。
