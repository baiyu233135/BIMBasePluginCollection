# 桥梁病害识别 — 投影测试组件

本组 4 个简化参数化组件位于 `组件测试/` 目录下，专门用于测试“桥梁病害识别”模块中的病害投影效果。它们已注册到 `组件测试.pyplugin` 的“桥隧投影测试”面板，可直接在 BIMBase 中点击按钮运行。

## 组件清单

| 文件 | 组件类 | 用途 | 对应病害照片 |
|---|---|---|---|
| `投影测试T梁.py` | `投影测试T梁` | 模拟 T 梁底板、腹板、翼缘，用于测试梁底剥落、翼缘掉角等投影 | `数据参考源/桥隧数据源/T梁照片/` |
| `投影测试横隔板.py` | `投影测试横隔板` | 模拟横隔板大桩号面/小桩号面，用于测试横隔板裂缝、剥落投影 | `桥隧病害识别/datasets/bridge_disease/by_component/横隔板/` |
| `投影测试湿接缝.py` | `投影测试湿接缝` | 模拟湿接缝顶面/侧面，用于测试湿接缝裂缝、渗水投影 | `桥隧病害识别/datasets/bridge_disease/by_component/湿接缝/` |
| `投影测试墩柱.py` | `投影测试墩柱` | 模拟桥墩柱身，支持圆柱/方柱切换，用于测试墩柱裂缝、剥落投影 | `桥隧病害识别/datasets/bridge_disease/by_component/墩柱/` |

## 使用方式

1. 在 BIMBase 中直接运行任意 `.py` 文件，例如：

   ```python
   exec(open('组件测试/投影测试T梁.py', encoding='utf-8').read())
   ```

2. 在 CADBoard 的“桥梁病害识别”对话框中导入对应病害照片并识别。

3. 在 BIMBase 中选中已放置的投影测试组件，点击“投影到BIMBase”。

4. 观察病害阴影/纹理/点云是否正确落在组件对应面上。

## 参数说明

### 投影测试T梁
- `梁长`：T 梁纵向长度（cm）
- `底板宽`、`底板高`：梁底板截面尺寸
- `腹板宽`：腹板厚度
- `翼缘宽`、`翼缘高`：顶翼缘截面尺寸
- `总高`：T 梁总高度

### 投影测试横隔板
- `宽度`、`高度`、`厚度`：横隔板外形尺寸
- `预留孔宽`、`预留孔高`：翼缘板穿过的预留孔尺寸

### 投影测试湿接缝
- `长度`、`顶宽`、`底宽`、`高度`：湿接缝梯形截面尺寸

### 投影测试墩柱
- `柱径`、`柱高`：柱身直径/边长与高度
- `截面形式`：0=圆柱，1=方柱

## 与 face_projection.py 的关系

`face_projection.py` 已新增对以上 4 个组件的支持：

- `投影测试T梁`：bottom（梁底）、web_side（腹板侧面）、flange_bottom（翼缘底面）
- `投影测试横隔板`：front（大桩号面）、side（侧面）
- `投影测试湿接缝`：top（顶面）、side（侧面）
- `投影测试墩柱`：front（正面）、side（侧面展开）

如需新增投影面，在 `face_projection.py` 中按 `_get_{组件名}_{面名}_face` 约定添加方法即可。
