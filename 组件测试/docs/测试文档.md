# 组件测试 - 测试文档

## 测试环境

- BIMBase V1.6.x
- Python 3.7 / 3.x
- pyp3d 可用

## 基础几何测试

### 测试 1：正方体

1. 在 BIMBase 中点击"正方体"按钮。
2. 设置边长参数，例如 `20`。
3. 预期结果：在场景中生成一个边长为 20 的立方体。

### 测试 2：长方体

1. 点击"长方体"按钮。
2. 设置长、宽、高，例如 `30, 20, 10`。
3. 预期结果：生成对应尺寸的长方体。

### 测试 3：圆柱

1. 点击"圆柱"按钮。
2. 设置半径 `5`、高度 `20`。
3. 预期结果：生成一个圆柱。

### 测试 4：直角三棱柱

1. 点击"直角三棱柱"按钮。
2. 设置两条直角边和高度。
3. 预期结果：生成直角三棱柱。

## 新增组件测试

### 测试 5：索缆锚锭

1. 点击"索缆锚锭"按钮。
2. 使用默认参数生成模型。
3. 预期结果：
   - 生成上窄下宽的梯形锚碇主体。
   - 底部有承台。
   - 锚碇上有红色小圆柱表示的索孔。
4. 在属性面板中修改"锚碇高度"、"锚碇底宽"等参数。
5. 预期结果：模型尺寸实时更新。

### 测试 6：引桥桥墩

1. 点击"引桥桥墩"按钮。
2. 使用默认参数生成模型。
3. 预期结果：
   - 顶部有盖梁。
   - 两根墩柱向下延伸。
   - 中间有系梁连接。
   - 底部有桩基。
4. 在属性面板中修改"墩高"、"盖梁长"、"墩柱间距"等参数。
5. 预期结果：模型尺寸实时更新。

## 参数修改测试

1. 创建一个正方体。
2. 在 BIMBase 中选中该正方体。
3. 在属性面板中修改边长。
4. 预期结果：正方体尺寸实时更新。

## 失败排查

如果某个组件无法创建：

1. 检查 BIMBase 命令行输出。
2. 确认 `pyp3d` 已正确导入。
3. 使用最简单的 `正方体.py` 验证环境。
4. 查看是否有 `__pycache__` 缓存导致旧代码运行，可删除后重试。
5. 对于新增组件，检查参数是否合理（如直径、高度是否为正数）。
