# 组件测试 - 测试文档

## 测试环境

- BIMBase V1.6.x
- Python 3.7 / 3.x
- pyp3d 可用

## 基础几何测试

### 测试 1：正方体

1. 在 BIMBase 中点击"正方体"按钮。
2. 设置边长参数，例如 `20`。
3. 预期结果：在场景中生成一个边长为 20 的立方体。

### 测试 2：长方体

1. 点击"长方体"按钮。
2. 设置长、宽、高，例如 `30, 20, 10`。
3. 预期结果：生成对应尺寸的长方体。

### 测试 3：圆柱

1. 点击"圆柱"按钮。
2. 设置半径 `5`、高度 `20`。
3. 预期结果：生成一个圆柱。

### 测试 4：直角三棱柱

1. 点击"直角三棱柱"按钮。
2. 设置两条直角边和高度。
3. 预期结果：生成直角三棱柱。

## 修复记录

### 2026-06-20：修复索缆锚锭、引桥桥墩无法点击放置的问题

**现象**：点击"索缆锚锭"或"引桥桥墩"图标后完全无反应，参数面板不弹出。

**原因**：
1. 代码中使用了 `Cylinder(radius, height)` 创建圆柱，但 pyp3d 中创建圆柱/圆桩的正确 API 是 `Cone(p1, p2, r1, r2)`（令 `r1 == r2` 即可）。
2. 多个几何体的并集使用 `+` 操作符，参考桥梁组件库统一改为 `Combine(...)`。
3. 索缆锚锭中承台位置计算不当，导致几何体中心错位。

**修复内容**：
1. 将两个组件中所有 `Cylinder` 替换为 `Cone(Vec3(...), Vec3(...), r, r)`。
2. 统一使用 `Combine(...)` 组合多个几何体。
3. 重新对照 PDF 图纸调整索缆锚锭的默认参数和几何方向：
   - 锚碇主体改为 XZ 平面梯形截面、沿 Y 轴拉伸。
   - 增加"锚碇厚度"参数。
   - 承台使用 `translate(-L/2, -W/2, -H) * scale(L, W, H) * Cube()` 定位，确保顶面与锚碇底面齐平。
4. 新增 `_test_components.py` 测试脚本，便于在 BIMBase 内快速验证组件可用性。

### 2026-06-22：根据 DWG 文件精确重建引桥桥墩

**依据**：`数据参考源/6.22--A1.dwg`

**提取的关键尺寸**：
- 盖梁总长 1950（含两端 30 宽凸起）
- 盖梁总高 300（主体 250 + 凸起 50）
- 盖梁主体顶宽 1890、底宽 1410
- 两侧斜边水平投影 270、垂直投影 120
- 墩柱直径 270、中心间距 1140
- 墩高 1200、桩长 900
- 盖梁宽度（Y 方向）300
- 系梁 200×200，共 2 根，第一根距盖梁底 200，间距 500

**调整内容**：
1. 盖梁截面改为 10 点多边形，精确包含底部斜边、主体、顶部凸起。
2. 增加 `盖梁主体顶宽`、`盖梁主体底宽`、`凸起宽`、`凸起高` 等参数。
3. 系梁位置改为由 `系梁起始距顶` 和 `系梁间距` 控制。
4. 默认墩高、桩长、墩柱间距等按 DWG 实际几何设置。

## 失败排查

如果某个组件无法创建：

1. 检查 BIMBase 命令行输出。
2. 确认 `pyp3d` 已正确导入。
3. 使用最简单的 `正方体.py` 验证环境。
4. 运行 `_test_components.py` 查看具体失败步骤。
5. 查看是否有 `__pycache__` 缓存导致旧代码运行，可删除后重试。
6. 对于新增组件，检查参数是否合理（如直径、高度是否为正数）。
