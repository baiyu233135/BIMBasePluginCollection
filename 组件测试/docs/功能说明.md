# 组件测试 - 功能说明

## 功能概述

组件测试模块包含一系列基础参数化几何体和简单组合结构，用于验证 BIMBase Python SDK 环境、测试 CADBoard 组件创建流程，以及为 AI 智能建模提供基础测试用例。

## 测试组件

### 基础几何体

| 组件 | 核心几何逻辑 | 用途 |
|---|---|---|
| 正方体 | `scale(a,a,a) * Cube()` | 验证基础缩放和立方体创建 |
| 长方体 | `scale(L,W,H) * Cube()` | 验证不等比例缩放 |
| 圆柱 | 32 边形 `Section` + `Sweep` | 验证旋转体创建 |
| 直角三棱柱 | 直角三角形 `Section` + `Sweep` | 验证自定义截面拉伸 |

### 组合结构

| 组件 | 说明 |
|---|---|
| 工字钢混凝土组合梁 | 主纵梁、横梁、小纵梁、混凝土板分别用 `Cube`/`Sweep`/`Combine` 拼装 |
| 索缆锚锭 | 基于工程图纸参数化的索缆锚锭：梯形锚碇 + 承台 + 索孔 |
| 引桥桥墩 | 基于工程图纸参数化的引桥桥墩：盖梁 + 双墩柱 + 系梁 + 双桩基 |
| 门式桥墩 | 基于工程图纸参数化的门式桥墩：盖梁 + 垫石 + 双变截面空心八边形墩柱 + 系梁 |
| 承台及桩基 | 基于工程图纸参数化的承台及桩基：矩形承台 + 列×排桩阵列 |

### 桥隧病害投影测试组件

| 组件 | 说明 |
|---|---|
| 投影测试T梁 | 简化 T 梁（底板 + 腹板 + 翼缘），用于测试梁底剥落、翼缘掉角等病害投影 |
| 投影测试横隔板 | 简化横隔板竖直板，用于测试横隔板裂缝、剥落投影 |
| 投影测试湿接缝 | 简化湿接缝长条块，用于测试湿接缝裂缝、渗水投影 |
| 投影测试墩柱 | 简化墩柱（圆柱/方柱可切换），用于测试墩柱裂缝、剥落投影 |

> 以上 4 个组件同时被 `桥隧病害识别/face_projection.py` 支持，可在 BIMBase 中选中后点击“投影到BIMBase”验证效果。

## 新增组件详细说明

### 索缆锚锭

参考 `数据参考源/索缆锚锭，引桥桥墩.pdf` 第 1 页"索缆锚锭构造图"。

可调参数：

| 参数名 | 默认值 | 说明 |
|---|---|---|
| 锚碇高度 | 2000 mm | 锚碇主体总高度 |
| 锚碇底宽 | 2200 mm | 锚碇底部宽度 |
| 锚碇顶宽 | 1000 mm | 锚碇顶部宽度 |
| 承台宽 | 1600 mm | 承台宽度 |
| 承台高 | 850 mm | 承台高度 |
| 索孔排数 | 2 | 索孔沿高度方向排数 |
| 每排索孔数 | 4 | 每排索孔数量 |
| 索孔直径 | 200 mm | 索孔直径 |
| 索孔间距 | 200 mm | 索孔中心间距 |

几何生成：

1. 用梯形 `Section` 沿 Z 轴 `Sweep` 生成锚碇主体。
2. 底部放置立方体承台。
3. 用红色小圆柱表示索孔（不做布尔减，避免 pyp3d 布尔运算不稳定）。

### 引桥桥墩

参考 `数据参考源/索缆锚锭，引桥桥墩.pdf` 第 2 页"引桥桥墩构造图"。

可调参数：

| 参数名 | 默认值 | 说明 |
|---|---|---|
| 盖梁长 | 1890 mm | 盖梁长度 |
| 盖梁宽 | 300 mm | 盖梁宽度 |
| 盖梁高 | 250 mm | 盖梁高度 |
| 墩柱直径 | 250 mm | 墩柱直径 |
| 墩高 | 2000 mm | 墩柱高度 |
| 墩柱间距 | 1140 mm | 两墩柱中心间距 |
| 桩基直径 | 200 mm | 桩基直径 |
| 桩长 | 1500 mm | 桩基长度 |
| 系梁宽 | 200 mm | 系梁宽度 |
| 系梁高 | 200 mm | 系梁高度 |

几何生成：

1. 顶部放置盖梁立方体。
2. 两根圆柱作为墩柱。
3. 两根圆柱作为桩基。
4. 中间用立方体连接两根墩柱作为系梁。

### 门式桥墩

参考 `数据参考源/门式桥墩/门式桥墩.dwg`（DQ01 示意图）。

可调参数（单位 cm）：

| 参数名 | 默认值 | 说明 |
|---|---|---|
| 盖梁总长 | 4700 | 盖梁长度（X 向） |
| 盖梁总高 | 400 | 盖梁高度 |
| 盖梁宽 | 1000 | 盖梁宽度（Y 向） |
| 墩高 | 5000 | 墩柱高度 |
| 墩柱间距 | 3500 | 两墩柱中心间距 |
| 柱顶宽 | 1200 | 柱顶 X 向宽度 |
| 柱底宽 | 1400 | 柱底 X 向宽度 |
| 柱顶厚 | 1000 | 柱顶 Y 向厚度 |
| 柱底厚 | 1200 | 柱底 Y 向厚度 |
| 系梁根数 | 1 | 系梁数量（贴盖梁底向下均布） |

几何生成：

1. 盖梁用 `scale * Cube`，置于柱顶（z = 墩高 ~ 墩高+盖梁总高）。
2. 垫石两块（400×400×80，固定细部）置于两柱顶中心的盖梁顶面。
3. 墩柱为变截面空心八边形：底/顶倒角八边形截面 `Loft` 放样，减矩形内腔（壁厚 300 固定，布尔失败时退化实心）。
4. 系梁贴盖梁底，长度随柱身锥度自适应。

### 承台及桩基

参考 `数据参考源/承台及桩基/承台及桩基.dwg`。

可调参数（单位 cm）：

| 参数名 | 默认值 | 说明 |
|---|---|---|
| 承台长 | 5500 | 承台长度（X 向） |
| 承台宽 | 2350 | 承台宽度（Y 向） |
| 承台高 | 500 | 承台高度 |
| 桩径 | 250 | 桩直径 |
| 桩长 | 5000 | 桩长度（承台底向下延伸） |
| 桩间距 | 630 | 桩中心间距 |
| 桩列数 | 9 | X 向桩数 |
| 桩排数 | 4 | Y 向桩数 |

几何生成：

1. 承台用 `scale * Cube`，底面中心在原点（z 0 ~ 承台高）。
2. 桩阵列为 `Cone` 圆柱，按 列数×排数×桩间距 网格布置，桩顶伸入承台底（z -桩长 ~ 0）。

## 组件模式

所有测试组件遵循相同的参数化模式：

1. 继承 `Component`。
2. 在 `__init__` 中用 `Attr` 定义参数。
3. 在 `replace()` 中读取参数并生成几何体。
4. 调用 `place()` 放置到场景。

## 入口

由根目录 `组件测试.pyplugin` 注册。

## 与画板识别的关系

这两个新增组件将作为 CADBoard 画板图纸识别功能的**目标组件**。未来画板识别出"索缆锚锭"或"引桥桥墩"后，可以直接调用对应组件生成参数化模型。
