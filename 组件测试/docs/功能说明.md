# 组件测试 - 功能说明

## 功能概述

组件测试模块包含一系列基础参数化几何体和简单组合结构，用于验证 BIMBase Python SDK 环境、测试 CADBoard 的组件创建流程，以及为 AI 智能建模提供基础测试用例。

## 测试组件

| 组件 | 文件 | 几何逻辑 | 用途 |
|---|---|---|---|
| 正方体 | `正方体.py` | `scale(a,a,a) * Cube()` | 验证基础缩放和立方体创建 |
| 长方体 | `长方体.py` | `scale(L,W,H) * Cube()` | 验证不等比例缩放 |
| 圆柱 | `圆柱.py` | 32 边形 `Section` + `Sweep` | 验证旋转体创建 |
| 直角三棱柱 | `直角三棱柱.py` | 直角三角形 `Section` + `Sweep` | 验证自定义截面拉伸 |
| 工字钢混凝土组合梁 | `工字钢混凝土组合梁.py` | 多部分 `Cube`/`Sweep` 组合 | 验证复杂组合结构 |

## 组件模式

所有测试组件遵循相同的参数化模式：

1. 继承 `Component`。
2. 在 `__init__` 中用 `Attr` 定义参数。
3. 在 `replace()` 中读取参数并生成几何体。
4. 调用 `place()` 放置到场景。

## 入口

由根目录 `组件测试.pyplugin` 注册：

- **正方体** → `正方体.py`
- **长方体** → `长方体.py`
- **圆柱** → `圆柱.py`
- **直角三棱柱** → `直角三棱柱.py`

## 使用场景

### 1. 环境验证

当不确定 BIMBase Python 环境是否正常时，先运行 `正方体.py`。如果能成功创建正方体，说明环境基本正常。

### 2. CADBoard 组件适配

CADBoard 在创建复杂结构前，可先用这些基础组件验证组件工厂和放置逻辑。

### 3. AI 智能建模基础用例

AI 智能建模解析到“创建圆柱”“创建长方体”等指令时，可调用对应组件。

## 注意事项

- `model.py` 与 `直角三棱柱.py` 内容相同，可作为模板参考。
- 所有组件参数均可通过 BIMBase 属性面板修改。
