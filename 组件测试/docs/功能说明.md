# 组件测试 - 功能说明

## 功能概述

组件测试模块包含一系列基础参数化几何体和简单组合结构，用于验证 BIMBase Python SDK 环境、测试 CADBoard 组件创建流程，以及为 AI 智能建模提供基础测试用例。

## 测试组件

### 基础几何体

| 组件 | 核心几何逻辑 | 用途 |
|---|---|---|
| 正方体 | `scale(a,a,a) * Cube()` | 验证基础缩放和立方体创建 |
| 长方体 | `scale(L,W,H) * Cube()` | 验证不等比例缩放 |
| 圆柱 | 32 边形 `Section` + `Sweep` | 验证旋转体创建 |
| 直角三棱柱 | 直角三角形 `Section` + `Sweep` | 验证自定义截面拉伸 |

### 组合结构

| 组件 | 说明 |
|---|---|
| 工字钢混凝土组合梁 | 主纵梁、横梁、小纵梁、混凝土板分别用 `Cube`/`Sweep`/`Combine` 拼装 |
| 索缆锚锭 | 基于工程图纸参数化的索缆锚锭：梯形锚碇 + 承台 + 索孔 |
| 引桥桥墩 | 基于工程图纸参数化的引桥桥墩：盖梁 + 双墩柱 + 系梁 + 双桩基 |

## 新增组件详细说明

### 索缆锚锭

参考 `数据参考源/索缆锚锭，引桥桥墩.pdf` 第 1 页"索缆锚锭构造图"。

可调参数：

| 参数名 | 默认值 | 说明 |
|---|---|---|
| 锚碇高度 | 2000 mm | 锚碇主体总高度 |
| 锚碇底宽 | 2200 mm | 锚碇底部宽度 |
| 锚碇顶宽 | 1000 mm | 锚碇顶部宽度 |
| 承台宽 | 1600 mm | 承台宽度 |
| 承台高 | 850 mm | 承台高度 |
| 索孔排数 | 2 | 索孔沿高度方向排数 |
| 每排索孔数 | 4 | 每排索孔数量 |
| 索孔直径 | 200 mm | 索孔直径 |
| 索孔间距 | 200 mm | 索孔中心间距 |

几何生成：

1. 用梯形 `Section` 沿 Z 轴 `Sweep` 生成锚碇主体。
2. 底部放置立方体承台。
3. 用红色小圆柱表示索孔（不做布尔减，避免 pyp3d 布尔运算不稳定）。

### 引桥桥墩

参考 `数据参考源/索缆锚锭，引桥桥墩.pdf` 第 2 页"引桥桥墩构造图"。

可调参数：

| 参数名 | 默认值 | 说明 |
|---|---|---|
| 盖梁长 | 1890 mm | 盖梁长度 |
| 盖梁宽 | 300 mm | 盖梁宽度 |
| 盖梁高 | 250 mm | 盖梁高度 |
| 墩柱直径 | 250 mm | 墩柱直径 |
| 墩高 | 2000 mm | 墩柱高度 |
| 墩柱间距 | 1140 mm | 两墩柱中心间距 |
| 桩基直径 | 200 mm | 桩基直径 |
| 桩长 | 1500 mm | 桩基长度 |
| 系梁宽 | 200 mm | 系梁宽度 |
| 系梁高 | 200 mm | 系梁高度 |

几何生成：

1. 顶部放置盖梁立方体。
2. 两根圆柱作为墩柱。
3. 两根圆柱作为桩基。
4. 中间用立方体连接两根墩柱作为系梁。

## 组件模式

所有测试组件遵循相同的参数化模式：

1. 继承 `Component`。
2. 在 `__init__` 中用 `Attr` 定义参数。
3. 在 `replace()` 中读取参数并生成几何体。
4. 调用 `place()` 放置到场景。

## 入口

由根目录 `组件测试.pyplugin` 注册。

## 与画板识别的关系

这两个新增组件将作为 CADBoard 画板图纸识别功能的**目标组件**。未来画板识别出"索缆锚锭"或"引桥桥墩"后，可以直接调用对应组件生成参数化模型。
