# 桥隧病害识别 - 功能说明

## 功能概述

桥隧病害识别功能基于 **YOLOv8** 目标检测模型，对无人机拍摄的桥梁/隧道照片进行病害检测，自动生成 Word 诊断报告，并可将病害位置投影到 BIMBase 模型中。

## 支持识别的病害类型

| 类型 | 说明 |
|---|---|
| 裂缝 | 混凝土表面裂缝 |
| 剥落 | 保护层剥落 |
| 露筋 | 钢筋外露 |
| 蜂窝麻面 | 混凝土表面蜂窝状缺陷 |
| 渗水 | 结构渗水痕迹 |
| 锈蚀 | 钢筋或钢结构锈蚀 |

## 主要文件

| 文件 | 功能 |
|---|---|
| `bridge_disease_launcher.py` | 入口脚本，创建 Qt App 并打开对话框 |
| `disease_dialog.py` | 病害识别主对话框 `DiseaseDialog` |
| `disease_detector.py` | YOLOv8n 病害检测封装 |
| `disease_marker.py` | 病害标记组件管理 |
| `cv_crack_detector.py` | 传统 CV 裂缝检测（备用） |
| `component_classifier.py` | 构件图像分类器 |
| `face_projection.py` | 面投影引擎 |
| `report_generator.py` | Word 诊断报告生成 |
| `bimbase_query.py` | 查询 BIMBase 当前选中组件 |
| `scan_debug.py` | 扫描调试 |
| `test_projection.py` | 投影测试 |

## 训练相关

| 文件 | 功能 |

## 使用流程

1. 在 CADBoard 面板中点击"桥隧病害识别"按钮。
2. 选择或导入无人机照片。
3. 选择模型权重（默认 `models/yolov8n.pt`）。
4. 点击"开始检测"，等待 YOLO 推理完成。
5. 查看检测结果，确认病害位置和类型。
6. 点击"生成报告"，导出 Word 诊断报告。
7. （可选）在 BIMBase 中选中对应构件，将病害投影到模型表面。

## 入口说明

本模块不单独注册 `.pyplugin`，入口由 CADBoard 转发：

```text
CADBoard/bridge_disease_launcher.py（转发脚本）
    → 桥隧病害识别/bridge_disease_launcher.py
    → disease_dialog.py
```

## 与 CADBoard 的边界

- 本模块代码独立存放在 `桥隧病害识别/` 目录。
- `bimbase_sync.py` 仍由 CADBoard 提供，本模块通过动态路径导入。
- CADBoard 仅保留一个转发入口文件，保持 BIMBase 面板按钮路径不变。
