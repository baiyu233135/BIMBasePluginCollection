# 桥隧病害识别 - 功能说明

## 功能概述

桥隧病害识别功能支持两种工作模式：

1. **深度学习检测**：基于 **YOLOv8** 目标检测模型，对无人机照片进行 6 类病害检测（需专用模型）。
2. **传统 CV 异常区域识别**：基于 **OpenCV** 图像处理算法，自动圈出 T 梁等混凝土构件表面的异常区域（裂缝、渗水、污渍、剥落等），**不区分具体病害类型**，无需训练模型即可使用。

识别结果可自动生成 Word 诊断报告，并支持投影到 BIMBase 模型中。

## 支持识别的病害类型

| 类型 | 说明 |
|---|---|
| 异常区域 | 传统 CV 自动圈出的异常区域，可能包含裂缝、渗水、污渍、剥落等，不分类 |
| 裂缝 | 混凝土表面裂缝 |
| 剥落 | 保护层剥落 |
| 露筋 | 钢筋外露 |
| 蜂窝麻面 | 混凝土表面蜂窝状缺陷 |
| 渗水 | 结构渗水痕迹 |
| 锈蚀 | 钢筋或钢结构锈蚀 |

> 注：当前默认使用"异常区域"模式对 T 梁照片进行快速识别，YOLO 六分类模式需额外训练专用模型。

## 使用流程

### 方式一：T梁异常区域快速识别（推荐，无需模型）

1. 在 CADBoard 面板中点击"桥隧病害识别"按钮。
2. 点击"导入无人机照片"，选择 T 梁照片（如 `数据参考源/桥隧数据源/T梁/00.png`）。
3. 点击"自动识别异常区域"。
4. 等待数秒后，照片上将用红色框圈出异常区域，并自动添加到病害记录列表。
5. 点击"生成诊断报告"，导出 Word 诊断报告。
6. （可选）在 BIMBase 中选中对应构件，将病害投影到模型表面。

### 方式二：YOLO 六分类检测（需专用模型）

1. 在 CADBoard 面板中点击"桥隧病害识别"按钮。
2. 选择或导入无人机照片。
3. 选择模型权重（默认 `models/yolov8n.pt`，需训练专用病害模型）。
4. 点击"开始检测"，等待 YOLO 推理完成。
5. 查看检测结果，确认病害位置和类型。
6. 点击"生成报告"，导出 Word 诊断报告。

- pyp3d
- Pillow

## 入口说明

本模块不单独注册 `.pyplugin`，入口由 CADBoard 转发：

```text
CADBoard/bridge_disease_launcher.py（转发脚本）
    → 桥隧病害识别/bridge_disease_launcher.py
    → disease_dialog.py
```

## 与 CADBoard 的边界

- 本模块代码独立存放在 `桥隧病害识别/` 目录。
- `bimbase_sync.py` 仍由 CADBoard 提供，本模块通过动态路径导入。
- CADBoard 仅保留一个转发入口文件，保持 BIMBase 面板按钮路径不变。
