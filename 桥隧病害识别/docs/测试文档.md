# 桥隧病害识别 - 测试文档

## 测试环境

- BIMBase V1.6.x
- Python 3.7 / 3.x
- PyQt5 已安装
- pyp3d 可用
- ultralytics、opencv-python、python-docx 已安装

## 功能测试

### 1. 入口转发测试

1. 在 BIMBase 中点击 CADBoard 面板的"桥隧病害识别"按钮。
2. 预期结果：弹出"桥隧病害识别 — 手动录入"对话框。

### 2. 病害检测测试

1. 准备一张包含裂缝的桥梁/隧道照片。
2. 在对话框中导入照片。
3. 选择模型权重 `models/yolov8n.pt`。
4. 点击"开始检测"。
5. 预期结果：照片上用框标出病害位置，列表显示病害类型和置信度。

### 3. CV Fallback 测试

1. 临时移除或重命名 `models/yolov8n.pt`。
2. 导入照片并检测。
3. 预期结果：使用 OpenCV 方法检测裂缝（可能效果不如 YOLO）。

### 4. 报告生成测试

1. 完成病害检测或手动添加病害记录。
2. 点击"生成报告"。
3. 预期结果：生成 Word 文档，包含项目概况、病害统计、详细信息。

### 5. BIMBase 投影测试

1. 在 BIMBase 中选中一个桥梁构件。
2. 在对话框中点击"投影到BIMBase"。
3. 预期结果：在构件表面或附近生成红色病害标记。

### 6. 扫描调试

```bash
python 桥隧病害识别/scan_debug.py
```

预期结果：在 BIMBase 命令行中打印当前实例参数，用于排查构件识别问题。

### 7. 投影测试

```bash
python 桥隧病害识别/test_projection.py
```

预期结果：测试 pyp3d 标记组件能否放置到 BIMBase。

## 注意事项

- 测试前确保 API Key 和模型权重已配置。
- 照片清晰度直接影响检测效果。
- 如果 YOLO 推理较慢，可尝试降低图片分辨率。
