# CADBoard 桥隧病害识别功能 — 使用说明

## 功能简介

在BIMBase插件中集成桥隧病害智能识别功能，支持：
- 导入无人机巡检照片，自动识别构件类型和病害
- 将病害信息投影到BIMBase桥梁模型对应构件上（红色标记）
- 生成Word格式诊断报告

---

## 快速开始

### 1. 启动方式

在BIMBase插件面板中，点击 **CADBoard → 桥隧病害识别** 按钮。

### 2. 操作流程

```
导入照片 → 自动识别构件类型 → 自动分配BIM实例 → 病害检测 → 投影标记 → 生成报告
```

#### Step 1: 导入照片
点击"📷 导入无人机照片"，选择单张无人机巡检图片（支持jpg/png/bmp/tiff）。

#### Step 2: 构件类型识别
- 点击"🔍 自动识别构件类型"，系统会尝试识别照片中的桥梁构件类型
- 如果自动识别失败或不准，可手动从下拉框中选择（19种构件）

#### Step 3: BIMBase实例分配
- 系统自动扫描BIMBase中的桥梁构件实例
- 按编号顺序自动分配对应类型的实例（如"箱梁-001"）
- 如果分配不对，点击"⏭ 换一个实例"

#### Step 4: 病害识别
点击"🤖 开始病害识别"，系统自动检测照片中的病害。

支持检测的病害类型：
| 病害类型 | 适用构件 |
|---------|---------|
| 裂缝 | 混凝土构件（梁、墩、台、塔等） |
| 剥落 | 混凝土构件 |
| 露筋 | 混凝土构件 |
| 蜂窝麻面 | 混凝土构件 |
| 渗水 | 混凝土构件 |
| 锈蚀 | 钢结构、护栏 |

#### Step 5: 投影到BIM模型
点击"📍 投影到BIM模型"，系统会在对应构件表面生成红色标记小球。

#### Step 6: 生成诊断报告
点击"📄 生成诊断报告"，输出Word文档，包含病害统计、详图和处理建议。

## 模型训练

### 病害检测模型（YOLOv8n）

**使用公开数据集训练：**

```bash
cd CADBoard/training

# 1. 准备数据集目录结构
python download_datasets.py --output ../datasets

# 2. 将下载的GYU-DET数据集图片放入对应目录：
#    ../datasets/gyu-det/images/train/
#    ../datasets/gyu-det/labels/train/
#    ../datasets/gyu-det/images/val/
#    ../datasets/gyu-det/labels/val/

# 3. 训练模型
python train_disease_yolo.py --data ../datasets/gyu-det/data.yaml --epochs 100 --device cpu

# 4. 训练完成后，将最佳模型复制到模型目录
cp ../models/disease_yolov8n/weights/best.pt ../models/disease_yolov8n.pt
```

**使用自有数据训练：**

1. 收集桥梁病害照片，按YOLO格式标注（每个图片对应一个.txt文件，内容为 `class x_center y_center width height`）
2. 修改 `../datasets/gyu-det/data.yaml` 中的路径和类别
3. 运行训练脚本

### 构件分类模型（EfficientNet-B0）

```bash
cd CADBoard/training

# 1. 准备数据集（按构件类型分文件夹）
#    ../datasets/component_cls/train/
#      T梁/*.jpg
#      箱梁/*.jpg
#      ...
#    ../datasets/component_cls/val/
#      T梁/*.jpg
#      ...

# 2. 训练模型
python train_classifier.py --data ../datasets/component_cls --epochs 50 --device cpu

# 3. 训练完成后，模型自动保存到
#    ../models/component_classifier.pt
```

## 注意事项

1. **首次使用**：如果缺少依赖，请点击BIMBase插件面板中的"自动配置环境"按钮，或手动运行：
   ```bash
   pip install ultralytics torch torchvision --index-url https://download.pytorch.org/whl/cpu
   pip install python-docx
   ```

2. **CPU推理速度**：YOLOv8n在CPU上推理单张图片约2-5秒，请耐心等待。

3. **模型精度**：默认使用COCO预训练权重，病害检测精度有限。建议用桥梁病害数据集训练专用模型以获得更好效果。

4. **构件分类fallback**：如果构件分类模型未训练，UI会自动切换为手动选择模式，不影响其他功能使用。

5. **BIMBase实例**：确保BIMBase项目中已使用"桥梁组件库"放置了构件，否则无法自动分配实例。
