# 常_常泰长江大桥 —— 常泰长江大桥参数化组件库

以**真实工程尺度**建模的常泰长江大桥参数化组件库插件，共 **16 个参数化构件**，按桥梁结构分 **3 大分类**（上部结构 / 下部结构 / 附属设施），另有 1 个独立「其他组件」。

## 主要功能

| 分类 | 目录 | 构件（7 / 3 / 5 个） |
|---|---|---|
| 上部结构 | `常泰长江大桥/1-上部结构/` | 主塔、侧面钢桁架、工字钢梁、支座、斜拉索、自密实混凝土层及隔离层、轨道底座 |
| 下部结构 | `常泰长江大桥/2-下部结构/` | 扩大基础、承台及桩基、门式桥墩 |
| 附属设施 | `常泰长江大桥/3-附属设施/` | 接触网、新泽西护栏、路面及交通标线、轨道、防撞护栏 |
| 其他组件 | `常泰长江大桥/铁路封闭网/` | 铁路封闭网 |

全部构件基于 pyp3d SDK（`Component/Attr/@export/place` 模式）编写，属性面板改参数即实时重生成，可直接拼装成整桥模型。

## 入口与 bfa 打包

由根目录 `常_常泰长江大桥.pyplugin`（v1.3.0，SDK 1.6.2）注册：

- `<BfaLibName>常泰长江大桥</BfaLibName>`：BIMBase 编译时将各分类目录聚合打包为 `.bfa` 组件库（`*.bfa` 已在 .gitignore 忽略，属编译产物）；
- 面板「常泰长江大桥」分 4 组按钮：上部结构 / 下部结构 / 附属结构（按目录整体加载）+ 其他组件·铁路封闭网（按单文件加载）。

## 使用方式

1. 启动 BIMBase，功能区「常泰长江大桥」面板选择分类按钮；
2. 在视图中点击放置构件，属性面板修改参数实时重生成；
3. 配合真实工程文件 `P3D文件/常泰长江大桥.p3d`（因超 GitHub 100MB 限制不入库，仅本地保留）可查看整桥拼装效果。

## 注意事项

- 构件尺寸为真实工程尺度（米/毫米量级混用），放置时注意视图缩放；
- 修改代码后需完全重启 BIMBase（embed 环境缓存模块）；
- 与 `组件测试/` 的同名构件（承台及桩基、门式桥墩）是独立实现，本库面向整桥拼装，组件测试面向图纸验证。
