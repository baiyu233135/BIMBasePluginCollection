# AI建模 - 早期大语言模型建模入口

本目录为早期版本的 AI 建模插件，通过 BIMBase 面板按钮打开外部 AI 对话页面（ChatGLM），用户复制生成的代码后，由脚本在 BIMBase 内置 Python 环境中运行。

## 功能特点

- **简单轻量**：无需本地部署复杂 AI 解析逻辑。
- **网页对话**：点击按钮自动打开浏览器进入 ChatGLM 智能体页面。
- **剪贴板运行**：将 AI 生成的 Python 代码复制到剪贴板，点击“复制代码 然后运行”即可执行。

## 目录结构

```
AI建模/
├── Picture/              # 按钮图标
└── 代码/                 # 插件入口脚本
    ├── 打开AI智能体.py   # 打开 ChatGLM 网页
    ├── 打开AI智能体.bat  # 浏览器启动批处理
    ├── 功能使用介绍.py   # 打开介绍文档
    ├── 代码运行交互.py   # 读取剪贴板代码并运行
    ├── 代码运行交互.bat  # 运行剪贴板代码的批处理
    ├── temp_clipboard_content.py # 临时存放剪贴板代码
    └── 介绍文档.docx     # 使用说明文档
```

## 入口

由根目录 `AI建模.pyplugin` 注册，BIMBase 面板按钮：

- **AI建模 使用说明** → `代码/功能使用介绍.py`
- **登录 大语言模型** → `代码/打开AI智能体.py`
- **AI对话 建模入口** → `代码/打开AI智能体.py`
- **复制代码 然后运行** → `代码/代码运行交互.py`

## 使用步骤

1. 在 BIMBase 中点击“登录 大语言模型”或“AI对话 建模入口”，打开 ChatGLM 网页。
2. 在网页中与大模型对话，获取 Python 建模代码。
3. 复制代码到剪贴板。
4. 回到 BIMBase，点击“复制代码 然后运行”。
5. 脚本会自动将代码写入 `temp_clipboard_content.py` 并调用 BIMBase 内置 Python 执行。

## 与 AI_Modeling 的区别

- `AI建模/` 依赖外部网页和手动复制代码，适合快速体验。
- `AI_Modeling/` 是新版独立实现，集成 DeepSeek 本地解析和自动放置，功能更完整。
