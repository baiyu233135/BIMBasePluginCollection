# AI建模 功能说明

## 功能概述

`AI建模` 是早期版本的 AI 建模入口，通过 BIMBase 面板按钮打开外部 AI 对话页面（ChatGLM），用户复制生成的代码后，由脚本在 BIMBase 内置 Python 环境中运行。

## 核心流程

```
用户点击按钮
  ├── 打开 ChatGLM 网页
  ├── 用户与大模型对话，复制 Python 代码
  └── 点击“复制代码 然后运行”，脚本执行代码
```

## 功能按钮

### 1. AI建模 使用说明

打开同目录下的 `介绍文档.docx`，查看使用说明。

### 2. 登录 大语言模型 / AI对话 建模入口

调用 `代码/打开AI智能体.py`，启动批处理 `打开AI智能体.bat`，打开浏览器访问 ChatGLM 智能体页面。

### 3. 复制代码 然后运行

调用 `代码/代码运行交互.py`，从剪贴板读取 Python 代码，写入 `temp_clipboard_content.py`，再调用 BIMBase 内置 Python 执行。

## 主要文件说明

| 文件 | 功能 |
|---|---|
| `代码/打开AI智能体.py` | 启动浏览器打开 ChatGLM 网页 |
| `代码/打开AI智能体.bat` | 浏览器启动批处理 |
| `代码/功能使用介绍.py` | 打开 Word 说明文档 |
| `代码/代码运行交互.py` | 读取剪贴板代码并运行 |
| `代码/代码运行交互.bat` | 运行剪贴板代码的批处理 |
| `代码/temp_clipboard_content.py` | 临时存放剪贴板代码 |
| `代码/介绍文档.docx` | 使用说明文档 |

## 依赖

- Windows 操作系统
- BIMBase 内置 Python
- 默认浏览器
- ChatGLM 账号

## 限制

- 需要手动复制代码，无法自动解析自然语言。
- AI 生成的代码可能存在兼容性问题，需要人工检查。
- 不依赖本地 AI 模型或 API Key。
