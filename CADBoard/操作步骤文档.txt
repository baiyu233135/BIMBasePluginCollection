CAD画板 v1.3 操作步骤文档
============================

一、基础操作
------------

1.1 视图控制
    滚轮         : 以鼠标位置为中心缩放
    中键拖拽     : 平移画布
    工具栏"重置视图": 恢复初始缩放
    工具栏"画布设置": 自定义画布宽度和高度(mm)

1.2 对象选择
    左键单击     : 选择单个对象（按住Ctrl可多选）
    左键拖拽     : 框选（从左向右=全在框内才选中；从右向左=与框相交即选中）
    工具栏"取消选中": 清除所有选择
    ESC键        : 取消当前命令，回到选择模式

1.3 命令行输入（底部输入框）
    回车确认输入。
    支持格式:
    - 坐标: (100,200) 或 100,200 或 @50,30（相对上一点）
    - 长度: 100（直线沿当前方向延伸100mm）
    - 长度+角度: @100<45（长度100mm，角度45度）
    - 矩形尺寸: 100,80（宽100 高80）
    - 多边形边数: 6
    - 椭圆参数: 50,30（rx=50 ry=30）或 50,30,15（rx ry rotation）

二、绘图命令操作步骤
--------------------

2.1 直线 (L)
    步骤1: 按L或点击"直线"按钮
    步骤2: 点击或输入坐标指定第一点
    步骤3: 点击或输入坐标/长度指定第二点，命令行支持:
           - 直接输入数字 = 长度（沿当前预览角度）
           - @长度<角度 如 @100<45
    步骤4: 继续指定下一点连续绘制，右键结束

2.2 圆 (C)
    步骤1: 按C或点击"圆"按钮
    步骤2: 点击或输入坐标指定圆心
    步骤3: 点击或输入数值指定半径，右键结束

2.3 圆弧 (A)
    步骤1: 按A或点击"圆弧"按钮
    步骤2: 点击或输入坐标指定圆心
    步骤3: 点击指定起点（确定半径）或输入半径数值
    步骤4: 点击指定终点（确定角度范围），右键结束

2.4 矩形 (REC)
    步骤1: 点击"矩形"按钮
    步骤2: 点击或输入坐标指定第一个角点
    步骤3: 点击指定对角点，或命令行输入 宽,高 如 100,80

2.5 多边形 (POL)
    步骤1: 点击"多边形"按钮
    步骤2: 输入边数（如6）或直接点击中心点
    步骤3: 点击或输入数值指定外接圆半径

2.6 椭圆 (EL)
    步骤1: 点击"椭圆"按钮
    步骤2: 点击或输入坐标指定中心点
    步骤3: 点击指定长轴端点，或命令行输入 rx,ry 如 50,30

2.7 样条曲线 (SPL)
    步骤1: 点击"样条曲线"按钮
    步骤2: 依次点击多个控制点
    步骤3: 右键结束，自动生成平滑曲线

2.8 点 (PO)
    步骤1: 点击"点"按钮
    步骤2: 点击放置点，右键结束

三、修改命令操作步骤
--------------------

3.1 删除 (E)
    步骤1: 按E或点击"删除"按钮
    步骤2: 点击或框选要删除的对象
    步骤3: 点击工具栏"取消选中"确认删除，或按ESC取消

3.2 复制 (CO)
    步骤1: 按CO或点击"复制"按钮
    步骤2: 点击或框选要复制的对象
    步骤3: 点击或输入坐标指定基点
    步骤4: 点击或输入坐标指定目标点

3.3 镜像 (MI)
    步骤1: 按MI或点击"镜像"按钮
    步骤2: 点击或框选要镜像的对象
    步骤3: 点击或输入坐标指定镜像线第一点
    步骤4: 点击或输入坐标指定镜像线第二点
    步骤5: 命令行输入 Y=保留原对象（默认），N=删除原对象

3.4 偏移 (O)
    步骤1: 按O或点击"偏移"按钮
    步骤2: 输入偏移距离（或点击对象后用默认距离）
    步骤3: 点击要偏移的对象
    步骤4: 点击指定偏移方向侧（内侧/外侧）

3.5 阵列 (AR)
    步骤1: 按AR或点击"阵列"按钮
    步骤2: 命令行输入 行,列 如 3,5
    步骤3: 点击要阵列的对象

3.6 移动 (M)
    步骤1: 按M或点击"移动"按钮
    步骤2: 点击或框选要移动的对象
    步骤3: 点击或输入坐标指定基点
    步骤4: 点击或输入坐标指定目标点

3.7 旋转 (RO)
    步骤1: 按RO或点击"旋转"按钮
    步骤2: 点击或框选要旋转的对象
    步骤3: 点击或输入坐标指定旋转中心
    步骤4: 点击确定角度，或命令行直接输入角度值（度）

3.8 缩放 (SC)
    步骤1: 按SC或点击"缩放"按钮
    步骤2: 点击或框选要缩放的对象
    步骤3: 点击或输入坐标指定缩放中心
    步骤4: 点击确定比例，或命令行直接输入比例值（1.0=原尺寸）

3.9 拉伸 (S)
    步骤1: 按S或点击"拉伸"按钮
    步骤2: 框选对象:
           - 从左向右拖拽 = 全选对象整体移动
           - 从右向左拖拽 = 交叉选择，只拉伸与框相交的部分
    步骤3: 点击或输入坐标指定基点
    步骤4: 点击或输入 @dx,dy 指定偏移量

3.10 修剪 (TR)
    步骤1: 按TR或点击"修剪"按钮
    步骤2: 点击要修剪的对象上靠近要删除端的一侧

3.11 延伸 (EX)
    步骤1: 按EX或点击"延伸"按钮
    步骤2: 先命令行输入延伸长度（可选，默认延伸20%）
    步骤3: 点击要延伸的对象

3.12 打断 (BR)
    步骤1: 按BR或点击"打断"按钮
    步骤2: 点击选择要打断的对象
    步骤3: 点击指定第一个打断点
    步骤4: 点击指定第二个打断点，中间段被删除

3.13 打断于点
    步骤1: 点击"打断于点"按钮
    步骤2: 点击对象上的打断位置，对象在该点分成两段

3.14 合并 (J)
    步骤1: 按J或点击"合并"按钮
    步骤2: 框选多条线段（至少2条）
    步骤3: 选中线段合并为一条多段线整体

3.15 分解 (X)
    步骤1: 按X或点击"分解"按钮
    步骤2: 点击要分解的对象（矩形/多边形/圆/椭圆/圆弧）
    步骤3: 对象被分解为多条独立线段

3.16 倒斜角 (CHA)
    步骤1: 按CHA或点击"倒斜角"按钮
    步骤2: 命令行输入倒角距离（可选，默认10mm）
    步骤3: 点击选择第一条线
    步骤4: 点击选择第二条线
    步骤5: 两线被截断并生成斜角连接线

3.17 圆角 (F)
    步骤1: 按F或点击"圆角"按钮
    步骤2: 命令行输入圆角半径（可选，默认10mm）
    步骤3: 点击选择第一条线
    步骤4: 点击选择第二条线
    步骤5: 两线被截断并生成圆角弧线（用线段近似）

3.18 定数等分 (DIV)
    步骤1: 按DIV或点击"定数等分"按钮
    步骤2: 命令行输入段数（可选，默认5）
    步骤3: 点击要等分的对象（直线/圆弧/圆/多段线）

3.19 定距等分 (ME)
    步骤1: 按ME或点击"定距等分"按钮
    步骤2: 命令行输入间距（可选，默认100mm）
    步骤3: 点击要等分的对象

四、图层管理
------------

4.1 打开图层管理器
    点击工具栏"图层管理"按钮

4.2 设置当前图层
    在表格中单击某行选中 → 点击"设为当前图层"按钮

4.3 修改图层属性
    - 可见性: 勾选/取消勾选"可见"列的复选框
    - 锁定: 勾选/取消勾选"锁定"列的复选框
    - 颜色: 双击"颜色"列的色块，弹出颜色选择器
    - 线宽: 双击"线宽"列的数值，输入新线宽

4.4 新建/删除图层
    点击"新建图层"按钮 → 输入名称
    选中图层后点击"删除图层"按钮

五、吸附设置
------------

5.1 打开吸附设置
    点击工具栏"吸附设置"按钮

5.2 吸附类型
    - 端点吸附: 吸附到线段端点、矩形角点、圆弧端点等
    - 交点吸附: 吸附到两条线段的交点
    - 中心点吸附: 吸附到圆心、矩形中心、多边形重心
    - 垂足吸附: 吸附到点到线段的垂足
    - 网格吸附: 吸附到网格交点

5.3 优先级（从高到低）
    端点 > 交点 > 中心点 > 垂足 > 网格

六、撤销与取消选中
------------------

6.1 撤销上一步
    点击工具栏"撤销(U)"按钮，移除最后添加的元素

6.2 取消选中
    点击工具栏"取消选中"按钮，清除所有选中状态

七、导入/导出
-------------

7.1 导入DWG/DXF
    点击"导入DWG"按钮 → 选择 .dwg 或 .dxf 文件
    - 如为 .dwg，自动调用ODA File Converter转为DXF后导入
    - 几何实体（直线/圆/圆弧/多段线/椭圆/点）被导入
    - 文字/标注/块引用被忽略
    - 图层信息被保留

7.2 导出DXF/DWG
    点击"导出DWG"按钮 → 选择保存格式和位置
    - DXF直接导出
    - DWG需要ODA File Converter转换（自动调用）

八、BIMBase同步
---------------

8.1 同步到BIMBase
    点击"同步到BIMBase"按钮
    - 每个几何元素创建一个独立的参数化Component
    - 闭合图形（矩形/圆/多边形/椭圆）→ Section面片
    - 开放图形（直线/圆弧/多段线）→ Line线段
    - 在BIMBase属性面板中修改参数可反向更新画板

8.2 从BIMBase更新
    点击"从BIMBase更新"按钮
    - 读取已同步的Component参数值
    - 更新画板上对应元素的几何

九、常见问题
------------

Q: 画板闪退怎么办？
A: 所有事件已加异常捕获，异常信息写入 CADBoard_error.log。如果仍闪退，请检查日志文件并反馈。

Q: DWG导出失败怎么办？
A: 请确保ODA File Converter已正确安装。工具会在以下路径查找：
   C:\Program Files\ODA\...
   C:\Program Files (x86)\ODA\...

Q: 修改命令点击对象后没反应？
A: 修改命令需要先选中对象。左键点击选择对象后，状态栏会提示下一步操作。

Q: 命令行怎么输入角度？
A: 直线命令支持 @长度<角度 格式，如 @100<45 表示长度100mm角度45度。
   旋转命令直接输入角度数值（度）。
