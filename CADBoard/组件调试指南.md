# BIMBase 参数化组件调试指南

## 一、核心问题：为什么组件代码难调试？

参数化组件（如 `RightTriangularPrism`、`SweepBoxComponent`）基于 `pyp3d` SDK，而 `pyp3d` **只在 BIMBase 进程内存在**。这意味着：

- ❌ 不能用系统默认的 Python 直接运行
- ❌ 不能在 VS Code 里按 F5 直接调试（除非附加到 BIMBase 进程）
- ✅ 必须在 BIMBase 的嵌入式 Python 环境中执行

---

## 二、三种实用调试方案

### 方案 1：独立调试脚本（推荐，最快）

写一个独立脚本，用 BIMBase 的 Python 解释器运行，测试组件的创建和 `replace()` 方法。

**步骤 1：找到 BIMBase Python 路径**

在你的环境中大概是：
```
D:\BIMBASE2025\BIMBase建模软件 2025\PythonScript\python-3.7.9-embed-amd64\python.exe
```

**步骤 2：创建调试脚本**

在 `组件测试` 目录下新建 `debug_component.py`：

```python
# -*- coding: utf-8 -*-
"""
组件独立调试脚本
用法: 用 BIMBase 的 python.exe 运行此脚本
"""
import sys
import os
import traceback

# 将组件目录加入路径
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

try:
    from pyp3d import Component, Attr, Section, Line, Sweep, Vec2, Vec3, place
    print("✅ pyp3d 导入成功")
except ImportError as e:
    print(f"❌ pyp3d 导入失败: {e}")
    print("请确认使用 BIMBase 的 Python 解释器运行此脚本")
    sys.exit(1)

try:
    from pyp3d import export
except ImportError:
    def export(func):
        return func

# ========== 导入要调试的组件 ==========
from model import RightTriangularPrism

# ========== 测试 1：创建组件 ==========
print("\n--- 测试 1：创建组件 ---")
try:
    prism = RightTriangularPrism(a=100, b=100, h=200)
    print(f"✅ 组件创建成功")
    print(f"   a = {prism['a']}")
    print(f"   b = {prism['b']}")
    print(f"   h = {prism['h']}")
except Exception as e:
    print(f"❌ 创建失败: {e}")
    traceback.print_exc()

# ========== 测试 2：调用 replace() ==========
print("\n--- 测试 2：调用 replace() ---")
try:
    prism.replace()
    print("✅ replace() 执行成功")
    # 检查几何体是否存在
    geom = prism.get('直角三棱柱', None)
    if geom is not None:
        print(f"   几何体已生成: {type(geom)}")
    else:
        print("⚠️ 几何体为 None")
except Exception as e:
    print(f"❌ replace() 失败: {e}")
    traceback.print_exc()

# ========== 测试 3：修改参数后再次 replace() ==========
print("\n--- 测试 3：修改参数后 replace() ---")
try:
    prism['h'] = 300
    prism.replace()
    print("✅ 参数修改后 replace() 执行成功")
except Exception as e:
    print(f"❌ 参数修改后 replace() 失败: {e}")
    traceback.print_exc()

# ========== 测试 4：尝试 place()（需要完整 BIMBase 环境）==========
print("\n--- 测试 4：place() ---")
try:
    # 注意：place() 需要完整的 BIMBase GUI 环境，独立脚本中可能失败
    # 如果失败是正常的，说明组件类本身没有问题
    place(prism)
    print("✅ place() 执行成功（有 GUI 环境）")
except Exception as e:
    print(f"⚠️ place() 失败（独立脚本中属正常）: {e}")

print("\n--- 调试完成 ---")
```

**步骤 3：用 BIMBase Python 运行**

在 PowerShell 或 CMD 中：

```powershell
# 替换为你的实际路径
$D:\BIMBASE2025\BIMBase建模软件 2025\PythonScript\python-3.7.9-embed-amd64\python.exe C:\ProgramData\PKPM\BIMBase\Plugins\Pro\V1.6\pythonplugin\组件测试\debug_component.py
```

**预期输出**：
```

--- 测试 1：创建组件 ---
✅ 组件创建成功
   a = 100.0

```

### 方案 2：日志调试法（最稳，零配置）

在组件代码的 `replace()` 方法中添加日志，通过日志文件排查问题。

**示例：在 `model.py` 中添加日志**

```python
import os

LOG_FILE = os.path.join(os.path.dirname(os.path.abspath(__file__)), "component_debug.log")

def _log(msg):
    try:
        from datetime import datetime
        with open(LOG_FILE, "a", encoding="utf-8") as f:
            f.write(f"[{datetime.now().strftime('%H:%M:%S')}] {msg}\n")
    except Exception:
        pass

class RightTriangularPrism(Component):
    @export
    def replace(self):
        _log(f"replace() start")
        try:
            a = self['a']
            b = self['b']
            h = self['h']
            _log(f"params: a={a}, b={b}, h={h}, types: {type(a)}/{type(b)}/{type(h)}")
            
            section = Section(Vec2(0, 0), Vec2(a, 0), Vec2(0, b))
            _log(f"section created")
            
            path = Line(Vec3(0, 0, 0), Vec3(0, 0, h))
            _log(f"path created")
            
            self['直角三棱柱'] = Sweep(section, path)
            _log(f"replace() success")
        except Exception as e:
            _log(f"replace() ERROR: {e}")
            import traceback
            _log(traceback.format_exc())
            raise
```

运行后查看 `component_debug.log` 文件，可以精确定位到哪一行出错。

### 方案 3：VS Code 附加到 BIMBase 进程（最专业，但配置复杂）

如果你坚持要在 VS Code 中断点调试，可以用 **Attach** 模式：

**步骤 1：安装 `debugpy`**

```powershell
# 用 BIMBase 的 pip 安装
d:\BIMBASE2025\...\python.exe -m pip install debugpy
```

**步骤 2：在 `model.py` 开头添加调试监听代码**

```python
import debugpy
debugpy.listen(5678)  # 监听 5678 端口
print("等待 VS Code 附加调试...")
debugpy.wait_for_client()  # 阻塞，直到 VS Code 连接
```

**步骤 3：在 VS Code 的 `launch.json` 中添加配置**

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Attach to BIMBase",
            "type": "debugpy",
            "request": "attach",
            "connect": {
                "host": "localhost",
                "port": 5678
            },
            "justMyCode": false
        }
    ]
}
```

**步骤 4：操作流程**
1. 启动 BIMBase，加载组件测试插件
2. 组件代码执行到 `debugpy.wait_for_client()` 时会卡住
3. 在 VS Code 中按 F5 选择 "Attach to BIMBase"
4. 连接成功后，断点会生效

⚠️ **缺点**：每次都要等 BIMBase 启动并执行到监听代码，比较麻烦。推荐先用**方案 1（独立脚本）**快速验证组件逻辑。

## 三、常见问题排查

### Q1：`replace()` 被调用了但几何没更新？

检查 `self['直角三棱柱']` 是否被正确赋值：
```python
self['直角三棱柱'] = Sweep(section, path)
```
注意：如果 `Sweep` 创建失败（如参数类型不对），这里会抛出异常。

### Q2：参数值看起来正确但 `Vec2`/`Line` 报错？

`pyp3d` 的 `Vec2`/`Vec3` 对参数类型敏感。确保传入的是 `float` 或 `int`，不是 `Attr` 对象或其他类型：
```python
# 错误：a 可能是 Attr 对象
section = Section(Vec2(0, 0), Vec2(a, 0), Vec2(0, b))

# 正确：强制转换为 float
section = Section(Vec2(0, 0), Vec2(float(a), 0), Vec2(0, float(b)))
```

### Q3：`replace()` 成功但 BIMBase 中看不到变化？

BIMBase 可能不会自动刷新视图。尝试：
- 在 BIMBase 中重新选中组件
- 手动触发视图刷新
- 检查 `replace()` 是否真的被 BIMBase 调用了（加日志确认）

## 四、推荐调试流程

```
1. 写组件代码 → 2. 用独立脚本测试 replace() → 3. 在 BIMBase 中验证
                                    ↓
                              如果失败，看日志/加 print
                                    ↓
                              修复后重复步骤 2
```

**核心原则**：组件类本身的逻辑（参数定义 + `replace()` 几何生成）完全可以**脱离 BIMBase GUI 独立测试**，测试通过后再放到 BIMBase 里验证交互。
