# CADBoard 测试文档

## 测试环境

- BIMBase V1.6.x
- Python 3.7 / 3.x
- PyQt5/PyQt6 已安装
- pyp3d 可用
- 依赖包：ezdxf、PyMuPDF、ultralytics、opencv-python、python-docx

## 测试脚本

CADBoard 目录下散落着一些测试脚本，整理如下：

| 文件 | 用途 |
|---|---|
| `test_projection.py` | 测试面投影功能 |
| `test_audio.py` | 测试语音输入 |
| `test_noumenon_replace.py` | 测试实体替换 |
| `box_component_demo.py` | 盒子组件演示 |
| `测试.py` | 综合测试 |

## 功能测试

### 1. CAD画板基础绘图测试

1. 启动 CAD画板（点击“CAD画板”按钮）。
2. 分别测试直线、圆、矩形、多段线命令。
3. 验证图元是否正确显示在画布中。

### 2. 编辑命令测试

1. 绘制一条直线。
2. 选中直线，测试移动、旋转、缩放、删除命令。

### 3. DWG 导入导出测试

1. 准备一个简单 DWG 文件。
2. 使用 CAD画板的导入功能加载 DWG。
3. 验证图元是否正确解析。

### 4. PDF 导入测试

1. 准备一个包含矢量线条的 PDF 文件（如 `测试1.0.pdf`）。
2. 使用 PDF 导入功能。
3. 验证线条是否被正确提取。

### 5. AI 智能建模测试

1. 点击“AI智能建模”按钮。
2. 输入“创建一个半径 5 的圆柱”。
3. 验证是否生成圆柱。

### 6. 桥隧病害识别测试

1. 点击“桥隧病害识别”按钮。
2. 选择一张包含裂缝的测试图片。
3. 运行检测，验证是否框出病害。
4. 点击生成报告，验证 Word 文件是否正确导出。

### 7. 自动配置环境测试

1. 点击“自动配置环境”按钮。
2. 查看日志 `CADBoard_env_setup.log`。
3. 验证依赖包是否安装成功。

## 注意事项

- 测试 AI 和病害识别功能前，确保 API Key 和模型权重已配置。
- 测试 DWG/PDF 导入时，建议使用简单文件，避免复杂对象解析失败。
- 如测试过程中崩溃，请查看根目录下的 `*_CRASH.txt` 文件。
