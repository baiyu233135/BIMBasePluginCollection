# CADBoard - 桥隧病害识别说明

## 功能概述

桥隧病害识别功能基于 **YOLOv8** 目标检测模型，对无人机拍摄的桥梁/隧道照片进行病害检测，自动生成 Word 诊断报告，并可将病害位置投影到 BIMBase 模型中。

## 入口

- 插件按钮：**桥隧病害识别** → `bridge_disease_launcher.py` → `dialogs/disease_dialog.py`

## 支持识别的病害类型

| 类型 | 说明 |
|---|---|
| 裂缝 | 混凝土表面裂缝 |
| 剥落 | 保护层剥落 |
| 露筋 | 钢筋外露 |
| 蜂窝麻面 | 混凝土表面蜂窝状缺陷 |
| 渗水 | 结构渗水痕迹 |
| 锈蚀 | 钢筋或钢结构锈蚀 |

## 主要文件

| 文件 | 功能 |
|---|---|
| `bridge_disease_launcher.py` | 入口脚本，创建 Qt App 并打开对话框 |
| `dialogs/disease_dialog.py` | 病害识别主对话框 `DiseaseDialog` |
| `utils/disease_detector.py` | YOLOv8n 病害检测封装 |
| `utils/disease_marker.py` | 病害标记管理 |
| `utils/cv_crack_detector.py` | 传统 CV 裂缝检测（备用） |
| `utils/report_generator.py` | Word 诊断报告生成 |
| `utils/bimbase_query.py` | 查询 BIMBase 当前选中组件 |
| `utils/face_projection.py` | 将病害投影到模型表面 |
| `models/yolov8n.pt` | 预训练模型权重 |

## 训练相关

| 文件 | 功能 |
|---|---|
| `training/train_disease_yolo.py` | YOLO 病害检测训练 |
| `training/train_classifier.py` | 病害分类器训练 |

## 使用流程

1. 点击“桥隧病害识别”按钮，打开对话框。
2. 选择或导入无人机照片。
3. 选择模型权重（默认 `yolov8n.pt`）。
4. 点击“开始检测”，等待 YOLO 推理完成。
5. 查看检测结果，确认病害位置和类型。
6. 点击“生成报告”，导出 Word 诊断报告。
7. （可选）在 BIMBase 中选中对应构件，将病害投影到模型表面。
