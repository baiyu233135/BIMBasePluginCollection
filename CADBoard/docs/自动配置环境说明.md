# CADBoard - 自动配置环境说明

## 功能概述

自动配置环境功能用于一键配置 BIMBase Python 插件开发所需的运行环境，包括 VSCode 设置、Python 解释器、pyp3d 补全路径、依赖包安装、ODA 转换器检测等。

## 入口

- 插件按钮：**自动配置环境** → `setup_env.py` → `utils/env_config.py`

## 主要文件

| 文件 | 功能 |
|---|---|
| `setup_env.py` | 入口脚本，直接调用环境配置 |
| `utils/env_config.py` | 环境配置核心逻辑 |
| `get-pip.py` | pip 安装脚本 |

## 配置内容

### 1. 检测 BIMBase 安装路径

自动搜索以下常见路径：

- `C:\ProgramData\BIMBase\`
- `C:\Program Files\BIMBase\`
- `D:\BIMBASE\`

### 2. 配置 VSCode

更新 `settings.json`：

- 设置默认 Python 解释器为 BIMBase 内置 Python。
- 添加 `pyp3d` 等包的补全路径。

### 3. 安装依赖包

通过清华源 pip 安装：

```bash
pip install PyQt5 ezdxf PyMuPDF python-docx openpyxl pandas -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 4. 检测 ODA File Converter

检查是否安装 ODA File Converter，用于 DWG/DXF 格式转换。如未安装，弹出提示引导下载。

## 使用步骤

1. 在 BIMBase 中点击“自动配置环境”按钮。
2. 等待脚本检测当前环境。
3. 根据提示安装缺失的依赖。
4. 配置完成后重启 VSCode 和 BIMBase。

## 日志

配置过程会记录到 `CADBoard_env_setup.log`，可用于排查配置失败原因。

## 依赖

- Windows 操作系统
- BIMBase 已安装
- 网络连接（用于 pip 安装）
