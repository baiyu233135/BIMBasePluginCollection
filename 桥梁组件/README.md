# 桥梁组件 - 桥梁参数化结构库

本模块为桥梁工程提供一系列预制参数化组件，涵盖上部结构、下部结构、附属设施，并集成清单算量、STL 导入导出、Lumion 渲染、3D 打印等功能。

## 功能方向

### 1. 上部结构

- T 梁、箱梁、工字钢混凝土组合梁
- 斜拉索、主塔
- 湿接缝、波形护栏、防撞护栏

### 2. 下部结构

- 柱式桥墩、薄壁墩
- 桩基承台、主塔群桩承台
- 扩大基础、柱式桥台、重力式桥台
- 异形盖梁

### 3. 附属设施

- 人行道及护栏
- 波形护栏、防撞护栏
- 路面及交通标线

### 4. 工具

- **承台与桩基清单**：框选实体后自动导出体积算量 Excel。
- **STL 工具**：FBX/STL 导入导出、FBX 转 STL。
- **Lumion 渲染**：导出到 Lumion 渲染软件。
- **3D 打印软件**：集成 OrcaSlicer 切片软件。
