# 桥梁组件 - 报错处理记录

## 1. 组件创建失败

### 现象

点击某个桥梁组件按钮后，没有生成模型或报错。

### 原因

- pyp3d 接口调用错误。
- 参数值不合理（如负值、零值）。
- BIMBase 放置上下文异常。

### 处理方法

1. 先用 `组件测试/正方体.py` 验证 BIMBase 放置功能。
2. 检查组件脚本中的参数范围和默认值。
3. 在脚本中添加 `print()` 输出中间结果。

## 2. 清单工具统计为空

### 现象

框选实体后，生成的 Excel 中没有数据。

### 原因

- 选中实体不包含 `总体积` 属性。
- `get_element_from_boxselect()` 未获取到实体。
- Excel 文件被占用。

### 处理方法

1. 确认构件是 `桩基承台.py` 等会写入体积属性的组件。
2. 检查框选时是否选中了有效实体。
3. 关闭已打开的 Excel 文件后重试。

## 3. STL 导入导出失败

### 现象

导出 FBX 或导入 STL 时报错。

### 原因

- 缺少必要的 BIMBase 命令（如 `ExportFbxAll`）。
- 文件路径含中文或特殊字符。
- 模型过大导致内存不足。

### 处理方法

1. 确认 BIMBase 版本支持相应命令。
2. 使用英文路径测试。
3. 简化模型后重试。

## 4. 3D 打印切片软件无法打开

### 现象

点击“导出FBX并打开切片”后，OrcaSlicer 没有启动。

### 原因

- OrcaSlicer 未安装或路径配置错误。
- 批处理中硬编码路径与实际安装路径不符。

### 处理方法

1. 确认 OrcaSlicer 已安装。
2. 检查脚本中的 OrcaSlicer 路径。
3. 手动指定正确路径。

## 5. Lumion 渲染导出失败

### 现象

点击“导入Lumion”后无反应。

### 原因

- Lumion 未安装。
- 导出格式或路径不正确。

### 处理方法

1. 确认 Lumion 已安装。
2. 检查 `Lumion渲染软件/` 下的脚本和配置。

## 6. 图标显示异常

### 现象

BIMBase 面板中按钮图标不显示。

### 原因

- `.ico` 文件路径错误。
- 图标文件损坏。

### 处理方法

1. 检查 `.pyplugin` 中的 `<iconPath>` 是否与 `Picture/` 下文件名一致。
2. 重新生成或替换图标文件。
