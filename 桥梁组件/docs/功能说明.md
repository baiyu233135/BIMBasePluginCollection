# 桥梁组件 - 功能说明

## 功能概述

桥梁组件库提供一系列桥梁工程常用的参数化结构，按上部结构、下部结构、附属设施分类，并集成清单算量、STL 导入导出、Lumion 渲染、3D 打印等工具。

## 功能分类

### 1. 上部结构

桥梁上部承重结构，包括：

- T 梁
- 箱梁
- 工字钢混凝土组合梁
- 斜拉索
- 主塔
- 湿接缝
- 波形护栏
- 防撞护栏

### 2. 下部结构

桥梁下部支撑结构，包括：

- 柱式桥墩
- 薄壁墩
- 桩基承台
- 主塔群桩承台
- 扩大基础
- 柱式桥台
- 重力式桥台
- 异形盖梁

### 3. 附属设施

桥面及附属构造，包括：

- 人行道及护栏
- 波形护栏
- 防撞护栏
- 路面及交通标线

### 4. 工具

#### 承台与桩基清单

框选 BIMBase 场景中的实体，自动筛选含“总体积”属性的构件，导出 Excel 算量清单。

#### STL 工具

- 导入 STL
- 导出 FBX
- FBX 转 STL
- 导出 FBX 并打开切片软件

#### Lumion 渲染

将模型导出到 Lumion 渲染软件。

#### 3D 打印软件

集成 OrcaSlicer 切片软件，支持导出模型并直接打开切片。

## 目录结构

```
桥梁组件/
├── Picture/              # 图标资源
└── 桥梁组件/
    ├── 1-上部结构/       # 8 个参数化组件 + .bfa
    ├── 2-下部结构/       # 8 个参数化组件 + .bfa
    ├── 3-附属设施/       # 4 个参数化组件
    ├── 承台与桩基清单/   # 清单工具 + 环境配置
    ├── Stl插件/          # STL/FBX 工具
    ├── Lumion渲染软件/   # Lumion 导出
    └── 3D打印软件/       # OrcaSlicer 集成
```

## 入口

由根目录 `桥梁组件.pyplugin` 注册，详见 [组件清单.md](组件清单.md)。

## 依赖

- pyp3d
- openpyxl（清单工具）
- PyQt5/PyQt6（部分工具 UI）
- OrcaSlicer（3D 打印，需单独安装）
- Lumion（渲染，需单独安装）
