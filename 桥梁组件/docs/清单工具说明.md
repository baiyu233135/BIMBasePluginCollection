# 桥梁组件 - 清单工具说明

## 功能概述

承台与桩基清单工具用于框选 BIMBase 场景中的实体，自动筛选含“总体积”属性的构件，生成 Excel 算量清单。

## 入口

- 插件按钮：**承台与桩基清单** → `桥梁组件/桥梁组件/承台与桩基清单/承台与桩基清单.py`
- 自动配置环境按钮 → `桥梁组件/桥梁组件/承台与桩基清单/自动配置环境.py`

## 主要文件

| 文件 | 功能 |
|---|---|
| `承台与桩基清单/承台与桩基清单.py` | 清单生成主脚本 |
| `承台与桩基清单/自动配置环境.py` | 环境配置 |
| `承台与桩基清单/自动配置环境.bat` | 环境配置批处理 |
| `承台与桩基清单/算量清单.xlsx` | 清单输出模板 |
| `承台与桩基清单/算量清单(单行).xlsx` | 单行格式清单 |

## 使用流程

1. 在 BIMBase 中创建或导入桥梁下部结构（如桩基承台）。
2. 确保构件属性中包含 `总体积`。
3. 点击“承台与桩基清单”按钮。
4. 在场景中框选需要统计的实体。
5. 脚本自动生成 `算量清单.xlsx` 并打开。

## 输出字段

- 序号
- 构件名称
- 类别
- 数量
- 承台体积（m³）
- 桩基体积（m³）
- 总体积（m³）

## 依赖

- openpyxl
- pyp3d

## 注意事项

- 只有包含 `总体积` 属性的实体才会被统计。
- 确保 `桩基承台.py` 等组件已正确写入体积属性。
