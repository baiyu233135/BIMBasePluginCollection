# 桥梁组件 - 测试文档

## 测试环境

- BIMBase V1.6.x
- Python 3.7 / 3.x
- pyp3d 可用
- openpyxl（清单工具）

## 组件创建测试

### 测试 1：T 梁

1. 在 BIMBase 中点击“T梁”按钮。
2. 在弹出的参数对话框中设置：长、底板宽/高、翼缘宽、腹板宽、总高。
3. 预期结果：生成 T 梁模型并放置到场景。

### 测试 2：桩基承台

1. 点击“桩基承台”按钮。
2. 设置承台宽/长/高、桩半径/高、单边桩基数量。
3. 预期结果：生成承台和桩基，属性中包含 `承台体积`、`桩基体积`、`总体积`。

### 测试 3：箱梁

1. 点击“箱梁”按钮。
2. 设置梁长、截面参数。
3. 预期结果：生成箱梁模型，自动计算横隔板数量。

## 清单工具测试

1. 在场景中创建多个桩基承台。
2. 点击“承台与桩基清单”按钮。
3. 框选所有承台和桩基。
4. 预期结果：生成 `算量清单.xlsx`，包含各构件体积。

## STL 工具测试

### 导出 FBX

1. 创建一个简单桥梁模型。
2. 点击“导出FBX”。
3. 预期结果：生成 `.fbx` 文件。

### 导入 STL

1. 准备一个 `.stl` 文件。
2. 点击“导入Stl”。
3. 预期结果：模型导入到场景。

## 注意事项

- 测试组件创建时，建议先使用 `组件测试/` 中的简单几何体验证环境。
- 清单工具依赖 `总体积` 属性，确保构件已正确写入。
- STL 工具测试需要准备相应的模型文件。
