# 99 - 常见问题与调试

本文件汇总项目开发和使用过程中遇到的常见问题与处理方法。各模块更详细的问题记录请查看对应目录下的 `docs/报错处理记录.md`。

## 一、通用问题

### 1. 插件按钮点击后没有反应

**可能原因**：
- `.pyplugin` 中的入口脚本路径错误或文件缺失。
- Python 环境缺少依赖包。
- BIMBase 内置 Python 与脚本所需的包版本不兼容。

**处理方法**：
- 检查 `.pyplugin` 中的 `<command>` 路径是否指向存在的 `.py` 文件。
- 在 BIMBase 命令行中手动运行入口脚本，查看报错信息。
- 运行对应模块的 `setup_env.py` 或 `环境配置.py` 安装缺失依赖。

### 2. 找不到 `pyp3d` 模块

**可能原因**：VSCode 或脚本使用的 Python 解释器不是 BIMBase 内置 Python。

**处理方法**：
- 在脚本中添加打印语句，确认 `sys.executable` 路径。
- 在 VSCode 中选择正确的解释器：`Python: Select Interpreter`。
- 将 BIMBase 内置 Python 的 `Lib/site-packages` 加入 `PYTHONPATH`。

### 3. 中文路径或中文文件名导致乱码

**可能原因**：Python 默认编码不是 UTF-8，或 PowerShell/Bat 脚本编码不一致。

**处理方法**：
- 在 Python 脚本开头添加 `# -*- coding: utf-8 -*-`。
- 在 `.bat` 文件中使用 `chcp 65001` 切换 UTF-8 编码。

## 二、AI 建模相关问题

### 1. 选中组件后“复制/在选中位置生成”找不到原参数

**可能原因**：
- 该组件不是通过 `AI_Modeling` 创建的，注册表中没有记录；
- 组件注册表 `AI_Modeling/component_registry.json` 被清空或损坏；
- 选中的是复杂组件，但动态加载失败。

**处理方法**：
- 对于非 AI 创建的组件，`AI_Modeling` 会尝试从 BIMBase 实体参数反推类型和尺寸，可继续使用；
- 点击 **🧹 清理缓存** 按钮或手动删除 `component_registry.json`，重新生成组件以重建注册表；
- 检查 `ai_modeling_debug.log` 中复杂组件加载失败的记录。

### 2. 修改组件后位置发生偏移

**可能原因**：
- 修改参数触发了 `replace_noumenon`，导致组件局部坐标系变化；
- 未使用“位置不变”等保留位置关键词。

**处理方法**：
- 在修改指令中加入“位置不变”、“不要移动”、“保留位置”等词；
- `AI_Modeling` 会记录修改前的位置并在修改后写回注册表；
- 如仍漂移，可手动选中组件后使用“复制选中的...到原坐标”恢复。

### 3. AI 返回的代码无法运行

**可能原因**：
- AI 生成的代码使用了当前环境不存在的 API。
- 代码中路径、参数与当前场景不匹配。

**处理方法**：
- 优先使用 `AI_Modeling` 的本地解析功能，减少对 AI 生成代码的依赖。
- 手动检查 AI 返回代码中的导入和参数。
- 在 `AI建模/` 旧版流程中，将代码粘贴到剪贴板后，由 `代码运行交互.py` 运行。

### 4. `place_to` 或 `create_geometry` 返回无效实体

**可能原因**：
- BIMBase 的模态对话框阻塞了交互上下文。
- 组件参数不正确，导致几何生成失败。

**处理方法**：
- `AI_Modeling/ai_modeling/component_factory.py` 已实现多级兜底策略：
  1. `create_geometry(translate(...) * comp)`
  2. 直接调用底层 `UnifiedFunction`
  3. 原生 `place_to(...)`
  4. 烘焙坐标到组件内部偏移参数
  5. 生成临时 IFC 导入
  6. 模拟鼠标点击
  7. 回退到手动 `place()`
- 如仍失败，可尝试关闭模态对话框，使用非模态窗口或 `QTimer` 延迟执行。

### 5. DeepSeek API 调用失败

**可能原因**：
- `api_key` 无效或过期。
- 网络连接不稳定。
- 请求格式不正确。

**处理方法**：
- 检查 `AI_Modeling/ai_modeling_config.json` 中的 `api_key`。
- 确认 `api_base` 和 `model` 名称正确。
- 查看 `ai_modeling.log` 中的请求返回信息。

## 三、CADBoard 相关问题

### 1. CAD 画板与 BIMBase 进程不同步

**可能原因**：BIMBase 进程 PID 变化，或 COM/IPC 连接失败。

**处理方法**：
- 运行 `CADBoard/utils/bimbase_pid.py` 修复 PID 绑定。
- 确保 BIMBase 已启动，且只有一个实例。

### 2. DWG/PDF 导入后尺寸不对

**可能原因**：坐标单位或比例因子设置错误。

**处理方法**：
- 在 `CADBoard/utils/dwg_handler.py` 或 `pdf_handler.py` 中调整单位转换系数。
- 检查导入对话框中的比例设置。

### 3. 桥梁病害识别检测不到病害

**可能原因**：
- 图片分辨率过低或病害特征不明显。
- YOLO 模型权重 `yolov8n.pt` 与目标病害类型不匹配。
- 置信度阈值设置过高。

**处理方法**：
- 使用清晰度更高的照片。
- 在 `CADBoard/utils/disease_detector.py` 中降低置信度阈值。
- 使用 `training/train_disease_yolo.py` 重新训练模型。

## 四、调试技巧

1. **查看日志**：大多数模块会生成 `.log` 文件，优先查看日志定位问题。
2. **最小化复现**：遇到复杂脚本报错时，先用 `组件测试/` 中的简单几何体验证环境。
3. **使用组件测试**：`组件测试/正方体.py`、`圆柱.py` 等可作为基础功能验证。
4. **检查 .pyplugin**：用文本编辑器打开 `.pyplugin`，确认入口路径是否正确。
5. **备份后尝试**：修改关键脚本前，先备份原文件。
