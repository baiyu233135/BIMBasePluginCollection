     模块从 BFATemp 哈希副本运行），无交互工具上下文。
  ⑤ replace 从 self.transformation 提取平移：✅ 定型。零风险、原生顺滑。


四、技术要点（务必记住）
------------------------
  1. "网长通道"：place_to 之前写进 data 的参数才持久化并显示在面板
     （TwoPointPlace 写网长即此机制）。
  2. replace() 在 service 进程跑（BFATemp 缓存副本），工具取点 API 在其中
     恒返 (0,0,0)；组件内写日志要多路径兜底（__file__/argv[0]/插件目录）。
  3. 实例放置变换：noumKV 的 '\x07_transformation' / '\x07GraphicElement::m_transform'
     （GeTransform._mat 3x4 行主序，平移 [i][3]）；Placement/BaseTransform 为 None。
  4. 面板选中的"参数化组件代理"datakey 的 noumKV 为空；真实实例需
     get_all_instancekey 全扫 + get_allbinding_entity_from_data 按
     (_ModelId,_ElementId) 元组匹配（不可 str()；(None,None) 退化不可作依据）。
  5. 全场景扫描逐个 RPC 分钟级，必须找到即停 + 进度日志。
  6. noum 直写会被重实例化冲掉；replace_noumenon 会崩——两条路都禁。
  7. pyp3d 新 API 引用前先用 grep 验证存在（get_selections 在本版本不存在，
     from-import 会直接炸脚本）；导入一律 getattr 宽容式。
  8. pyp3d 颜色：.color(r,g,b[,a]) 0~1 浮点；Combine 前分别上色；
     对 Combine 再调色会递归覆盖所有零件。
