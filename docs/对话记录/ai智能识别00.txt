一、用户需求
------------
增强 AI_Modeling 模块，使其支持"读取 BIMBase 中已选中组件的位置，并基于该位置放置新组件"。

具体场景包括：
1. 相对位置模式：在选中组件的某个轴向（x/y/z）偏移一定距离后生成新组件。
2. 选中位置模式：直接在选中组件所在位置生成新组件（不偏移）。
3. 复制模式：复制当前选中的 AI 组件到新位置。
4. 修改模式：修改选中组件参数时，若用户要求保留位置，则在修改后恢复原始位置。

核心难点：BIMBase 中对参数化组件的选中对象往往是 proxy 实体，直接读取其参数会失败，甚至导致 pyp3d _Core 损坏，必须设计稳定、非破坏性的读取回退链。

三、技术栈与关键实现
--------------------
运行环境：
  - BIMBase 2025
  - Python 3.7.9 嵌入式解释器（BIMBase 自带）
  - pyp3d SDK 版本：v18446497937724801024（Release 2024.10）
  - SDK 路径：D:\BIMBASE\BIMBase建模软件 2025\PythonScript\python-3.7.9-embed-amd64\Lib\site-packages\pyp3d

关键 API：
  - get_entityid_from_boxselection()：读取当前框选/点选的 entity id 列表（空选抛 ValueError，需捕获）。
  - get_current_entityId()：读取当前单选 entity id。
  - get_noumenon_on_entityid(entityid)：安全只读，获取实体对应的 Noumenon。
  - get_noumenon_from_datakey(instancekey)：通过 instance key 读取 Noumenon。
  - get_datakey_from_entity(entityid)：entity id → instance key 的反向查找。
  - get_allbinding_entity_from_data(instancekey)：获取某个参数化组件实例绑定的所有子实体 ID。
  - get_matrixs_position(transform)：从 GeTransform 中提取平移向量 (x, y, z)。

世界坐标读取链（按优先级）：
  1. get_entity_bounds()：当前版本不存在，自动跳过。
  2. get_noumenon_on_entityid(eid) → 提取 \a_transformation。
  3. get_datakey_from_entity(eid) → get_noumenon_from_datakey → 提取 \a_transformation。
  4. 扫描所有 instance key：用 get_allbinding_entity_from_data 匹配选中实体 → 读该实例的变换/Placement。
  5. 按 ID 扫描所有 instance key。
  6. get_selected_instance_keys() → 读 datakey 参数。
  7. 注册表 / 最近一次生成位置回退。

关键注意事项：
  - pyp3d _Core 很脆弱：把 entity id 传给期望 instance key 的 API（如 get_noumKV_from_instancekey）会损坏通讯端口，导致后续所有 UnifiedFunction 调用失败。代码中已严格区分 entity id 与 instance key 的处理路径。
  - get_element_from_boxselect() 是阻塞交互工具（启动 PyMarqueeTool 并 while True 等待），不能作为后台自动读取，已移除。
  - GeTransform._mat 是 3×4 行主序矩阵，平移分量位于 _mat[i][3]。
