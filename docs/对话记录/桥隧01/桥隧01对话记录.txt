一、我的需求
================================================================================

1. 在既有 "桥隧病害识别" 模块基础上，为 T 梁照片增加 AI 智能诊断能力。
2. AI 需能看懂图片：输入原始照片 + 算法圈好红框的标注照片，一次性分析
   所有红框区域，输出每处区域的专业诊断结论。
3. 由于 DeepSeek Chat 为纯文本模型，不能使用；改用阿里云 DashScope 
   Qwen-VL-Max / Qwen-VL-Plus 多模态大模型。
4. 诊断报告（Word）中必须显示带框/标注的照片，并包含 AI 诊断内容。
5. UI 调整：
   - 新增 "🧠 AI 智能诊断" 按钮（CV 识别完成后启用）。
   - 将三个投影测试按钮（面投影/纹理/点云）合并为统一的 "🎯 病害投影"
     按钮；实际投影逻辑可延后实现。
6. 提供弹窗配置 API Key 的入口，避免用户手动编辑 JSON。
7. 配置需写入 `桥隧病害识别/disease_config.json`。

三、技术栈
================================================================================

【运行环境】
  操作系统：Windows（项目实测环境）
  BIMBase 平台：BIMBase Python SDK 1.6.2
  Python 解释器：Python 3.7 embed（BIMBase 内置）

【核心语言与框架】
  Python 3.7
  PyQt5 —— 对话框、表格、图片预览、按钮交互
  OpenCV (cv2) —— 传统 CV 异常区域检测
  Pillow (PIL) —— 带框图片绘制、字体渲染

【模型与 AI 服务】
  阿里云 DashScope 多模态模型
    - qwen-vl-max（默认）
    - qwen-vl-plus（可配置切换）
  调用接口：OpenAI 兼容模式
    URL：https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
  传输方式：HTTP POST + JSON，图片使用 data URL（base64）

【报告生成】
  python-docx —— 生成 Word 诊断报告

【网络请求】
  requests（优先）
  urllib.request（fallback，BIMBase 无 requests 时使用）

【版本控制】
  Git（本地仓库，本对话记录纳入版本管理）

【依赖安装命令】
  若 BIMBase 内置环境缺少依赖，可在其 Python 环境中执行：

    pip install python-docx pillow requests opencv-python-headless PyQt5

  注：BIMBase 1.6.2 已内置 PyQt5 与部分库，实际按需补充即可。
