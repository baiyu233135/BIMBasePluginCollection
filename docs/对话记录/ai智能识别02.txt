三、技术栈与关键实现
--------------------
运行环境：
  - BIMBase 2025，Plugin SDK 1.6.2
  - BIMBase 内置 python-3.7.9-embed-amd64
  - pyp3d SDK v18446497937724801024（Release 2024.10）
  - 开发机 Python：D:\zengpython3.13.2（跑离线测试用）
  - GUI：PyQt5/PyQt6；AI：DeepSeek API（本地解析优先，AI 兜底）

关键机制（务必记住）：
  1. DependentFile 序列化：组件类必须定义在 sys.argv[0] 指向文件
     （AI_Modeling/bimbase_sync.py）的模块级，BIMBase 才能放置/序列化。
     动态加载到合成模块的类会静默失败。新增复杂组件照此办理。
  2. 放置必须校验：_PlaceToDirect/place_to 可能不抛异常但实体未创建，
     用 get_all_entityid() 计数或 get_place_to_entityId() 验证后再报成功。
  3. 解析器通用模式（高/长/宽 + 数字）会对复杂组件指令产生伪参数
     （如“墩高2000”套出 height=2000），在写入组件前按组件允许的键集过滤，
     不要在解析器里做特殊化。
  4. 汉字数字在 parse() 入口统一转换，下游所有模式（参数/坐标/间距/数量/
     索引）自动受益；数量提取按“共 N 个 > 动作词+N个 > 通用 N 个”分级。
  5. pyp3d _Core 脆弱：entity id 与 instance key 严格区分（见 ai智能识别00）。

关键文件：
  - AI_Modeling/bimbase_sync.py                 组件类定义（DependentFile）
  - AI_Modeling/ai_modeling/component_factory.py 创建/放置/校验/注册
  - AI_Modeling/ai_modeling/bimbase_modifier.py 修改已有实例
  - AI_Modeling/ai_modeling/command_parser.py   本地指令解析（含汉字数字）
  - AI_Modeling/ai_modeling/ai_window.py        对话面板与分发
  - AI_Modeling/test_pier_parse.py              离线回归测试（20 用例）
  - 调试日志：AI_Modeling/ai_modeling_debug.log
