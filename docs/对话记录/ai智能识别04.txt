二、关键纠正：删除 API 存在
---------------------------
此前记录（ai智能识别00/02）认为"BIMBase 未提供删除 API"——过时判断。
pyp3d SDK（v18446497937724801024/pyp3d_api.py）实际提供：
  - delete_one_entity(entityid)         按实体删（本功能主路径，实测有效）
  - delete_data_bydatakey(instancekey)  按实例删（兜底路径）
  - delete_entity(**kwargs) / clear_entity()  按条件删/清空（未使用，太危险）
教训：SDK 能力以源码检索为准（grep "def delete"），不要沿用旧结论。

四、实测与误报修复（重要教训）
------------------------------
现象：用户实测删除成功（组件消失），但面板报"删除指令已执行，但场景实体数
未减少，可能未生效"——误报。
根因：初版用 _count_entities() 前后对比做校验，但参数化组件实体经
delete_one_entity 删除后，get_all_entityid 计数不一定减少（计数口径不同），
entityid_isvaid 复查也可能仍有效（删除延迟/可撤销）。
修复（2026-08-21）：API 无异常即判成功，计数对比仅写日志。
教训：**校验手段本身也要实测验证**——放置校验（_verify_new_entity 计数增加）
是可靠的，但同样的计数思路套在删除上就会误报；不同 API 的计数口径不同。
关联提交：a4c7337。
