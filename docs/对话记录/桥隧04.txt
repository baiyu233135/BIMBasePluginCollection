一、我的需求
------------

1.1 本轮主需求（按对话顺序）
  ① 病害投影到真实构件：把对话框里带真实 bbox 的病害记录，投影到 BIMBase
     中真实摆放的桥墩构件表面上（不再只是估算位置放红方块）。
     首批构件选定为 柱式桥墩/墩柱；面由用户下拉选择；比例按“等比铺满整面”，
     位置大致准确即可。
  ② 可以采用点云模拟到表面上（替代最初的阴影薄片方案）。
  ③ 点击病害红框可选中，再删即删除红框及对应词条；在照片上手动拖拽框选

三、技术栈与关键实现（务必记住）
--------------------------------

3.1 环境
  - BIMBase 2025（D:\BIMBASE\BIMBase建模软件 2025），Plugin SDK 1.6.2，
    pyp3d SDK v18446497937724801024（源码在 D盘 PythonScript/python-3.7.9-embed-amd64
    /Lib/site-packages/pyp3d/，可查接口定义）。
  - BIMBase 内置 python-3.7.9-embed-amd64（PyQt5）；开发机 D:\zengpython3.13.2
    跑离线测试（PyQt5 offscreen、PIL）。

3.2 选中组件参数读取
  - get_current_entityId → get_datakey_from_entity 拿到的是“参数化组件代理”，
    读不到参数（官方注释证实）。正路：get_all_instancekey() 全场景扫描 +
    get_noumKV_from_instancekey + 展开 ParaCmptProperty +
    infer_bridge_component_type 签名识别；多构件时让用户选。
  - P3DInstanceKey 不可 str()/repr()/bool()（触发 _data AttributeError）。

3.3 构件基准坐标（世界坐标）
  - 优先级：手动输入 → params 的 x/y/z_bottom → noumKV 的
    '\a_transformation' / '\aGraphicElement::m_transform' / Placement /
    BaseTransform（GeTransform._mat 是 3x4 行主序矩阵，平移在 [i][3]）。
  - 目前只取平移，不处理旋转（组件被旋转放置时面方向会按未旋转算）。

3.4 标记放置（最易踩坑）
  - 几何烘焙世界坐标后，放置必须用零变换，否则平移应用两次。
  - pyp3d Cube() 原点在角点而非几何中心。
  - pyp3d Component 的 replace() 里不要局部 import 与模块级同名的名字
    （Cube 等）——BIMBase 放置时会用默认参数重实例化并跑 replace()，
    提前分支引用被遮蔽的名字会 UnboundLocalError。
  - 组件类必须在模块级定义（DependentFile 序列化）。
  - 放置用 CADBoard/bimbase_sync._PlaceToDirect（create_component +
    TRANSFORMATION + UnifiedFunction create），不走 place() 手动模式；
    调用前把 sys.argv[0] 指向 CADBoard/bimbase_sync.py。

3.5 照片框交互
  - 红框矢量叠加（QPainter），不要烘焙进显示图；烘焙图仅供报告/AI 诊断。
  - 框→记录靠并行索引表 _view_record_indices（只含当前照片且有 bbox 的记录）。
  - 拖拽阈值 5px 区分“单击空白取消选中”与“框选添加”。

3.6 关键文件
  - 桥隧病害识别/face_projection.py     面几何 + bbox→面映射 + 点云生成器
  - 桥隧病害识别/disease_dialog.py      对话框（扫描/投影/交互/记录）
  - 桥隧病害识别/disease_marker.py      标记组件（点云/阴影/纹理/立方体）
  - 桥隧病害识别/image_box_widget.py    可交互图片控件
  - 桥隧病害识别/bimbase_query.py       构件类型签名识别
  - 桥隧病害识别/test_pier_projection_mapping.py  离线回归测试（33 用例）
  - 调试日志：桥隧病害识别/bridge_disease_debug.log（[MARKER] 投影、
    [AI_DIAG] 诊断）、根目录 bridge_disease_debug.log（[SEL] 扫描）、
