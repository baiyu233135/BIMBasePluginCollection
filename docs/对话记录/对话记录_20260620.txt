三、技术栈
----------

3.1 基础环境
  - 操作系统：Windows
  - BIMBase 版本：Plugin SDK 1.6.2
  - Python 环境：BIMBase 内置 python-3.7.9-embed-amd64
  - 核心 SDK：pyp3d（BIMBase 三维建模接口）
  - 插件清单：*.pyplugin（XML 格式）

3.2 目标 ①：画板图纸识别与参数化建模
  - 图纸解析：
    * PDF 转图：PyMuPDF (fitz)、Pillow
    * DWG 解析：ezdxf（注意当前 DWG 仅为 PDF 引用，实际几何需从图片识别获取）
    * 图像处理：OpenCV-Python、Pillow、numpy
  - 识别方案（A + B 并行）：
    * 方案 A（联网多模态 LLM）：
      - GPT-4o / DeepSeek-VL / Qwen-VL-Max 等
      - 输入：PDF 页面截图或图纸局部截图
      - 输出：结构化参数 JSON（尺寸、数量、间距等）
    * 方案 B（本地化）：
      - OCR：PaddleOCR（文字/数字识别）
      - 图像理解：本地部署 Qwen-VL / InternVL 等轻量视觉模型
      - 标注/检测：OpenCV 轮廓分析、ultralytics/YOLO（可选，用于定位尺寸线、图框）
  - 参数化建模：pyp3d 组件开发（Component / Attr / export / place）
  - 交互界面：PyQt5（参数面板、识别按钮、结果展示）
  - 缓存：JSON 文件或 SQLite

3.3 目标 ②：桥隧病害识别并投影到 3D 构件
  - 图像识别：
    * OpenCV-Python（预处理、形态学、轮廓）
    * ultralytics / YOLOv8（目标检测/分割，用于病害定位）
    * Pillow（图像标注、结果可视化）
  - 报告生成：python-docx
  - 3D 投影：
    * BIMBase SDK 贴图 API（将病害图片贴到 T 梁构件表面）
    * BIMBase SDK 点云 API（生成近似位置点云）
    * pyp3d 构件定位与坐标转换
  - 交互：PyQt5 面板（导入图片、识别、圈出、生成报告、投影）

3.4 目标 ③：AI Agent 工作流整合
  - 参考实现：
    * PKPMAgent（D 盘 PKPM/pkpm2026r2.1 中的 AI 功能产品）
    * coze 智能体工作流（https://mp.weixin.qq.com/s/W_SRwEGorKPpmIKRy4y_cg）
  - 技术选项：
    * 大模型：DeepSeek / Qwen / GPT-4o 等
    * 调用协议：Function Calling / MCP（Model Context Protocol）
    * 编排框架（可选）：LangChain / LangGraph
    * 本地部署：Ollama / vLLM（若需离线运行小模型）
  - 集成点：
    * 接收自然语言指令 → 调用画板识别、参数修改、构件布置、病害检测等工具
    * 返回执行结果与可视化反馈
