2. 当前已完成
-------------
2.1 参数体系统一为精简版 7 个核心参数：
    盖梁总长、盖梁总高、盖梁宽、墩柱直径、墩柱间距、墩高、系梁根数。
    其余细部尺寸（凸起、斜边、系梁长/宽/高/间距等）固定为图纸默认值，由系统自动计算。

2.2 已更新的模块与逻辑：
    - `CADBoard/utils/drawing_recognizer.py`：AI 识别提示词改为只输出 7 个核心参数。
    - `CADBoard/face_overview_dialog.py`：`PIER_COMMON_PARAMS` 限定为 7 个核心参数；`_on_apply` 保持 `系梁根数` 为 int。
    - `CADBoard/bimbase_sync.py`：`ApproachPierComponent` 改为精简参数与圆柱墩柱几何；`_sync_pier_via_generated_code`、`_make_component_by_type` 调用 `normalize_pier_params`。
    - `CADBoard/geometry/faces.py`：面生成函数从精简参数推导细部尺寸，并修复系梁 Z 坐标重复加 `col_h` 的 bug。
    - `CADBoard/utils/ai_executor.py`、`utils/ai_panel.py`、`utils/component_matcher.py`：创建/解析/匹配逻辑统一为精简参数。
    - `CADBoard/utils/generated_component_cache.py`：生成脚本与 `normalize_pier_params` 已按精简参数实现。

2.3 缓存清理：
    - 新增 `clear_all_caches()`，清理范围包括：
      * `cad组件缓存/` 下的生成脚本
      * `CADBoard/**/__pycache__/` 目录
      * `CADBoard/*.log` 日志文件
      * `/tmp` 下 `cadboard_` 前缀的临时目录
    - 工具栏按钮与菜单项均改为"清除所有缓存"，调用 `clear_all_caches()`。

2.4 已提交版本：

3. 技术栈
--------
- 操作系统：Windows
- 宿主平台：BIMBase Python SDK 1.6.x / Python 3.7 embed
- UI 框架：PyQt5 / PyQt6 兼容
- 三维几何：pyp3d
- AI 图纸识别：DashScope Qwen-VL
- 图纸解析：PyMuPDF (fitz)、ezdxf
- 版本控制：Git（main 分支）


4. 本地版本管理
--------------
4.1 未经用户明确确认，不得执行 `git commit`、`git push`、`git reset`、`git rebase` 等任何 Git 变更操作。
4.2 运行时产物不得提交：
    - `cad组件缓存/`（已加入 `.gitignore`）
    - `__pycache__/`、*.pyc
    - `*.log` 日志文件
    - `/tmp` 下 `cadboard_` 前缀临时目录
4.3 提交前应对修改的 Python 文件执行语法检查，例如：
    python -m py_compile CADBoard/board.py CADBoard/bimbase_sync.py ...
