一、我的需求（按对话顺序）
--------------------------
  ① 新增被插板：板上开凹槽阵列，排数可调（1排2排3排），凹槽深度不随排数变，
     不要撑破板。
  ② 新增凸插板（与被插板咬合），配图标和插件按钮；突起排数规则要像凹插板。
  ③ 排数参数不要带 mm 单位；排列间距要带单位（mm）。
  ④ 凸插板不用排数/间距参数（固定单排），并修复凸起悬空问题。
     （他人实测反馈：排列间距为 0 时间距没有显示为 0 → 改为 0=所有排重叠到板中心）
  ⑤ 新增隧道组件，配图标和按钮；配色：除三条线为白色外全部深黑
     （参考桥梁组件库路面及交通标线的 .color(0,0,0,1)）。
  ⑥ 隧道侧墩与边弧重叠：先试"只显示边弧"（布尔减），后决定保留重叠不处理
     （按弧线建模方案已验证可行，代码注释留有回退线索）。
  ⑦ 铁路封闭网（1）：两点布置太卡要提速；约束：最好样子不变只优化代码结构，
     实在不行横纵杆减半。
  ⑧ 封闭网中间立柱：原来只有首尾两根，改成每三个网格一根，柱子要在网片交界处，
     末尾不要和端柱挤在一起。


二、最终状态（全部实测通过 2026-09-07）
--------------------------------------
  1. 被插板.py（凹插板）：凹槽长度/宽度/深度/间隔/凹槽排数/排列间距全参数化；
     多排沿宽度均布居中；开口超界按比例整体缩放防撑破（宽≤排距、长≤间隔），

  2. 凸插板.py（突插板）：固定单排居中；凸起顶面贴合板底（放置基准 -凸起高度，
     修复早期按 -板高 导致的悬空）；类名从"被插板"改为"凸插板"消除序列化冲突；
     文件名去尾部空格。
  3. 隧道.py：二次衬砌拱圈+仰拱+双侧检修道块+路面+三条白色设备带；
     本体 color(0,0,0,1) 深黑、设备带 color(1,1,1,1) 白色；侧墩与边弧重叠保留。
  4. 铁路封闭网（1）.py（Array 实例化版，类名 铁路封闭网_1）：
     - 所有重复几何（网片横竖杆、整排网片、顶部网格杆、中间立柱）改用

       两点布置不再卡顿，外观零变化（横纵杆不减半）

       双面耳板，位置严格落在网片交界处（2k + N×块宽），
       与端柱距离不足一块网宽时自动跳过
  5. 图标：Picture/_generate_icons.py 统一生成（被插板蓝/凸插板棕/隧道深黑白线/
     封闭网（1）蓝）；组件成品.pyplugin 注册 6 个按钮，路径全量校验通过。


三、关键技术细节与教训
----------------------
  1. Array 实例化是 pyp3d 官方性能方案：参考 BIMBase 内置组件库
     （D:\BIMBase\...\BFAComponentLib\场布内置\...\安全围栏样式一两点布置.py），
     Array.parts 存变换矩阵、ontology 存基准几何，内核按实例渲染。
  2. Array 上色坑（新规则）：Combine(...).color() 递归染色染不到 Array 壳里的
     基准几何——必须先 .color() 再进 Array。是 docs/04「先上色后 Combine」的延伸。
  3. 排数/数量类参数用字符串型 Attr（避免面板显示"3mm"），内部容错解析；
     长度/间距类用数字型（面板带 mm 单位正是所需）。
  4. 布尔减不稳定的三层处理：try/except 退化（被插板）→ 按弧线精确建模替代
     （隧道侧墩验证过）→ 用户拍板保留重叠（最终决策）。
  5. 类名必须与文件名一一对应且全局唯一（BIMBase 按类名序列化）；
     文件名不要带尾部空格（pyplugin 配置和加载都容易出问题）。
  6. 防撑破缩放的不变式：开口（长×宽）按比例缩放，深度/高度不参与；
     凹插板深度钳板厚，凸插板高度贴板底。
