四、技术要点（务必记住）
------------------------
  1. 删除 API 存在！delete_one_entity 按实体删即可，删参数化组件实体即可移除。
  2. 删除后必须校验：_count_entities() 前后对比，或 entityid_isvaid 复查。
  3. 注册表清理：unregister(instance_key) 直接传活对象；按 entity_id 删记录需
     用 _key_str 转换后与 record['entity_id'] 比对。
  4. 窗口路由测试不必建真实窗口：AIModelingWindow._execute_local_delete(fake_self, ...)
     用 SimpleNamespace 式假 self + mock.patch 模块级函数即可离线跑。
  5. 汉字数字在 parse() 入口统一转换后，所有依赖字面量"一个"的判断都要改正则。
