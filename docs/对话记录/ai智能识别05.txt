------------------------------------------
原始要求：
  ① 画板能画组件元素，可手动同步至 BIMBase，也可通过 AI 交流同步至 BIMBase，
     也可以从 BIMBase 读组件同步回画板；
  ② 通过 AI 对话操作/删除画板元素或 BIMBase 组件。重点是对 BIMBase：
     自动布置、沿轴布置、相对布置，并新增"移动布置"（用 pyp3d trans 函数）。
     AI 对画板只需：改元素/组件参数、删除、在指定位置画基本元素；

     引桥桥墩(dwg)；

  - 圆球保持现状不补（无组件关联/三视图模板）；
  - 移动布置三种都要：相对移动、移动到绝对坐标、画板元素也能移动；
  - 识图本轮低优先级，不动核心；
  - 画板选中普通 2D 图形时 AI 同步：明确提示不可同步，不假成功；
  - 相对布置语义：新组件放置点 = 选中组件【放置原点】+ 方向偏移

三、技术栈与关键实现（速查，新对话必读）
----------------------------------------
【指令路由链】
  ai_panel._send_message → AI优先fast-path / _should_use_local
    → _prefer_modeling 判定（3D组件词优先建模链路，"画板"字样/纯2D词走画板）
    → 画板：LocalCommandParser → ai_executor.AICommandExecutor
    → 建模：ai_modeling_bridge.parse/execute → ai_modeling_launcher
      .execute_modeling_action → 屏外(-32000,-32000)临时 AIModelingWindow
      → ai_window._execute_local_create/copy/modify/delete/move
  临时窗口执行前后快照/恢复 sys.path 与 sys.modules（bimbase_sync 同名冲突
  高危区，见 CADBoard/docs/报错处理记录.md #8/#10）。

【move 契约】（parser 与执行端严格遵守）
  {'action':'move', 'target':{...}, 'component_type':...|None,
   'move': {'mode':'relative','dx','dy','dz'}      # mm
       或 {'mode':'absolute','x','y','z'}}         # mm
  执行：python_transformation_operation(entityid, trans(dx,dy,dz))；
  绝对移动先读当前位置算增量；成功后更新注册表 placement。
  "位置不变/不要移动"是 modify 语境，不入 move。

【pyp3d 关键 API】（BIMBase 2025，SDK 源码在 D:\BIMBASE\BIMBase建模软件 2025\
  PythonScript\python-3.7.9-embed-amd64\Lib\site-packages\pyp3d\）
  - trans(x,y,z) ≡ translate ≡ translation → GeTransform；rotate 角度用弧度；
  - python_transformation_operation(entityid, GeTransform) 移动已放置实体；
  - place_to / create_geometry / place（交互）；get_place_to_entityId()；
  - get_selected_entity_ids / get_selected_instance_keys（get_selections 不存在）；
  - delete_one_entity（主）/ delete_data_bydatakey（兜底）；
  - delete/move/modify 成功判据 = API 无异常；实体计数口径不稳定
    （引桥桥墩=盖梁+双墩柱+系梁多个子实体，"新增5个实体"是正常的）。
  - 组件放置首选"烘焙偏移进 attrs + create_geometry(translate(0,0,0))"。

【位置读取的两个变换键】（本轮实测+docs/05 定论）
  - \a_transformation：数据级，放置时烘焙，移动后不更新；
  - \aGraphicElement::m_transform：实体级，移动后才是实际位置；
  - 读取规则：m_transform 优先（恒等不覆盖非零已有值），\a_transformation 兜底，
    再兜底 偏移X/Y/Z attrs；统一"放置原点"基准。
  - 移动后回写 偏移X/Y/Z attrs 是死路（内核 replace() 会冲掉，docs/05 实测），
    靠 m_transform 读取 + 注册表同步覆盖所有读取路径。

【解析器要点】（AI_Modeling/ai_modeling/command_parser.py）
  - 汉字数字 parse() 入口统一转换；坐标语境支持三段连读（五百二百一百）；
  - 显式轴向优先于方向词："Y方向500/y轴方向500/向x轴负方向500" > "上方500"；
  - 距离正则有 (?!\s*个) 负向环视，"布置一个"的"1个"不会被误吞为距离；
  - 单位默认 mm，支持逐个后缀与"单位用米"整体声明；
  - "三棱柱"映射 triangular_prism（=直角三棱柱）。

【已知限制（接受的现状）】
  - 读回是扫描式导入，不能精确匹配单个组件；BIMBase 来源组件重新同步只新建
    不替换，旧组件需手动删除；
  - 球体：能画能同步，无组件关联/三视图模板（用户明确不补）；
  - "画一个正方体"默认走 BIMBase 建模链路；画板画需说"在画板画…"；
  - m_transform 在实体带旋转/缩放时的平移语义未验证（移动链路只产纯平移）；
  - 中文数字坐标仅支持三段连读，两段歧义报错。
