一、我的需求

      bottom = translate(-dw/2, -L/2, 0)      * scale(dw, L, dh)  * Cube()
      web    = translate(-tw/2, -L/2, dh)     * scale(tw, L, web_h) * Cube()
      flange = translate(-fw/2, -L/2, dh+web_h) * scale(fw, L, fh) * Cube()
    横隔板预留孔、墩柱圆柱也统一为 Z 从 0 起算。
  - face_projection.py 已同步新增 4 个组件的面信息（bottom/web_side/

三、技术栈与关键实现
--------------------

3.1 环境
  - BIMBase Plugin SDK 1.6.2，pyp3d（BIMBase 内置 python-3.7.9-embed-amd64）
  - 开发机 Python：D:\zengpython3.13.2（装了 ultralytics 8.4.58、torch cpu、
    opencv-python、PyQt5、python-docx、Pillow、pywin32）
  - 训练设备：CPU（无 GPU）

3.2 数据提取（关键点）
  - .docx/.docm 本质是 ZIP，用 zipfile 读 word/media/* 出图，
    解析 word/document.xml 的 <w:drawing>/<a:blip r:embed> 关联题注，
    比 Word COM 稳定（COM 会遇到宏安全、'文件已被删除'、进程残留）。

3.3 模型训练（关键点）
  - YOLO 数据集标准结构：images/{train,val} + labels/{train,val} + data.yaml。
  - data.yaml 的 path 必须是实际目录（人工标注数据集00 的 data.yaml 路径
    与实际文件夹名不一致，已重新生成）。
  - fine-tune 从上一轮 best.pt 继续会经历“先降后升”；
    不同验证集之间 mAP 不可直接比较，必须在同一验证集评估对比。
  - 露筋(12框)、蜂窝麻面(7框)样本太少，模型还学不会，需继续补标。

3.4 BIMBase 放置（关键点）
  - place() 会进入手动布置工具；自动放置要用 _PlaceToDirect
    （create_component + 设置 TRANSFORMATION + UnifiedFunction create）。
  - 组件类必须在模块级别定义，BIMBase 才能序列化。
  - Cube() 原点是角点；球体用 Sphere()；颜色用 .color(r,g,b,a)（0~1）。

3.5 对话框记录结构（关键点）
  - self.records 为 dict 列表，字段：id/photo/marked_image/component/
    component_no/disease/severity/position/size/bbox/note/time/
    ai_diagnosed/ai_diagnosis。
  - AI 非病害判定：ai_diagnosis 或 note 含“疑似正常/正常纹理/正常标记/
    文字标记/无明显病害/非真实病害/非病害”等关键词。
