# SDK 接口指南（P1 按需加载）

## 任务边界

此分类是 pyp3d API 参考文档集合。每个文档描述一个或一组 SDK 函数。
**严禁凭经验猜测 pyp3d API 参数** — 使用任何 SDK 前必须加载对应文档。

子目录：
- `geometric_interface/` — 几何体创建和属性接口（15 篇）
- `test/` — pyp3d 底层 SDK 参考（9 篇，仅供深入查阅）

## 使用规则

1. 根据代码中需要使用的 SDK 函数，按需加载对应文档
2. 不要一次性加载全部文档 — 只加载当前任务需要的
3. 文档中的参数格式和约束是权威来源，必须严格遵守
4. 底层参考（test/）仅在需要了解 SDK 内部行为时查阅
