name: Combine
description: 将多个几何体组合成一个组，不处理重叠部分，保留原有属性
---


## 功能说明

将多个独立的几何体组合成一个逻辑组进行统一操作，但不进行布尔融合。适用于需要保持各几何体独立性的整体变换或管理场景。

**接口形式：**

```python
TestCombine = combine(testa, testb)
```

**使用场景：**

- 将多个独立的几何体组合成一个逻辑组进行统一操作
- 需要保持各几何体独立性的同时进行整体变换或管理
- 当不需要进行布尔运算的几何融合时使用

## 接口用例

**组合两个几何体：**

```python
combined = combine(geometryA, geometryB)
```

**组合多个几何体并进行统一变换：**

```python
group = combine(part1, part2, part3)
# 可对整个 group 进行旋转、平移等操作
```

## 注意事项

- **非破坏性操作：** 不会修改原始几何体的形状或结构
- **属性保留：** 保留各几何体原有的颜色和其他属性信息
- **独立性保持：** 组合后的几何体仍保持各自的独立性，不会融合重叠部分
- **便于管理：** 适合对多个相关几何体进行统一的变换或操作
