name: Loft

## 功能说明

Loft 函数可装载至少 2 个截面 Section，根据装填顺序依次连接扫掠形成复杂曲面或实体。

**接口形式：**

```python
Loft(section1, section2, ..., sectionN)
```
## 防退化警告（必读）

- 用于 Loft 时：每个 Section 必须通过 translate(x,y,z)或rotate 在空间上分离，否则会退化为平面。

## 核心概念（必须理解）

| 概念              | 说明                                            |
| --------------- | --------------------------------------------- |
| **截面 Section**  | Loft 的输入单元，至少需要 2 个；确保参与放样的截面不共面，至少有一个维度不同；Type 约束为二维元素集合            |
| **截面装填顺序**      | 决定扫掠路径：从起始到终止依次连接                             |
| **类型一致性**       | 平面 A、B 中线/点/弧数量必须一致，不可混用开放/封闭或 Arc/Line       |
| **融合规则（pyp3d）** | - 单闭合线型按起点终点与比例做融合- 非单闭合时从各自起点开始一一对应，剩余轮廓对应终点 |

## 关键约束（代码级）

### 1. Type 约束：Section 的元素与其内部端点全部是二维（Vec2）

- Line 中不得出现 Vec3
- Arc 行为：弧线会自动补全为所在平面上的弓形，必须当作弧段参与对应
- **禁止 Vec3**：任意位置传入 Vec3 都应直接判错

### 2. 截面方向一致性

所有截面曲线必须具有相同的方向（顺时针或逆时针）。

```python
# 代码要点
- 在数据层面明确"每条截面曲线的方向"并统一<br>- 线段与弧段有起点/终点，方向改变对应关系<br>- Section 内相邻元素首尾相接：前一个终点=后一个起点，否则断裂 |
```

### 3. 开闭属性一致性

```python
# 约束与建议
- 允许开放或封闭，但所有 Section 必须保持一致（不混用）<br>- 封闭要求：首尾连接闭合，最后一个元素终点回到第一个元素起点 |
```

### 4. Arc 方向规则

- `Arc(angle)` 创建单位圆弧（半径 1），需 scale(r) 缩放- 默认从 X 轴起点逆时针绘制**必须显式指定**：不指定则方向与预期不一致导致截面错误 |

## 截面规划策略

### 数量规划

| 场景   | 推荐数量      |
| ---- | --------- |
| 最少要求 | 2         |
| 简单形状 | 2–5       |
| 复杂形状 | 7–15      |
| 过多警告 | >20（波动风险） |

**选择建议：**

1. 先用尽量少的截面跑通形状逻辑，再加截面2. 波动明显时优先检查质量与对应关系，而非加截面

### 位置规划（必须放截面的关键位置）

- 起始和终止位置
- 最大/最小截面（极值点）
- 曲率变化点
- 设计的关键控制位

**布局建议：**

1. 每个截面起点大致对齐2. 空间分布尽量"均匀"，剧烈区域加密、平缓区域稀疏

## 基于 pyp3d 的实现流程

### Step 1：建立截面数据模型

```python
# 表达为有序几何片段列表，记录类型：点（Vec2）、线段（Line, Vec2 端点）、弧段（Arc）
```

**最低要求：**

- 每个 Section 有相同长度的片段序列- 同一索引位置的片段类型一致（线对线、弧对弧、点对点）

### Step 2：生成多个截面（用变换保证对应）

```python
# 推荐做法
基准截面 A = Section([...])  # 片段稳定、方向明确、接缝明确
截面 B = rotation(θ) * scale(r) * translate(dx,dy) * 基准截面 A
截面 C = ... # ...
```

### Step 3：按顺序装填截面并执行 Loft

```python
Loft(*sections)  # 至少 2 个 Section，顺序决定扫掠路径（起始→终止）
# 可通过 translate/rotate/scale 变换布置同一基准截面到不同位置
```

### Step 4：失败时的修正优先级

| 现象          | 优先检查                           |
| ----------- | ------------------------------ |
| 扭转（Twist）   | 1) 方向一致性 → 2) 封闭接缝对齐 → 3) 重建分段 |
| 波动/起伏（Wavy） | 截面分布合理性 → 对应关系稳定性              |
| 接缝跳变        | 不同截面接缝点位置不一致，需统一后重新 Loft       |

**修正优先级：**

1. 方向一致性 → 2. 封闭曲线接缝对齐 → 3. 开闭属性一致 → 4. 分段/对应关系 → 5. 数量与位置合理性

## 质量检查 Checklist（逐项确认）

```markdown
- [ ] 所有截面曲线方向一致（顺/逆时针统一）
- [ ] 所有截面曲线开闭属性一致（不混用开放/封闭）
- [ ] 封闭截面接缝点位置一致/相近（起点对齐）
- [ ] 截面分段结构一致（线对线、弧对弧、点对点）
- [ ] 平面 A、B 中线/点/弧数量一致（无"某截面有弧另一截面无弧"）
- [ ] Section 仅装填二维元素（Vec2/Line/Arc），不传 Vec3
- [ ] Line 的端点仅使用 Vec2（Line 中不得出现 Vec3）
- [ ] 各 Section 内相邻元素首尾连通（前一终点=后一起点）
- [ ] Arc 方向符合预期（默认 X 轴起点逆时针，必要时显式指定）
- [ ] 截面装填顺序正确（起点 → 终点扫掠路径）
- [ ] 关键位置有截面（起止、极值、曲率变化）
```

## 常见问题与快速排查

### A. 放样扭转（Twist）

**最可能原因：**

1. 截面方向不一致 2. 封闭接缝不对齐 3. 分段/对应关系混乱

**处理顺序：**
统一方向 → 对齐接缝（封闭）→ 重建/重分段让对应一致

### B. 曲面波动/起伏不平（Wavy）

**最可能原因：**

1. 截面过多（>20）或分布不合理2. 曲线抖动、控制点不均匀3. 对应关系不稳定导致局部插值异常

**处理建议：**

- 减少冗余，保留关键截面- 在形态变化处放截面，平缓处稀疏- 优先提升截面质量与对应关系

### C. 接缝线跳变/不连续（封闭放样）

\*\*原因：\*\*不同截面的接缝点位置不一致\*\*处理：\*\*将所有截面接缝移动到同一语义位置后重新 Loft

### D. 放样失败/自交

**最可能原因：**

1. 截面变化剧烈或相互交叠2. 对应关系不一致导致局部反转

**处理建议：**

- 在剧烈变化区增加"过渡截面"
- 调整位置避免穿插，重建时保证分段与接缝/方向一致

## 接口用例

### 示例 1：圆弧放样（3 个截面）

```python
# 描述基准截面（单位圆缩放为直径 200）
testarc = Section(scale(100, 100) * Arc(2 * pi))

# 放样：起点→中点→终点，方向一致、数量对应
testloft_arc = Loft(
    testarc,
    scale(0.5) * translate(0, 0, 100) * testarc,
    rotation(0.5 * pi) * translate(0, 0, 300) * scale(0.5) * testarc
)
```

### 示例 2：复杂截面放样（混合线弧点）

```python
# 描述截面：起点→弧段→终点→返回起点
section = Section(
    Vec2(100, -100),      # 起点
    scale(100) * Arc(0.5*pi),  # 上半圆
    Vec2(-100, 100),     # 终点（弧结束）
    Vec2(-100, -100)     # 闭合回起点（形成半圆环截面）
)

# 放样：通过变换保持对应关系一致
testloft = Loft(
    section,
    scale(0.5) * translate(0, 0, 100) * section,      # 缩放平移
    rotation(0.5*pi) * translate(40, 0, 300) * section  # 旋转位移
)
```

## 注意事项

| 约束类型      | 说明                                        |
| --------- | ----------------------------------------- |
| **数量约束**  | 最少需要两个截面才能进行放样操作                          |
| **结构对应**  | 所有截面的线、弧数量和位置必须一一对应                       |
| **严禁混用**  | 不可出现平面 A/B 中线/点/弧数量不一致的情况                 |
| **一致性要求** | 不可出现平面 A 中有弧线而平面 B 中无弧线等情况                |
| **变换兼容**  | 可将平面 A 旋转、缩放、平移得到平面 B，但拓扑结构需保持一致（弧对弧、线对线） |

## 性能提示

- Arc 默认从 X 轴起点逆时针绘制，**必须显式指定**角度或起点/终点范围- 封闭截面接缝点位置应接近但不必绝对相等（容差内即可）- 超过 20 个截面可能导致数值波动，建议用关键截面 + 过渡截面替代均匀分布
