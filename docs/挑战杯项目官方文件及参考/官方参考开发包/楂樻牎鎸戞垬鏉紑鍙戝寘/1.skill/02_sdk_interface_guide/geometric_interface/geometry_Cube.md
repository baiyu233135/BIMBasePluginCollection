---
name: Cube
description: 创建单位立方体或指定尺寸的立方体
---


## 功能说明

创建棱长为 1 的单位立方体，或通过缩放操作创建指定长宽高的立方体。

**接口形式：**

```python
# 创建棱长为 1 的单位立方体
testcube = Cube()

# 创建长宽高为 L、W、H 的立方体
testcube = scale(L, W, H) * Cube()
```

## 接口用例

**创建单位立方体：**

```python
cube = Cube()
```

**创建自定义尺寸的立方体：**

```python
# 创建一个 100x200x50 的长方体
box = scale(100, 200, 50) * Cube()
```

## 注意事项

- **单位立方体：** `Cube()` 默认创建一个中心在原点的单位立方体
- **缩放顺序：** 缩放操作应在使用`scale()` 函数后作用于 `Cube()`
- **坐标系：** 基于右手坐标系构建
