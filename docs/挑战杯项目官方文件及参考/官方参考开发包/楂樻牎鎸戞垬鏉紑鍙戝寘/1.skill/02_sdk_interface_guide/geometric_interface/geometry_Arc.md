## 功能说明

创建单位圆弧或基于三点定义的圆弧。支持创建标准的单位圆（半径为 1）或根据指定弧度绘制部分圆弧，也可通过空间中的三个点精确构建圆弧路径。

**函数签名：**

```python
Arc(angle: float) -> ArcObject
Arc(startPoint: Vec3, midPoint: Vec3, endPoint: Vec3) -> ArcObject
```

**参数说明：**

- `angle` (float): 圆弧的弧度值，用于定义圆弧的跨度
- `startPoint` (Vec3): 圆弧的起始点坐标
- `midPoint` (Vec3): 圆弧的中间点坐标
- `endPoint` (Vec3): 圆弧的结束点坐标

## 接口用例

**创建完整的单位圆：**

```python
arc = Arc(pi*2)
```

**创建 3/4 圆弧：**

```python
arc = Arc(pi*1.5)
```

**基于三点创建圆弧：**

```python
arc = Arc(Vec3(0,0,0), Vec3(100,100,0), Vec3(0,200,0))
```

## 注意事项

- **默认基准：** 当基于角度创建时，默认圆心位于原点 (0,0,0)，绘制起点位于 X 轴上的 (1,0,0)
- **绘制方向：** 遵循右手定则，默认沿逆时针方向绘制
- **坐标系统：** 使用右手坐标系进行圆弧绘制
- **参数验证：** 确保三点不共线，否则无法定义有效的圆弧
