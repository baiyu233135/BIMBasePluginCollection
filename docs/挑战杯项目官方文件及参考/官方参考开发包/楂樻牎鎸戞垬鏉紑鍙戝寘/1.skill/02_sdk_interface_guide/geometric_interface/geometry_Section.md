name: Section
description: 装填二维几何体作为放样截面
---

## 功能说明

用于将二维几何体（Vec2、Line、Arc 等）依此装填为放样截面，供 Loft、Sweep 函数使用。

**接口形式：**

```python
Section(point1, geometry1, point2, geometry2, ...)
```

## 接口用例

**创建包含点和弧线的截面：**

```python
testsection = Section(Vec2(100, -100), scale(100) * Arc(0.5*pi), Vec2(-100, 100))
```

## 注意事项

- **禁止 Vec3：** 不可传入 Vec3 类型的坐标，仅支持 Vec2 二维点
- **弧线自动补全：** 弧线会自动补全为弓形
- **截面一致性要求：** 多个截面之间需保持"弧对弧，线对线，点对点"的结构对应关系
- **适用于放样：** Section 主要用于 Loft 函数的截面定义
- **支持截面布尔：** 截面与截面之间可以进行布尔减、布尔交操作
- **截面装填顺序：** Loft 会根据你装填截面的顺序，依次把截面连接扫掠，形成完整几何体。
- **截面平面说明：** 每个截面在创建时默认位于XOY平面。需要额外旋转、位移操作才能将其放置在其他平面上。
