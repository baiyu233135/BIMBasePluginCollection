## 功能说明

`.color()` 方法用于设置几何体的颜色和透明度（不透明度）。使用 RGB 颜色模型和 Alpha 通道控制。

**函数签名：**

```python
.color(R, G, B, Alpha)
```

**参数说明：**

| 参数 | 类型 | 范围 | 说明 |
|------|------|------|------|
| `R` | float | 0.0 - 1.0 | 红色分量 |
| `G` | float | 0.0 - 1.0 | 绿色分量 |
| `B` | float | 0.0 - 1.0 | 蓝色分量 |
| `Alpha` | float | 0.0 - 1.0 | 不透明度 |

**RGB 颜色模型示例：**

| 颜色 | R | G | B | 代码 |
|------|---|---|---|------|
| 白色 | 1 | 1 | 1 | `.color(1, 1, 1, 1)` |
| 黑色 | 0 | 0 | 0 | `.color(0, 0, 0, 1)` |
| 红色 | 1 | 0 | 0 | `.color(1, 0, 0, 1)` |
| 绿色 | 0 | 1 | 0 | `.color(0, 1, 0, 1)` |
| 蓝色 | 0 | 0 | 1 | `.color(0, 0, 1, 1)` |
| 黄色 | 1 | 1 | 0 | `.color(1, 1, 0, 1)` |

## 接口用例

**基础颜色设置：**

```python
# 红色圆锥（完全不透明）
cone = Cone(Vec3(10000,0,0), Vec3(10000,0,2000), 1000, 1000).color(1, 0, 0, 1)

# 蓝色直线
line = Line(Vec2(0,0), Vec2(100,0), Vec2(0,100), Vec2(100,100)).color(0, 0, 1, 1)

# 黄色方块（半透明）
box = Box(...).color(1, 1, 0, 0.5)
```

**透明度控制：**

```python
# 完全不透明
solid = scale(100) * Cube().color(1, 0, 0, 1.0)

# 半透明
semi_transparent = scale(100) * Cube().color(1, 0, 0, 0.5)

# 高度透明
very_transparent = scale(100) * Cube().color(1, 0, 0, 0.1)
```

**链式调用：**

```python
result = (
    translate(1000, 0, 0) * 
    rotation(math.pi / 4) * 
    scale(100, 50, 30) * 
    Cube()
    .color(0.2, 0.6, 0.8, 1)
)
```

## 注意事项

- **取值范围：** 所有参数必须在 0 到 1 之间，使用小数格式
- **透明度说明：** Alpha=1.0 完全不透明，0.5 半透明，0.0 完全透明
- **链式调用：** 通常在几何体创建后链式调用 `.color()`
- **布尔运算后重设：** 布尔运算会抹除颜色，需重新设置
- **组合保留颜色：** combine 不会改变成员颜色
- **默认颜色：** 不调用 `.color()` 时使用白色 (1, 1, 1, 1)
