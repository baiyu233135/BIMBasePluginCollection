---
name: Line
description: 创建二维或三维线段
---


## 功能说明

支持创建二维线和三维线，通过起点、中间点和终点定义线段路径。

**接口形式：**

```python
# 三维线（使用 Vec3）
testLine3D = Line(Vec3(0,0,0), Vec3(100,0,25), Vec3(0,100,50))

# 二维线（使用 Vec2）
testLine2D = Line(Vec2(0,0), Vec2(100,0), Vec2(0,100))
```

## 接口用例

**创建三维线段：**

```python
line3D = Line(Vec3(0,0,0), Vec3(100,0,25), Vec3(0,100,50))
```

**创建二维线段：**

```python
line2D = Line(Vec2(0,0), Vec2(100,0), Vec2(0,100))
```

## 注意事项

- **类型一致性：** Vec3 和 Vec2 不能混用，需保持一致性
- **坐标系：** 基于右手坐标系构建
- **三点定义：** 通过起点、中间点、终点三个点定义线的形状
