# 01 - 项目总览

## 项目背景

本项目是个人在学习和使用 **BIMBase** 过程中开发的 Python 插件集合，目标是实现参数化建模、AI 辅助建模、CAD 绘图、桥梁病害识别等土木工程数字化能力。

## 技术栈

- **BIMBase Python SDK 1.6.x**
- **Python 3.7 / 3.x**（BIMBase 内置 embed Python 或系统 Python）
- **PyQt5 / PyQt6**：插件界面
- **pyp3d**：BIMBase 几何建模接口
- **OpenPyXL / pandas**：Excel 参数读取
- **DeepSeek API / 百度语音**：AI 对话与语音输入
- **YOLOv8 / OpenCV**：桥梁病害识别

## 功能模块

### 1. AI 建模

包含两代实现：

- **`AI建模/`**：早期版本，通过 `.pyplugin` 在 BIMBase 面板中提供按钮，打开 ChatGLM 网页，用户复制代码后由脚本运行。
- **`AI_Modeling/`**：新版独立 AI 建模助手，集成 DeepSeek 流式对话、本地中文命令解析、自动放置几何体、阵列、沿路线布置等功能。

### 2. CADBoard

包含三个方向：

1. **CAD 画板**：2D/3D 绘图、编辑、导入导出 DWG/PDF。
2. **AI 智能建模**：调用 `AI_Modeling` 或内嵌 AI 面板，将自然语言转换为参数化构件。
3. **自动配置环境**：一键配置 VSCode、Python、pyp3d、依赖包、ODA 转换器。

### 3. 桥梁病害识别

已从 CADBoard 中独立拆分的模块，基于 YOLOv8 检测裂缝、剥落、露筋等病害，生成 Word 报告并投影到 BIMBase。

入口由 CADBoard 面板按钮转发调用。

### 4. 建模插件库

通过 Excel 表格参数驱动建模：

- **曲线建模**：读取平面/竖直要素表生成三维空间路线。
- **圆柱建模**：沿路线批量生成圆柱（桥墩桩基等）。

### 5. 桥梁组件库

预制的桥梁参数化结构：

- **上部结构**：T 梁、箱梁、工字钢混凝土组合梁、斜拉索、主塔等。
- **下部结构**：柱式桥墩、桩基承台、扩大基础、薄壁墩、桥台等。
- **附属设施**：防撞护栏、波形护栏、路面及交通标线等。
- **工具**：承台与桩基清单、STL 导入导出、Lumion 渲染、3D 打印切片。

### 6. 组件测试

基础几何体测试组件，用于验证 CAD 画板和 AI 智能建模的组件创建流程：

- 正方体、长方体、圆柱、直角三棱柱、工字钢混凝土组合梁。
