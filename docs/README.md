## 使用建议

- 新人上手顺序：`01 → 03 → 各模块 README → 02`；
- 排查问题先查 `99_常见问题与调试.md`，再查对应模块 `docs/报错处理记录.md`；
- 赛事材料以最新版本号为准，旧版本仅留档。
