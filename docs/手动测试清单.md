# 手动测试清单

> 本轮改动（AI 布置链路修复 + 新增移动布置 + 双向同步修复）无法在本机自动验证（依赖 BIMBase GUI / pyp3d 运行时）。
> 请在 BIMBase V1.6.x 中打开「速构智维 → CAD画板」，按本清单逐项验证。
> 每项失败时，把对应日志内容发回来定位：
> - `CADBoard/ai_modeling_launcher.log`（建模指令代理执行）
> - `CADBoard/bimbase_sync_debug.log`（画板同步 + AI 面板路由 [AI_PANEL]/[AI_BRIDGE]）
> - `AI_Modeling/ai_modeling_debug.log`（AI_Modeling 窗口内部执行）

## 一、AI 对话 → BIMBase 布置（本轮核心修复）

在画板右侧 AI 面板逐条输入：

| # | 输入指令 | 预期结果 |
|---|---|---|
| 1 | `在(0,0,0)生成一个半径50高100的圆柱` | BIMBase 原点出现圆柱，面板回复 ✅（不再误报"未检测到新实体"） |
| 2 | `在(2000,0,0)创建一个边长100的正方体` | BIMBase 出现正方体 |
| 3 | `在(4000,0,0)生成一个三棱柱` | BIMBase 出现直角三棱柱（三棱柱=直角三棱柱） |
| 4 | `沿X轴每隔500布置5个圆柱` | 5 个圆柱沿 X 等距排开（沿轴布置） |
| 5 | 先在 BIMBase 选中圆柱，再输入 `在选中组件上方500生成一个正方体` | 正方体出现在圆柱上方 500mm（相对布置） |
| 6 | `从(0,0,0)到(5000,0,0)每隔1000放一个直角三棱柱` | 沿直线布置成功，且棱柱方向与路线切向对齐（本轮修复点，以前不旋转） |
