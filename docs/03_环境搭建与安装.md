# 03 - 环境搭建与安装

## 1. 安装 BIMBase

- 下载并安装 **BIMBase V1.6.x**。
- 默认安装路径可能为 `C:\ProgramData\BIMBase\` 或 `D:\BIMBASE\`，具体以实际安装为准。

## 2. 安装 VSCode

- 下载 [Visual Studio Code](https://code.visualstudio.com/)。
- 安装 Python 扩展，用于代码高亮、补全、调试。

## 3. 配置 Python 解释器

BIMBase 内置了 embed Python，通常位于：

```
C:\ProgramData\BIMBase\python-3.7.9-embed-amd64\python.exe
```

或在 `D:\BIMBASE\...` 下。

在 VSCode 中按 `Ctrl+Shift+P`，选择 **Python: Select Interpreter**，指向上述解释器。

## 4. 配置 pyp3d 补全路径

为了让 VSCode 识别 `pyp3d` 等 BIMBase 接口，需要在 `settings.json` 中添加：

```json
{
    "python.analysis.extraPaths": [
        "C:/ProgramData/BIMBase/python-3.7.9-embed-amd64/Lib/site-packages",
        "C:/ProgramData/BIMBase/.../pyp3d"
    ]
}
```

具体路径可通过运行 `CADBoard/setup_env.py` 自动检测。

## 5. 安装依赖包

部分插件依赖以下 Python 包：

```bash
python -m pip install PyQt5 PyQt6 ezdxf PyMuPDF python-docx openpyxl pandas requests numpy opencv-python ultralytics
```

如果使用 BIMBase 内置 embed Python，可能需要先安装 pip：

```bash
python get-pip.py
```

CADBoard 提供了自动环境配置脚本：

```bash
python CADBoard/setup_env.py
```

## 6. 配置 API Key

AI 相关功能需要配置 API Key：

- **DeepSeek**：编辑 `AI_Modeling/ai_modeling_config.json`，填写 `api_key`。
- **百度语音**：在同一配置文件中填写 `baidu_api_key` 和 `baidu_secret_key`。
- **ChatGLM**：旧版 `AI建模/` 通过浏览器打开 ChatGLM 智能体页面，无需本地 Key。

## 7. 加载插件

将项目目录（或其中的 `.pyplugin` 文件）放入 BIMBase 插件加载路径：

```
C:\ProgramData\PKPM\BIMBase\Plugins\Pro\V1.6\pythonplugin
```

启动 BIMBase 后，在插件面板中即可看到对应按钮。

## 8. 常见问题

- **找不到 pyp3d**：检查 Python 解释器是否指向 BIMBase 内置 Python。
- **插件按钮不显示**：确认 `.pyplugin` 文件位于 BIMBase 能扫描到的目录。
- **AI 对话无响应**：检查网络连接和 `api_key` 是否有效。
- **缺少 openpyxl/pandas**：运行对应模块的自动配置脚本或手动 pip 安装。

更多问题请参考 [99_常见问题与调试.md](99_常见问题与调试.md) 及各模块 `docs/报错处理记录.md`。
