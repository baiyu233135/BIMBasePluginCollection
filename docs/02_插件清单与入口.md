# 02 - 插件清单与入口

## 插件文件说明

BIMBase Python 插件通过 `.pyplugin` 文件注册，根目录下共有 8 个插件文件。

| 插件文件 | 插件名 | 版本 | SDK | 入口目录 |
|---|---|---|---|---|
| `AI建模.pyplugin` | AI建模（大语言模型） | 1.0.2 | 1.6.1 | `AI建模/` |
| `速构智维.pyplugin` | 速构智维（原 速构智维） | 1.2.0 | 1.6.2 | `速构智维/` |
| `桥梁组件.pyplugin` | 桥梁组件库 | 1.0.6 | 1.6.2 | `桥梁组件/` |
| `组件测试.pyplugin` | 组件测试 | 1.0.1 | 1.6.2 | `组件测试/` |
| `组件成品.pyplugin` | 组件成品 | 1.0.0 | 1.6.2 | `组件成品/` |
| `隧道病害识别.pyplugin` | 隧道病害识别 | 1.0.0 | 1.6.2 | `隧道病害识别/` |
| `体育馆组件库.pyplugin` | 体育馆组件库 | 1.0.0 | 1.6.2 | `F:\临时\体育馆组件库`（指向工作区外） |
| `常_常泰长江大桥.pyplugin` | 常泰长江大桥 | 1.2.0 | 1.6.2 | `常_常泰长江大桥/` |

> 注意：`常_常泰长江大桥/` 前缀是 PKPM 插件打包工具解压目录的命名规则（插件名首字_插件名），本工作区里它就是常泰长江大桥这套组件的开发目录。旧的 `常泰长江大桥/`、`常泰长江大桥布置/` 已删除，bfa 组件库不再随这套分发（布置全部走脚本点击）。

## 各插件按钮与入口脚本

### 1. AI建模.pyplugin

```xml
Category: AI建模(大语言模型)
├── Panel: 使用说明（请先登录）
│   ├── AI建模 使用说明 → AI建模/代码/功能使用介绍.py
│   └── 登录 大语言模型 → AI建模/代码/打开AI智能体.py
└── Panel: AI建模（先复制代码后运行）
    ├── AI对话 建模入口 → AI建模/代码/打开AI智能体.py
    └── 复制代码 然后运行 → AI建模/代码/代码运行交互.py
```

### 2. 速构智维.pyplugin

```xml
Category: 速构智维
└── Panel: 绘图面板
    ├── CAD画板        → 速构智维/main.py
    ├── 自动配置环境    → 速构智维/setup_env.py
    └── 桥梁病害识别    → 速构智维/bridge_disease_launcher.py（转发到 桥梁病害识别/）
```

> 注意 1：桥梁病害识别功能已独立到 `桥梁病害识别/` 目录，`速构智维/bridge_disease_launcher.py` 仅作为转发入口。
>
> 注意 2：自 1.2.0 起，"AI智能建模"独立按钮已移除，AI_Modeling 的建模能力（创建/复制/修改/删除 3D 组件、阵列、沿路线布置）已并入 CAD 画板内嵌的 AI 助手面板（`utils/ai_panel.py` + `utils/ai_modeling_bridge.py`），在画板右侧 AI 面板中直接输入建模指令即可。`ai_modeling_launcher.py` 保留为面板内部的 3D 命令执行载体。

### 5. 常_常泰长江大桥.pyplugin（bfa 组件库 + 分类按钮）

BfaLibName 为 `常泰长江大桥`，前端完全对齐桥梁组件库：3 个分类大按钮点击后打开左侧组件库面板浏览布置；组件文件按分类放在 `常_常泰长江大桥/常泰长江大桥/{1-上部结构,2-下部结构,3-附属设施}/` 下（.py + .bfa 成对）。铁路封闭网无 .bfa，以直接运行按钮保留，命令必须带库前缀和子文件夹：`常泰长江大桥*//铁路封闭网//铁路封闭网.py`（设置 BfaLibName 后裸文件名无法解析）。

```xml
Category: 常泰长江大桥
├── Panel: 上部结构   → 常泰长江大桥*//1-上部结构（主塔/侧面钢桁架/工字钢梁/斜拉索/支座/自密实混凝土层及隔离层/轨道底座）
├── Panel: 下部结构   → 常泰长江大桥*//2-下部结构（门式桥墩/承台及桩基/扩大基础）
├── Panel: 附属设施   → 常泰长江大桥*//3-附属设施（防撞护栏/新泽西护栏/轨道/接触网/路面及交通标线）
└── Panel: 其他组件
    └── 铁路封闭网 → 常泰长江大桥*//铁路封闭网//铁路封闭网.py
```

> 分发给别人：打包 `常_常泰长江大桥.pyplugin` + `常_常泰长江大桥/` 整个文件夹（可排除 `.vscode/`）。

## AI_Modeling 说明

`AI_Modeling/` 是一个独立的 Python 包，目前**没有**对应的根目录 `.pyplugin` 文件。其建模能力已并入 速构智维 画板的 AI 助手面板：

- 画板 AI 面板通过 `速构智维/utils/ai_modeling_bridge.py` 复用 `AI_Modeling/ai_modeling/command_parser.py` 做本地建模指令解析；
- 命中建模指令后由 `速构智维/ai_modeling_launcher.py` 的 `execute_modeling_action()` 在临时 AI_Modeling 窗口上下文中执行（pyp3d 放置需要该上下文）；
- `AI_Modeling/main.py` 的独立窗口仍可作为脚本单独运行：

```bash
python AI_Modeling/main.py
```
