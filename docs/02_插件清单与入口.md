# 02 - 插件清单与入口

## 插件文件说明

BIMBase Python 插件通过 `.pyplugin` 文件注册，根目录下共有 5 个插件文件。

| 插件文件 | 插件名 | 版本 | SDK | 入口目录 |
|---|---|---|---|---|
| `AI建模.pyplugin` | AI建模（大语言模型） | 1.0.2 | 1.6.1 | `AI建模/` |
| `CADBoard.pyplugin` | 速构智维（原 CADBoard） | 1.2.0 | 1.6.2 | `CADBoard/` |
| `桥梁组件.pyplugin` | 桥梁组件库 | 1.0.6 | 1.6.2 | `桥梁组件/` |
| `组件测试.pyplugin` | 组件测试 | 1.0.1 | 1.6.2 | `组件测试/` |
| `组件成品.pyplugin` | 组件成品 | 1.0.0 | 1.6.2 | `组件成品/` |

## 各插件按钮与入口脚本

### 1. AI建模.pyplugin

```xml
Category: AI建模(大语言模型)
├── Panel: 使用说明（请先登录）
│   ├── AI建模 使用说明 → AI建模/代码/功能使用介绍.py
│   └── 登录 大语言模型 → AI建模/代码/打开AI智能体.py
└── Panel: AI建模（先复制代码后运行）
    ├── AI对话 建模入口 → AI建模/代码/打开AI智能体.py
    └── 复制代码 然后运行 → AI建模/代码/代码运行交互.py
```

### 2. CADBoard.pyplugin

```xml
Category: 速构智维
└── Panel: 绘图面板
    ├── CAD画板        → CADBoard/main.py
    ├── 自动配置环境    → CADBoard/setup_env.py
    └── 桥梁病害识别    → CADBoard/bridge_disease_launcher.py（转发到 桥隧病害识别/）
```

> 注意 1：桥梁病害识别功能已独立到 `桥隧病害识别/` 目录，`CADBoard/bridge_disease_launcher.py` 仅作为转发入口。
>
> 注意 2：自 1.2.0 起，"AI智能建模"独立按钮已移除，AI_Modeling 的建模能力（创建/复制/修改/删除 3D 组件、阵列、沿路线布置）已并入 CAD 画板内嵌的 AI 助手面板（`utils/ai_panel.py` + `utils/ai_modeling_bridge.py`），在画板右侧 AI 面板中直接输入建模指令即可。`ai_modeling_launcher.py` 保留为面板内部的 3D 命令执行载体。

## AI_Modeling 说明

`AI_Modeling/` 是一个独立的 Python 包，目前**没有**对应的根目录 `.pyplugin` 文件。其建模能力已并入 CADBoard 画板的 AI 助手面板：

- 画板 AI 面板通过 `CADBoard/utils/ai_modeling_bridge.py` 复用 `AI_Modeling/ai_modeling/command_parser.py` 做本地建模指令解析；
- 命中建模指令后由 `CADBoard/ai_modeling_launcher.py` 的 `execute_modeling_action()` 在临时 AI_Modeling 窗口上下文中执行（pyp3d 放置需要该上下文）；
- `AI_Modeling/main.py` 的独立窗口仍可作为脚本单独运行：

```bash
python AI_Modeling/main.py
```
