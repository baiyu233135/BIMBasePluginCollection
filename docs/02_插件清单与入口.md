# 02 - 插件清单与入口

## 插件文件说明

BIMBase Python 插件通过 `.pyplugin` 文件注册，根目录下共有 5 个插件文件。

| 插件文件 | 插件名 | 版本 | SDK | 入口目录 |
|---|---|---|---|---|
| `AI建模.pyplugin` | AI建模（大语言模型） | 1.0.2 | 1.6.1 | `AI建模/` |
| `CADBoard.pyplugin` | CADBoard | 1.1.0 | 1.6.2 | `CADBoard/` |
| `建模.pyplugin` | 建模插件库 | 1.0.6 | 1.6.2 | `建模/` |
| `桥梁组件.pyplugin` | 桥梁组件库 | 1.0.6 | 1.6.2 | `桥梁组件/` |
| `组件测试.pyplugin` | 组件测试 | 1.0.0 | 1.6.2 | `组件测试/` |

## 各插件按钮与入口脚本

### 1. AI建模.pyplugin

```xml
Category: AI建模(大语言模型)
├── Panel: 使用说明（请先登录）
│   ├── AI建模 使用说明 → AI建模/代码/功能使用介绍.py
│   └── 登录 大语言模型 → AI建模/代码/打开AI智能体.py
└── Panel: AI建模（先复制代码后运行）
    ├── AI对话 建模入口 → AI建模/代码/打开AI智能体.py
    └── 复制代码 然后运行 → AI建模/代码/代码运行交互.py
```

### 2. CADBoard.pyplugin

```xml
Category: CADBoard
└── Panel: 绘图面板
    ├── CAD画板        → CADBoard/main.py
    ├── 自动配置环境    → CADBoard/setup_env.py
    ├── AI智能建模      → CADBoard/ai_modeling_launcher.py
    └── 桥隧病害识别    → CADBoard/bridge_disease_launcher.py
```

### 3. 建模.pyplugin

```xml
Category: 建模插件库
└── Panel: 建模工具
    ├── 曲线建模        → 建模/quxian.py
    ├── 圆柱建模        → 建模/yuanzhu.py
    └── 自动配置环境    → 建模/环境配置.py
```

### 4. 桥梁组件.pyplugin

```xml
Category: 桥梁组件库
├── Panel: 上部结构    → 桥梁组件/桥梁组件/1-上部结构
├── Panel: 下部结构    → 桥梁组件/桥梁组件/2-下部结构
├── Panel: 附属设施    → 桥梁组件/桥梁组件/3-附属设施
├── Panel: 承台与桩基清单
│   ├── 承台与桩基清单 → 桥梁组件/桥梁组件/承台与桩基清单/承台与桩基清单.py
│   └── 自动配置环境   → 桥梁组件/桥梁组件/承台与桩基清单/自动配置环境.py
├── Panel: 3D打印软件
│   ├── 导入Stl        → 桥梁组件/桥梁组件/Stl插件/导入Stl.py
│   ├── 导出FBX        → 桥梁组件/桥梁组件/Stl插件/仅导出Stl.py
│   ├── 导出FBX并打开切片 → 桥梁组件/桥梁组件/Stl插件/导出Stl.py
│   └── FBX转STL工具   → 桥梁组件/桥梁组件/Stl插件/test_button.py
└── Panel: Lumion渲染
    └── 导入Lumion     → 桥梁组件/桥梁组件/Lumion渲染软件/model.py
```

### 5. 组件测试.pyplugin

```xml
    ├── 直角三棱柱 → 组件测试/直角三棱柱.py
```

## AI_Modeling 说明

`AI_Modeling/` 是一个独立的 Python 包，目前**没有**对应的根目录 `.pyplugin` 文件。它既可以被 CADBoard 的 `ai_modeling_launcher.py` 调用，也可以作为独立脚本运行：

```bash
python AI_Modeling/main.py
```

未来如需在 BIMBase 面板中注册，可复制 `AI建模.pyplugin` 并修改入口指向 `AI_Modeling/main.py`。
