# 速构智维 测试文档

## 测试环境

- BIMBase V1.6.x
- Python 3.7 / 3.x
- PyQt5/PyQt6 已安装
- pyp3d 可用
- 依赖包：ezdxf、PyMuPDF、ultralytics、opencv-python、python-docx

## 测试脚本

速构智维 目录下散落着一些测试脚本，整理如下：

| 文件 | 用途 |
|---|---|
| `test_projection.py` | 测试面投影功能 |
| `test_audio.py` | 测试语音输入 |
| `test_noumenon_replace.py` | 测试实体替换 |
| `box_component_demo.py` | 盒子组件演示 |
| `测试.py` | 综合测试 |

## 功能测试

### 1. CAD画板基础绘图测试

1. 启动 CAD画板（点击“CAD画板”按钮）。
2. 分别测试直线、圆、矩形、多段线命令。
3. 验证图元是否正确显示在画布中。

### 2. 编辑命令测试

1. 绘制一条直线。
2. 选中直线，测试移动、旋转、缩放、删除命令。

### 3. DWG 导入导出测试

1. 准备一个简单 DWG 文件。
2. 使用 CAD画板的导入功能加载 DWG。
3. 验证图元是否正确解析。

### 4. PDF 导入测试

1. 准备一个包含矢量线条的 PDF 文件（如 `测试1.0.pdf`）。
2. 使用 PDF 导入功能。
3. 验证线条是否被正确提取。

### 5. AI 智能建模测试（画板 AI 面板，1.2.0 起）

1. 打开 CAD画板，点击工具栏"AI助手"展开右侧面板。
2. 依次输入以下指令并验证：
   - "放一个半径2高5的圆柱到(0,0,0)" → BIMBase 中生成圆柱（模式指示器显示"🏗️ 建模"），全程不弹 AI 建模窗口。
   - "在500.200.100的地方布置一个桥墩" → 桥墩放置在 X=500, Y=200, Z=100（毫米），且组件属性面板中"偏移X/偏移Y/偏移Z"显示该坐标。
   - "沿X轴每隔10放5个圆柱" → 生成 5 个一排的圆柱。
   - 在 BIMBase 中选中一个组件后输入"复制选中的组件到(500,0,0)" → 生成副本。
   - 选中组件后输入"把半径改成300" → 组件参数更新。
   - 选中组件后输入"删除选中的组件" → 组件被删除。
   - "画一个半径50的圆" → 画板 2D 圆（回归验证：2D 指令不被建模路由截胡）。
3. 清空 API 配置后重试建模指令 → 无网络/无 Key 时建模指令仍可执行。
4. 离线路由逻辑可先用 `python 速构智维/test_ai_modeling_bridge.py` 做单元验证（无需 BIMBase）。

### 5b. 建模指令扩展能力测试（单位/不写入/上色）

- "在5m,4m,2m放一个半径50cm的圆柱" → 放置在 (5000,4000,2000)mm，半径 500mm。
- "在500,400,200的位置放置一个桥墩，不要写入位置参数" → 位置正确，属性面板不出现坐标参数。
- "放一个红色的圆柱" → 红色圆柱；"把选中的组件涂成半透明灰色" → 选中组件变为半透明灰。

### 5c. 同步基准坐标测试

1. 画板中绘制组件后点击"同步到BIMBase" → 弹出 X/Y/Z 基准坐标输入框（默认 0,0,0，毫米）。
2. 输入 (1000,0,0) 确认 → 画板内容整体以 (1000,0,0) 为基准放置到 BIMBase。
3. 点"取消" → 不同步。

### 5d. 面元素生成测试

1. 选中一个组件元素，点"生成面元素" → 弹出模式对话框，只含两个选项：
   - **智能**：生成 3 个标准投影面（俯视图/主视图/左视图）。
   - **全部面**：生成组件定义的所有面（正方体/长方体为 6 面；引桥桥墩/索缆锚锭模板仅定义 3 面，效果同智能）。
2. 左侧"识别三视图"下方不应再有"三视图"下拉框（已删除，原为未使用的冗余控件）。

### 6. 桥梁病害识别测试

1. 点击“桥梁病害识别”按钮。
2. 选择一张包含裂缝的测试图片。
3. 运行检测，验证是否框出病害。
4. 点击生成报告，验证 Word 文件是否正确导出。

### 7. 自动配置环境测试

1. 点击“自动配置环境”按钮。
2. 查看日志 `速构智维_env_setup.log`。
3. 验证依赖包是否安装成功。

## 注意事项

- 测试 AI 和病害识别功能前，确保 API Key 和模型权重已配置。
- 测试 DWG/PDF 导入时，建议使用简单文件，避免复杂对象解析失败。
- 如测试过程中崩溃，请查看根目录下的 `*_CRASH.txt` 文件。
