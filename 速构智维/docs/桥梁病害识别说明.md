# 速构智维 - 桥梁病害识别说明

## 重要变更

桥梁病害识别功能已从 速构智维 中**独立拆分**到 `桥梁病害识别/` 目录，与 `AI_Modeling/` 类似：

- **不单独注册 `.pyplugin`**
- **速构智维 面板按钮"桥梁病害识别"仍然保留**
- `速构智维/bridge_disease_launcher.py` 仅作为转发入口，实际逻辑在 `桥梁病害识别/bridge_disease_launcher.py` 中执行

## 入口

- 插件按钮：**桥梁病害识别** → `速构智维/bridge_disease_launcher.py`（转发） → `桥梁病害识别/bridge_disease_launcher.py` → `桥梁病害识别/disease_dialog.py`

## 为什么拆分

1. **职责清晰**：病害识别与 CAD 画板、AI 智能建模在功能上相对独立。
2. **便于维护**：独立模块可以单独迭代、测试、部署。
3. **复用方便**：其他插件或项目可以直接引用 `桥梁病害识别/` 下的模块。

## 依赖

- 本模块依赖 速构智维 提供的 `bimbase_sync.py`（BIMBase API 适配层）。
- 其他依赖：ultralytics、opencv-python、python-docx、PyQt5、pyp3d。
