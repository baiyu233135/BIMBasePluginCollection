# 隧道病害识别 — 使用说明

## 功能简介

在 BIMBase 插件中集成隧道病害智能识别功能，支持：
- 导入隧道巡检照片，自动识别异常区域
- 使用阿里云 Qwen-VL 多模态大模型进行 AI 智能诊断
- 将病害信息投影到 BIMBase 隧道模型对应构件上（衬砌、路面、洞门、检修道、排水）
- 生成带框照片和 AI 诊断结论的 Word 诊断报告

---

## 快速开始

### 1. 启动方式

在 BIMBase 插件面板中，点击 **隧道病害识别 → 隧道病害识别** 按钮。

### 2. 操作流程

```
导入照片 → 自动识别异常区域 → AI 智能诊断 → 获取选中构件 → 病害投影 → 生成报告
```

#### Step 1: 导入照片

点击 **"📷 导入隧道巡检照片"**，选择单张隧道巡检图片（支持 jpg/png/bmp/tiff）。

#### Step 2: 自动识别异常区域

点击 **"🔍 自动识别异常区域"**，系统优先调用**统一病害模型**（YOLO，模型文件为 `models/disease_yolov8n.pt`）在照片上圈出裂缝、渗水、剥落等异常区域；若模型尚未部署，则自动回退到传统 CV 算法兜底检测。两种途径的结果在界面上统一按 4 类显示（裂缝/渗水/剥落/其他），并自动添加到病害记录列表。

> 统一模型识别时，圈出的区域会直接按 4 类（裂缝红/渗水蓝/剥落橙/其他灰）着色并填入病害类型；CV 兜底时圈出的区域类型为占位标签「异常区域」（绿色框），具体病害类型由下一步 AI 诊断确定。

> **统一模型说明**：识别由统一病害模型（桥隧合并训练，7 类输出归并为界面 4 类：裂缝/渗水/剥落/其他）+ CV 兜底完成；模型未放入 `models/disease_yolov8n.pt` 时自动回退 CV 检测。

#### Step 3: 人工标注对照（可选）

导入照片前，在左侧「标注目录」中填写 YOLO 人工标注集目录（默认 `隧道病害识别/人工标好`，含 `images/` + `labels/` + `data.yaml`，目录存在即自动生效）。导入照片后，若标注集中存在同名标注，照片上会叠加显示**白色虚线「人工标注·类名」框**；自动识别或手动画框后，下方状态区实时统计对照结果（如 `人工标注 3 ｜ 识别一致 2 ✓ ｜ 漏检 1 ｜ 误检 0`），一致率按 ≥80% 绿 / ≥50% 黄 / <50% 红着色，选中表格记录时还会显示该条的「识别一致 / 误检」判定。

#### Step 4: 配置 AI Key（首次使用）

点击 **"🔑 配置 AI Key"**，在弹出的对话框中粘贴阿里云 DashScope API Key，点击保存即可写入 `tunnel_disease_config.json`。

> 获取方式：登录阿里云 → 开通 DashScope 灵积模型服务 → 创建 API Key。

#### Step 5: AI 智能诊断

点击 **"🧠 AI 智能诊断"**，系统将原图和带框图一起发送给阿里云 Qwen-VL 多模态大模型，对每个异常区域给出：

- 病害类型（裂缝、渗水、剥落、其他）
- 严重程度（轻微 / 中等 / 严重 / 极严重）
- 位置描述
- 尺寸估算
- 专业诊断建议

诊断完成后，照片上的框颜色会按病害类型更新：裂缝红、渗水蓝、剥落橙、其他灰。

> **注意**：使用 AI 诊断前，请先通过「🔑 配置 AI Key」填写 DashScope API Key。

#### Step 6: 获取当前选中构件

在 BIMBase 中选中一个隧道构件（衬砌、路面、洞门、检修道、排水），然后点击 **"🔍 获取当前选中组件"**。系统会读取构件类型和参数，自动切换「构件类型」下拉框，并按构件类型填充「投影面」下拉框（如衬砌→拱圈内壁/仰拱内壁，路面→顶面，洞门→正面，排水→沟底面等）。

> 基准坐标自动读取失败时，可从 BIMBase 属性面板手动抄录构件放置坐标，按 `x,y,z` 格式填入「基准坐标」输入框。

#### Step 7: 病害投影

点击 **"🎯 病害投影"**，将带检测框的病害记录等比映射到选中构件的指定投影面，以彩色点云标记放入 BIMBase 场景（每条记录一团彩色小点，颜色随病害类型）。

> 隧道组件轴线沿 **Y 方向**（洞口朝 ±Y），横断面在 XZ 面；投影面几何与该坐标系一致。
> 选择「衬砌→拱圈内壁 / 仰拱内壁」时，点云逐点贴合真实内弧面（沿内法线偏移 2mm），而非切平面近似。

也可以在右侧记录列表中选中一条记录，点击 **"📍 投影选中记录到BIMBase"** 放置病害标记。

#### Step 8: 生成诊断报告

点击 **"📄 生成诊断报告"**，输出 Word 文档，包含：
- 项目概况与病害统计
- 每处病害的带框照片
- 病害类型、位置、尺寸、AI 诊断结论
- 处理建议汇总

## 配置文件

### `tunnel_disease_config.json`

AI 诊断所需的阿里云 DashScope 配置：

```json
{
  "dashscope_api_key": "",
  "api_base": "https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions",
  "model": "qwen-vl-max",
  "temperature": 0.3,
  "max_tokens": 2000,
  "max_boxes": 10
}
```

- `dashscope_api_key`：必填，阿里云 DashScope API Key
- `model`：可选 `qwen-vl-max` 或 `qwen-vl-plus`
- `max_boxes`：单张图最多传入的异常区域数量

## 注意事项

1. **API Key**：首次使用 AI 诊断前，请务必配置 DashScope API Key，否则点击 AI 诊断会提示未配置。

2. **依赖安装**：如果缺少 `python-docx`、`Pillow` 或 `requests`，请手动安装：
   ```bash
   pip install python-docx pillow requests
   ```

3. **网络要求**：AI 智能诊断需要访问阿里云 DashScope 服务，请确保网络通畅。

4. **照片清晰度**：自动识别异常区域对照片清晰度、光照条件敏感，建议导入高分辨率、无明显反光的隧道巡检照片。

5. **AI 诊断结果**：AI 诊断结论仅供参考，最终病害判定应以现场专业检测为准。
