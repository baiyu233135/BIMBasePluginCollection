# 建模 - 测试文档

## 测试环境

- BIMBase V1.6.x
- Python 3.7 / 3.x
- openpyxl、pandas 已安装
- 测试用 Excel 文件

## 测试脚本

| 文件 | 用途 |
|---|---|
| `test.py` | 选择集测试 |
| `test_pick.py` | `pick_object` 测试 |
| `quxian00.py` | 早期路线生成版本，可用于对比 |

## 曲线建模测试

### 测试 1：直线段路线

1. 准备平面要素表：

| 桩号 | 类型 | 方位角 |
|---|---|---|
| 0 | Z | 0 |
| 100 | Z | 0 |

2. 准备竖直要素表：

| 桩号 | 高程 |
|---|---|
| 0 | 10 |
| 100 | 10 |

3. 运行 `quxian.py`，选择两个 Excel 文件。
4. 预期结果：生成一条从 (0,0,10) 到 (100,0,10) 的红色直线。

### 测试 2：圆曲线路线

1. 平面要素表包含一段圆曲线。
2. 运行 `quxian.py`。
3. 预期结果：生成平滑的曲线模型。

### 测试 3：数据持久化

1. 运行 `quxian.py` 生成路线。
2. 检查 `route_data.json` 是否生成并包含曲线点数据。
3. 选中路线组件，查看属性中是否包含 `plan_data_json` 和 `vert_data_json`。

## 圆柱建模测试

### 测试 1：沿路线生成圆柱

1. 先运行 `quxian.py` 生成路线。
2. 准备圆柱参数表：

| 桩号 | 横向偏移 | 纵向偏移 | 半径 | 桩顶标高 | 桩底标高 |
|---|---|---|---|---|---|
| 0 | 0 | 0 | 1 | 12 | 0 |
| 20 | 0 | 0 | 1 | 12 | 0 |

3. 运行 `yuanzhu.py`，选择“导入圆柱表并自动生成”。
4. 预期结果：在路线桩号 0 和 20 处各生成一个半径 1 的圆柱。

### 测试 2：从文件读取路线数据

1. 删除或隐藏场景中的路线组件。
2. 运行 `yuanzhu.py`，选择“从文件读取路线数据”。
3. 预期结果：从 `route_data.json` 读取路线并生成圆柱。

## 环境配置测试

1. 卸载 `openpyxl` 或 `pandas`。
2. 运行 `环境配置.py`。
3. 预期结果：脚本检测到缺失并自动安装。

## 注意事项

- Excel 表头必须与脚本中定义的列名一致。
- 生成圆柱前建议先生成路线，确保路线数据可用。
- 如果圆柱位置偏离路线，可检查 `route_data.json` 和圆柱参数表。
