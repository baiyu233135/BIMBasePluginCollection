# 建模 - 报错处理记录

## 1. Excel 读取失败

### 现象

运行 `quxian.py` 或 `yuanzhu.py` 时提示 Excel 读取错误。

### 原因

- 缺少 `openpyxl` 或 `pandas`。
- Excel 文件被占用。
- 表头与脚本预期不一致。

### 处理方法

1. 运行 `环境配置.py` 安装依赖。
2. 关闭 Excel 文件后重新运行脚本。
3. 对照脚本中的列名检查 Excel 表头。

## 2. 路线生成后没有显示

### 现象

`quxian.py` 运行成功，但 BIMBase 中没有路线模型。

### 原因

- `place()` 调用失败。
- 曲线点数据为空或参数错误。
- BIMBase 当前视图范围不合适。

### 处理方法

1. 检查 `route_data.json` 是否生成并包含数据。
2. 在脚本中添加打印，查看 `plan_data` 和 `vert_data` 是否正确解析。
3. 使用 `组件测试/正方体.py` 验证 BIMBase 放置功能是否正常。

## 3. 圆柱生成位置偏离路线

### 现象

圆柱没有沿路线布置，或高度不对。

### 原因

- 路线数据解析错误。
- 横向/纵向偏移计算错误。
- 桩顶/底标高未按路线高程叠加。

### 处理方法

1. 先验证 `quxian.py` 生成的路线是否正确。
2. 在 `yuanzhu.py` 中打印 `get_xyz(station)` 的中间结果。
3. 检查圆柱参数表中的偏移列名是否与脚本一致。

## 4. 圆柱建模找不到路线数据

### 现象

`yuanzhu.py` 提示找不到路线组件或 `route_data.json`。

### 原因

- 场景中确实没有路线组件。
- `route_data.json` 文件丢失或路径错误。
- 路线组件的属性名称不匹配。

### 处理方法

1. 先运行 `quxian.py` 生成路线。
2. 确认 `route_data.json` 存在于 `建模/` 目录。
3. 检查 `find_route_component_in_scene()` 中的属性名是否与 `quxian.py` 中写入的一致。

## 5. 环境配置无法安装依赖

### 现象

运行 `环境配置.py` 后仍提示缺少包。

### 原因

- pip 未安装。
- 网络问题。
- 使用了错误的 Python 解释器。

### 处理方法

1. 先运行 `setup_env.bat` 安装 pip。
2. 检查网络，必要时使用手机热点或配置国内镜像源。
3. 确认脚本调用的 Python 是 BIMBase 内置 Python。

## 6. quxian00.py 与 quxian.py 的区别

- `quxian00.py` 是早期版本，缺少数据持久化和属性接口。
- `quxian.py` 是 V4 完善版，推荐日常使用。
- 如果旧版脚本在新环境中报错，建议切换到 `quxian.py`。
