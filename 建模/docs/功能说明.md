# 建模 - 功能说明

## 功能概述

本模块通过读取 Excel 参数表格，自动生成三维空间曲线和沿路线批量布置的圆柱。适用于路线工程、桩基、桥墩等场景。

## 主要功能

### 1. 曲线建模（quxian.py）

读取平面要素表和竖直要素表，生成三维空间路线。

**输入数据**：

- 平面要素表：桩号、曲线类型（直线/圆曲线）、半径、转向角等。
- 竖直要素表：变坡点桩号、高程、竖曲线半径等。

**输出**：

- BIMBase 场景中的红色三维路线模型。
- 路线数据写入组件属性。
- 共享数据文件 `route_data.json`。

**核心类**：

- `CombinedRouteModel`：解析平面/竖直数据并生成三维曲线。
- 方法：
  - `_parse_plan_data()`：解析平面曲线。
  - `_parse_vert_data()`：解析竖曲线。
  - `_generate_3d_curve()`：按 0.5m 步长采样生成三维点。
  - `get_point_at_station(station)`：按桩号查询坐标。

### 2. 圆柱建模（yuanzhu.py）

读取圆柱参数表，沿路线自动批量生成圆柱。

**输入数据**：

- 圆柱参数表：桩号、横向偏移、纵向偏移、半径、桩顶/底标高等。
- 路线数据：优先从场景组件自动提取，失败则读取 `route_data.json`。

**输出**：

- BIMBase 场景中的圆柱群模型。

**核心类**：

- `RouteMathEngine`：复现路线解析逻辑。
- `CylindersAssembly`：组合所有圆柱并放置到场景。

### 3. 自动环境配置（环境配置.py）

检测并安装以下依赖：

- `openpyxl`
- `pandas`
- `pyp3d`

## 数据链路

```
quxian.py 生成路线
  ├── 组件属性保存路线数据
  └── route_data.json 保存共享数据

yuanzhu.py 生成圆柱
  ├── 优先读取场景组件属性
  └── 失败时回退到 route_data.json
```

## 入口

由根目录 `建模.pyplugin` 注册：

- **曲线建模** → `quxian.py`
- **圆柱建模** → `yuanzhu.py`
- **自动配置环境** → `环境配置.py`

## 依赖

- openpyxl
- pandas
- pyp3d
- PyQt5/PyQt6（UI 对话框）
