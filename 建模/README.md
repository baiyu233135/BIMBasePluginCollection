# 建模 - 曲线与圆柱参数化建模插件

本模块通过读取 Excel 参数表格，自动生成三维空间曲线和沿路线批量布置的圆柱，适用于路线工程、桩基、桥墩等场景。

## 功能特点

- **曲线建模**：读取平面要素表和竖直要素表，生成三维空间路线。
- **圆柱建模**：读取圆柱参数表，沿路线自动批量生成圆柱。
- **数据共享**：路线数据同时写入组件属性和 `route_data.json`，供圆柱插件读取。
- **自动环境配置**：检测并安装 `openpyxl`、`pandas` 等依赖。

## 入口

由根目录 `建模.pyplugin` 注册：

- **曲线建模** → `quxian.py`
- **圆柱建模** → `yuanzhu.py`
- **自动配置环境** → `环境配置.py`

## 使用流程

1. 准备 Excel 参数表：
   - 平面要素表：桩号、曲线类型（直线/圆曲线）、半径、转向角等。
   - 竖直要素表：变坡点桩号、高程、竖曲线半径等。
2. 运行“曲线建模”，选择 Excel 文件生成路线。
3. 准备圆柱参数表：桩号、横向偏移、纵向偏移、半径、桩顶/底标高等。
4. 运行“圆柱建模”，选择路线和圆柱表，自动生成圆柱。
