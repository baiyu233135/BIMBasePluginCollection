## 数据用途与合规提醒

1. 本目录资料来源于真实工程项目，**仅供本项目内部研发与测试使用**，请勿对外分发或用于其他商业用途；
2. 病害照片可用于模型训练/测试，但对外展示时注意隐去项目敏感信息；
3. 大体积资料（单文件接近或超过 100MB）不要直接提交 git——参考 `.gitignore` 中「大文件本地保留」段的既有做法：本地留存、忽略入库；
4. `隧道数据源/`（根目录）存放隧道定检报告，性质与本目录相同，同样注意体积与合规。
