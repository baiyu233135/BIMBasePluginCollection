# AI_Modeling 报错处理记录

## 1. `place_to` 或 `create_geometry` 返回无效实体

### 现象

执行创建指令后，BIMBase 中没有出现几何体，或返回的实体 ID 无效。

### 原因

- BIMBase 的模态对话框阻塞了交互上下文。
- 组件参数不正确，几何生成失败。
- `UnifiedFunction` 调用方式与当前 SDK 版本不兼容。

### 处理方法

`component_factory.py` 已实现多级兜底策略：

1. `create_geometry(translate(...) * comp)`
2. 直接调用底层 `UnifiedFunction`
3. 原生 `place_to(...)`
4. 烘焙坐标到组件内部偏移参数
5. 生成临时 IFC 导入
6. 模拟鼠标点击
7. 回退到手动 `place()`

如仍失败，可尝试：
- 关闭模态对话框，改用非模态窗口。
- 使用 `QTimer.singleShot` 延迟执行放置操作。
- 检查 BIMBase 版本与 SDK 接口是否匹配。

## 2. DeepSeek API 调用失败

### 现象

输入指令后长时间无响应，或返回“API 请求失败”。

### 原因

- `api_key` 无效或过期。
- 网络连接问题。
- 请求体格式错误。

### 处理方法

1. 检查 `ai_modeling_config.json` 中的 `api_key`。
2. 确认 `api_base` 为 `https://api.deepseek.com/chat/completions`。
3. 确认 `model` 为 `deepseek-chat`。
4. 查看 `ai_modeling.log` 中的 HTTP 返回码和错误信息。
5. 尝试切换网络环境。

## 3. 本地解析失败

### 现象

简单指令也无法本地解析，总是调用 AI。

### 原因

- 指令表述与解析器支持的句式不匹配。
- 数值或单位提取失败。

### 处理方法

- 参考 `command_parser.py` 中支持的句式，尽量使用标准表述：
  - “创建一个半径 5 高 10 的圆柱”
  - “把圆柱半径改为 8”
- 避免使用方言、缩写或模糊单位。

## 4. 语音输入无法识别

### 现象

点击语音按钮后，没有识别结果或识别错误。

### 原因

- 麦克风权限未开启。
- 百度语音 API Key 未配置。
- 录音环境嘈杂。

### 处理方法

1. 检查麦克风是否被其他应用占用。
2. 配置 `baidu_api_key` 和 `baidu_secret_key`。
3. 在安静环境下测试，说话清晰。

## 5. 窗口重复创建

### 现象

多次运行 `main.py` 后，出现多个 AI 对话框。

### 原因

`main.py` 中虽然做了 `QApplication` 单例判断，但窗口实例未做全局缓存。

### 处理方法

- 如需避免重复窗口，可在 `main.py` 中使用全局变量缓存窗口实例。
- 或每次运行前手动关闭旧窗口。
