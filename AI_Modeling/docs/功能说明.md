# AI_Modeling 功能说明

## 功能概述

`AI_Modeling` 是新版 AI 智能建模助手，目标是通过自然语言对话或本地解析，自动生成并放置参数化 BIM 构件。

## 核心流程

```
用户输入
  ├── 本地解析成功 → 直接执行创建/修改/删除/阵列/路线布置
  └── 本地解析失败 → 调用 DeepSeek API → 返回 JSON 指令 → 执行
```

## 支持的指令类型

### 1. 创建几何体

支持创建以下基础几何体：

- 圆柱（cylinder）
- 长方体（box）
- 正方体（cube）
- 球体（sphere）
- 圆锥（cone）

示例：

```text
在 (0,0,0) 创建一个半径 5 高 10 的圆柱
创建一个边长为 20 的正方体
```

### 2. 修改已有实体

支持选中实体后，通过自然语言修改其参数：

```text
把圆柱半径改为 8
将长方体高度设为 30
```

### 3. 删除实体

```text
删除选中的实体
```

### 4. 阵列

- 线性阵列：按 X/Y/Z 方向等距复制
- 矩形阵列：按两个方向等距复制
- 沿路线布置：根据桩号沿曲线放置多个组件

示例：

```text
沿 X 方向阵列 5 个，间距 10
沿路线每 5 米布置一个圆柱
```

### 5. 语音输入

点击语音按钮，使用麦克风输入中文指令，经百度语音识别后送入解析流程。

## 主要文件说明

| 文件 | 功能 |
|---|---|
| `main.py` | 独立运行入口，创建 QApplication 并显示主窗口 |
| `ai_modeling/ai_window.py` | 主对话框 UI，处理用户输入和消息展示 |
| `ai_modeling/command_parser.py` | 本地中文命令解析器 |
| `ai_modeling/component_factory.py` | 组件创建与多级放置策略 |
| `ai_modeling/bimbase_modifier.py` | 已有实体修改 |
| `ai_modeling/chat_thread.py` | DeepSeek 流式/非流式对话线程 |
| `ai_modeling/config.py` | 配置读写 |
| `bimbase_sync.py` | BIMBase 参数化组件类定义 |
| `ai_modeling/array_generator.py` | 阵列坐标生成 |
| `ai_modeling/route.py` | 路线等距采样 |
| `ai_modeling/geometry_exporter.py` | OBJ/IFC 导出 |
| `ai_modeling/voice_input.py` | 语音输入 |

## 依赖

- PyQt5 或 PyQt6
- pyp3d
- requests
- numpy
- 百度语音 API（可选）
