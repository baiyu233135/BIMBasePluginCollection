# AI_Modeling 功能说明

## 功能概述

`AI_Modeling` 是新版 AI 智能建模助手，目标是通过自然语言对话或本地解析，自动生成并放置参数化 BIM 构件。

## 核心流程

```
用户输入
  ├── 本地解析成功 → 直接执行创建/修改/删除/阵列/路线布置
  └── 本地解析失败 → 调用 DeepSeek API → 返回 JSON 指令 → 执行
```

## 支持的指令类型

### 1. 创建几何体

支持创建以下基础几何体：

- 圆柱（cylinder）
- 长方体（box）
- 正方体（cube）
- 球体（sphere）
- 圆锥（cone）

以及复杂参数化组件：

- 引桥桥墩（pier）
- 索缆锚锭 / 索塔锚块（anchor）

示例：

```text
在 (0,0,0) 创建一个半径 5 高 10 的圆柱
创建一个边长为 20 的正方体
生成一个引桥桥墩，盖梁总长 2000
生成索塔锚块，底柱半径 180
```

### 2. 基于选中组件的位置创建

在 BIMBase 中先选中一个组件，再通过自然语言在其位置或相对偏移位置生成新组件：

```text
在选中的圆柱位置生成半径 200 的正方体
在选中实体上方 500mm 生成一个圆柱，半径 100 高 200
在选中实体左侧 1000mm 生成长方体，长 300 宽 200 高 100
```

### 3. 复制组件

复制选中的组件到指定坐标或相对偏移位置：

```text
复制选中的圆柱到 (1000,2000,0)
复制选中的桥墩到当前位置上方 1000mm
```

### 4. 修改已有实体

支持选中实体后，通过自然语言修改其参数：

```text
把圆柱半径改为 8
将长方体高度设为 30
```

如需在修改参数的同时保留原位置，可加上“位置不变”等关键词：

```text
把选中圆柱半径改成 400，位置不变
将桥墩高度设为 1500，不要移动
```

### 5. 删除实体

```text
删除选中的实体
```

### 6. 阵列与沿路线布置

- 线性阵列：按 X/Y/Z 方向等距复制
- 矩形阵列：按两个方向等距复制
- 沿直线布置：按起点/终点、轴长或选中直线组件等距放置，组件自动与直线切线方向对齐
- 沿曲线（圆弧）布置：按圆心/半径/起止角或选中曲线组件等距放置，组件自动与圆弧切线方向对齐

示例：

```text
沿 X 方向阵列 5 个，间距 10
从(0,0,0)到(5000,0,0)每隔1000mm放半径50高100的圆柱
沿圆心(0,0,0)半径500从0°到180°的圆弧每隔200mm放圆柱
沿选中的曲线每隔200mm放圆柱，共5个
沿选中的直线每隔500mm放圆柱，共10个
```

### 7. 缓存清理

点击 AI 智能建模助手面板顶部的 **🧹 清理缓存** 按钮，可清空组件注册表和日志文件。已生成的 BIMBase 几何体不会被删除。

### 8. 语音输入

点击语音按钮，使用麦克风输入中文指令，经百度语音识别后送入解析流程。

## 主要文件说明

| 文件 | 功能 |
|---|---|
| `main.py` | 独立运行入口，创建 QApplication 并显示主窗口 |
| `ai_modeling/ai_window.py` | 主对话框 UI，处理用户输入和消息展示 |
| `ai_modeling/command_parser.py` | 本地中文命令解析器 |
| `ai_modeling/component_factory.py` | 组件创建与多级放置策略 |
| `ai_modeling/bimbase_modifier.py` | 已有实体修改、位置读取 |
| `ai_modeling/component_registry.py` | 组件注册表（位置/参数持久化） |
| `ai_modeling/chat_thread.py` | DeepSeek 流式/非流式对话线程 |
| `ai_modeling/config.py` | 配置读写 |
| `bimbase_sync.py` | BIMBase 参数化组件类定义 |
| `ai_modeling/array_generator.py` | 阵列坐标生成 |
| `ai_modeling/route.py` | 路线等距采样 |
| `ai_modeling/geometry_exporter.py` | OBJ/IFC 导出 |
| `ai_modeling/voice_input.py` | 语音输入 |

## 依赖

- PyQt5 或 PyQt6
- pyp3d
- requests
- numpy
- 百度语音 API（可选）
