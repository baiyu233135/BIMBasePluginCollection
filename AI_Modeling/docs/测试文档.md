# AI_Modeling 测试文档

## 测试环境

- BIMBase V1.6.x
- Python 3.7 / 3.x
- PyQt5/PyQt6 已安装
- DeepSeek API Key 已配置（如需测试 AI 对话）

## 测试脚本

### 1. 独立运行测试

```bash
python AI_Modeling/main.py
```

预期结果：弹出 AI 建模助手对话框，包含输入框、发送按钮、语音按钮、配置按钮。

### 2. 本地解析测试

在输入框中输入：

```text
创建一个半径 5 高 10 的圆柱
```

预期结果：
- 聊天窗口显示解析结果。
- 如果当前在 BIMBase 环境中，应能在场景中创建一个圆柱。

### 3. DeepSeek 对话测试

在输入框中输入一个较复杂的指令：

```text
在 (10,0,0) 创建 3 个半径为 2 的球体，沿 X 方向间距 5
```

预期结果：
- 如果本地解析失败，会调用 DeepSeek API。
- 返回 JSON 指令并执行，创建 3 个球体。

### 4. 实体修改测试

1. 在 BIMBase 中选中一个已创建的实体。
2. 在 AI 对话框输入：

```text
把半径改为 8
```

预期结果：选中实体的半径更新为 8。

### 5. 阵列测试

```text
创建一个长方体，长 10 宽 5 高 3，然后沿 Y 方向阵列 4 个，间距 6
```

预期结果：生成 4 个等距排列的长方体。

### 6. 语音输入测试

1. 确保麦克风可用。
2. 点击语音按钮，说出“创建一个半径 3 的球体”。
3. 等待识别结果并执行。

### 7. 沿直线/曲线布置测试

#### 沿直线（坐标输入）

```text
从(0,0,0)到(5000,0,0)每隔1000mm放半径50高100的圆柱
```

预期结果：沿 X 轴生成 6 个圆柱，每个圆柱的轴线与 X 轴平行。

#### 沿直线（选中直线组件）

1. 先用 `组件测试/直线.py` 在场景中创建一条直线。
2. 选中该直线，输入：

```text
沿选中的直线每隔500mm放圆柱，共10个
```

预期结果：沿该直线等距生成 10 个圆柱，圆柱轴线与直线方向一致。

#### 沿曲线（参数输入）

```text
沿圆心(0,0,0)半径500从0°到180°的圆弧每隔200mm放圆柱
```

预期结果：在 XY 平面半圆上生成若干圆柱，圆柱轴线与圆弧切线方向一致。

#### 沿曲线（选中曲线组件）

1. 先用 `组件测试/曲线.py` 在场景中创建一条圆弧。
2. 选中该曲线，输入：

```text
沿选中的曲线每隔200mm放圆柱，共5个
```

预期结果：沿该圆弧等距生成 5 个圆柱，圆柱轴线与圆弧切线方向一致。

### 8. place_to 底层测试

```bash
python AI_Modeling/test_place_to.py
```

预期结果：在 BIMBase 命令行中测试 `place_to` 和 `replace_noumenon` 接口。

## 测试注意事项

- 首次测试建议先使用简单的本地解析指令，无需配置 API Key。
- 测试 AI 对话前，确保 `ai_modeling_config.json` 中的 `api_key` 有效。
- 如果几何体无法自动放置，可查看 `ai_modeling.log` 中的兜底策略执行记录。
