# 组件成品 —— 铁路封闭网

已「定稿」的成品组件插件（`组件成品.pyplugin`，v1.0.0，SDK 1.6.2）。目前包含一个组件：**铁路封闭网**（铁路沿线参数化护栏网），提供优化版与原版两个按钮作性能对比。

| 面板按钮 | 文件 | 说明 |
|---|---|---|
| 铁路封闭网 | `铁路封闭网.py` | Cone 优化版 + 放置坐标自动回写（日常使用这个） |
| 铁路封闭网_原版 | `铁路封闭网_原版.py` | 32 边形 Section+Loft 原版，性能对比基线 |

## 关键技术栈

- **BIMBase Plugin SDK 1.6.2** + **pyp3d**：`Component/Attr/Cone/Section/Loft/Combine/translate/TwoPointPlace.linearize/place`
- **Pillow**：面板图标生成（`Picture/_generate_icons.py`，绿=优化版，橙=原版）
- 无外部 API、无配置文件；诊断日志 `坐标写入_debug.log` 运行时生成（多路径兜底写入）

## 核心机制（技术说明）

### 1. 两点拉伸布置

入口 `__main__` 用 `TwoPointPlace.linearize(FinalGeometry, '网长')`（`铁路封闭网.py:186-189`）：在视图中点两个点，封闭网自动按两点距离拉伸「网长」并沿线排布立柱与网片。末块网逻辑：剩余长度 ≤200 时并入最后一块整网，避免出现一小段零碎网片。

> 通俗说：像 CAD 里画线一样点起点和终点，护栏网自动「铺满」这条线，最后一点零头自动并到最后一跨。

### 2. Cone 优化（性能亮点）

线杆/长杆的截面从 32 边形 `Section + Loft` 改为 pyp3d 原生 `Cone`（真圆弧截面）。几何、参数、外观完全不变，但每根杆不再封送截面多边形数据、图形节点组装开销大幅降低，缓解了长距离封闭网的卡顿。原版保留作对照基准。

> 通俗说：原来每根杆子都要"手画 32 边形再拉伸"，现在直接告诉内核"来根圆杆"，画得快、模型也轻。

### 3. 放置坐标自动回写（技术亮点，本项目攻克的硬骨头）

需求：组件放到场景后，参数面板应显示它的 X/Y/Z 放置坐标。难点在于：

- 组件的 `replace()` 由 **pyp3d 内核 service 进程**执行，工具取点 API 在其中恒返回 `(0,0,0)`——在 replace 里问"我在哪"永远得不到答案；
- 直接写 noumenon 参数会被冲掉；`replace_noumenon` 整体替换会**硬崩溃**（已禁用）。

最终方案（`铁路封闭网.py:145-183` `_write_place_coords()`）：从 `self.transformation._mat`（3×4 行主序矩阵，平移量在 `[i][3]`）提取放置平移，写入 X/Y/Z 坐标参数；放置瞬间平移为零则跳过，**下次重生成**（改参数/重开工程）时自动写入。

> 通俗说：组件自己不知道被放在哪，但它的「变身记录」（变换矩阵）里记着——每次重新生成时顺手把坐标抄进参数表。

完整探索过程（5 次方案迭代、两条失败路线、官方放置工具速查）见根目录 `docs/05_pyp3d交互放置工具与坐标回写.md`。

## 使用说明

1. BIMBase 功能区「组件成品」面板 → 点「铁路封闭网」；
2. 在视图中点两个点 → 封闭网按两点距离自动拉伸排布；
3. 属性面板改任意参数（网高、立柱间距等）→ 触发重生成，X/Y/Z 坐标参数自动显示放置基准点坐标；
4. 对比测试：同距离分别用「铁路封闭网」与「铁路封闭网_原版」布置长距离网，可直观感受 Cone 优化前后的流畅度差异。

## 测试与调试

- 无独立测试脚本；验证方式即上述使用流程 + 与原版对比；
- 排查看 `坐标写入_debug.log`（运行时生成；因 BIMBase 编译缓存使 `__file__` 指向 BFATemp 副本，日志写入采用多路径兜底）；
- 常见问题同全项目高频坑：改代码后需完全重启 BIMBase；`replace_noumenon` 禁用；pyp3d Attr 只存标量/字符串。
