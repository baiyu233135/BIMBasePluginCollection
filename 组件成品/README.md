# 组件成品 —— 成品参数化组件库

已「定稿」的成品组件插件（`组件成品.pyplugin`，v1.0.0，SDK 1.6.2）。目前包含 6 个按钮、4 类组件：

| 面板按钮 | 文件 | 说明 |
|---|---|---|
| 铁路封闭网 | `铁路封闭网.py` | Cone 优化版 + 放置坐标自动回写（日常使用） |
| 铁路封闭网(原版) | `铁路封闭网_原版.py` | 32 边形 Section+Loft 原版，性能对比基线 |
| 铁路封闭网(1) | `铁路封闭网（1）.py` | **Array 实例化版**（长网不卡）+ 中间立柱排布 |
| 被插板 | `被插板.py` | 带凹槽的板（凹插板），排数/间距可调 |
| 凸插板 | `凸插板.py` | 带凸起的板（突插板），与被插板咬合 |
| 隧道 | `隧道.py` | 隧道二次衬砌+边墙+路面，深黑本体+三条白色设备带 |

## 关键技术栈

- **BIMBase Plugin SDK 1.6.2** + **pyp3d**：`Component/Attr/Cone/Section/Loft/Sweep/Combine/Array/linspace/translate/TwoPointPlace.linearize/place`
- **Pillow**：面板图标生成（`Picture/_generate_icons.py`）
- 无外部 API、无配置文件；诊断日志 `坐标写入_debug.log` 运行时生成（多路径兜底写入）

## 核心机制（技术说明）

### 1. 两点拉伸布置

入口 `__main__` 用 `TwoPointPlace.linearize(FinalGeometry, '网长')`：视图中点两个点，组件自动按两点距离拉伸并沿线排布。末块网逻辑：剩余长度 ≤200 时并入最后一块整网，避免零碎网片。

> 通俗说：像 CAD 里画线一样点起点和终点，护栏网自动「铺满」这条线，最后一点零头自动并到最后一跨。

### 2. 性能优化两代方案（重点）

**第一代（铁路封闭网.py，Cone 优化）**：线杆截面从 32 边形 `Section+Loft` 改为原生 `Cone`，减少每根杆的截面数据封送与图形节点组装开销。

**第二代（铁路封闭网（1）.py，Array 实例化）**：所有重复几何（网片横竖杆、整排网片、顶部网格杆、中间立柱）改用 `Array + linspace` 实例化排布——基准几何只建一份，重复部分只存变换矩阵。参考 BIMBase 内置围栏（`BFAComponentLib/.../安全围栏样式一两点布置.py`）的同款做法。100m 长网图元量从约 2500 降到约 10 个基准几何 + 阵列定义，两点布置不再卡顿。

> 通俗说：原来 2500 根杆每根都"画"一遍，现在只画一根，剩下 2499 根告诉内核"复制粘贴到这些位置"。

⚠️ **Array 上色坑**：`Array` 的 `parts` 存的是变换矩阵，`Combine(...).color()` 递归染色染不到壳里的基准几何——**必须在创建基准几何时就 `.color()`，再进 Array**（与 docs/04「先上色后 Combine」同一条规则的延伸）。

### 3. 中间立柱排布（铁路封闭网（1））

- 参数「立柱间隔块数」（字符串型，默认 `3`）：每隔 N 块网一根中间立柱；`0` = 只要首尾两根；
- 中间柱**双面耳板**（两侧都接网），位置必须落在**网片交界处**（`2k + N×块宽`，网片从 2k 处起排）——否则会骑在网片中间、网格杆穿柱身；
- 交界柱与端柱之间至少留一块网的距离，太近的自动跳过，避免末尾两根柱挤在一起。

### 4. 被插板 / 凸插板（咬合板对）

- **被插板（凹插板）**：板上开凹槽阵列。参数：凹槽长/宽/深度/间隔/凹槽排数/排列间距（中心距，0=所有排重叠到板中心）；多排沿宽度均布居中；开口超界时按比例整体缩放防撑破（宽度向 ≤ 排距/板宽，长度向 ≤ 间隔），**深度不随排列参数变化**（仅超过板厚时钳到板厚通槽）。
- **凸插板（突插板）**：板底单排凸起。凸起顶面始终贴合板底（放置基准 `-凸起高度`，修复了早期按 `-板高` 导致的悬空问题）。
- 排数类参数用**字符串型** Attr（避免面板显示 mm 后缀），内部容错解析；长度类用数字型（带 mm 单位）。

### 5. 隧道

二次衬砌拱圈 + 仰拱 + 双侧边墙（检修道块）+ 路面 + 三条白色设备带。配色：本体 `color(0,0,0,1)` 深黑（参考桥梁组件库路面及交通标线的写法），三条设备带 `color(1,1,1,1)` 白色。侧墩与衬砌边弧的重叠按用户决定**保留不处理**（曾验证过"按衬砌内弧圆反推侧墩外缘"的方案，可回退启用）。

### 6. 放置坐标自动回写（铁路封闭网）

需求：组件放到场景后，参数面板显示它的 X/Y/Z 放置坐标。难点：`replace()` 由内核 service 进程执行，取点 API 恒返回 `(0,0,0)`。

最终方案（`铁路封闭网.py` `_write_place_coords()`）：从 `self.transformation._mat`（3×4 行主序矩阵，平移量在 `[i][3]`）提取放置平移写入 X/Y/Z 坐标参数；放置瞬间平移为零则跳过，**下次重生成**时自动写入。完整探索过程见根目录 `docs/05_pyp3d交互放置工具与坐标回写.md`。

## 使用说明

- **铁路封闭网系列**：面板点按钮 → 视图两点拉伸布置 → 属性面板改参数实时重生成；「铁路封闭网（1)」适合长距离布置（不卡）；
- **被插板/凸插板**：点按钮 → 视图点击放置 → 属性面板调凹槽/凸起参数；两板默认参数下凹槽与凸起位置对齐（同一套排布算法）；
- **隧道**：点按钮 → 视图点击放置（默认 50m 长、10m 净宽，放置后记得缩放全图找模型）。

## 测试与调试

- 无独立测试脚本；验证方式即上述使用流程 + 封闭网新旧版对比；
- 排查看 `坐标写入_debug.log`（运行时生成）；
- 常见问题同全项目高频坑：改代码后需完全重启 BIMBase；`replace_noumenon` 禁用；pyp3d Attr 只存标量/字符串；**多几何体并用 `Combine()` 不是 `+`**；Array 要先上色再阵列。
