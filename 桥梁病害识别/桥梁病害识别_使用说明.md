# 桥梁病害识别 — 使用说明

## 功能简介

在 BIMBase 插件中集成桥隧病害智能识别功能，支持：
- 导入无人机巡检照片，自动识别异常区域
- 使用阿里云 Qwen-VL 多模态大模型进行 AI 智能诊断
- 将病害信息投影到 BIMBase 桥梁模型对应构件上
- 生成带框照片和 AI 诊断结论的 Word 诊断报告

---

## 快速开始

### 1. 启动方式

在 BIMBase 插件面板中，点击 **速构智维 → 桥梁病害识别** 按钮。

### 2. 操作流程

```
导入照片 → 自动识别异常区域 → AI 智能诊断 → 获取选中构件 → 病害投影 → 生成报告
```

#### Step 1: 导入照片

点击 **"📷 导入无人机照片"**，选择单张无人机巡检图片（支持 jpg/png/bmp/tiff）。

#### Step 2: 自动识别异常区域

点击 **"🔍 自动识别异常区域"**，系统使用传统 CV 算法在照片上圈出可能的裂缝、剥落、渗水等异常区域，并自动添加到病害记录列表。

#### Step 3: 配置 AI Key（首次使用）

点击 **"🔑 配置 AI Key"**，在弹出的对话框中粘贴阿里云 DashScope API Key，点击保存即可写入 `disease_config.json`。

> 获取方式：登录阿里云 → 开通 DashScope 灵积模型服务 → 创建 API Key。

#### Step 4: AI 智能诊断

点击 **"🧠 AI 智能诊断"**，系统将原图和带框图一起发送给阿里云 Qwen-VL 多模态大模型，对每个红框区域给出：

- 病害类型（裂缝、剥落、露筋、蜂窝麻面、渗水、锈蚀等）
- 严重程度（轻微 / 中等 / 严重 / 极严重）
- 位置描述
- 尺寸估算
- 专业诊断建议

> **注意**：使用 AI 诊断前，请先填写 `桥梁病害识别/disease_config.json` 中的 `dashscope_api_key`。

#### Step 5: 获取当前选中构件

在 BIMBase 中选中一个桥梁构件，然后点击 **"🔍 获取当前选中组件"**。系统会读取构件类型和参数，并自动匹配到病害记录中。

#### Step 6: 病害投影

点击 **"🎯 病害投影"**，根据构件形态给出推荐的投影方式：
- **直线/平面型构件**（T梁、箱梁、护栏等）：推荐纹理贴图
- **曲线/复杂构件**（圆柱、主塔、墩台等）：推荐点云投影

> 当前版本统一投影入口已实现，具体纹理/点云自动投影逻辑将在后续迭代中完善。
> 现在可点击右侧面板 **"📍 投影选中记录到BIMBase"** 放置红色病害标记。

#### Step 7: 生成诊断报告

点击 **"📄 生成诊断报告"**，输出 Word 文档，包含：
- 项目概况与病害统计
- 每处病害的带框照片
- 病害类型、位置、尺寸、AI 诊断结论
- 处理建议汇总

## 配置文件

### `disease_config.json`

AI 诊断所需的阿里云 DashScope 配置：

```json
{
  "dashscope_api_key": "",
  "api_base": "https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions",
  "model": "qwen-vl-max",
  "temperature": 0.3,
  "max_tokens": 2000,
  "max_boxes": 10
}
```

- `dashscope_api_key`：必填，阿里云 DashScope API Key
- `model`：可选 `qwen-vl-max` 或 `qwen-vl-plus`
- `max_boxes`：单张图最多传入的异常区域数量

## 注意事项

1. **API Key**：首次使用 AI 诊断前，请务必在 `disease_config.json` 中填写 `dashscope_api_key`，否则点击 AI 诊断会提示未配置。

2. **依赖安装**：如果缺少 `python-docx`、`Pillow` 或 `requests`，请手动安装：
   ```bash
   pip install python-docx pillow requests
   ```

3. **网络要求**：AI 智能诊断需要访问阿里云 DashScope 服务，请确保网络通畅。

4. **照片清晰度**：自动识别异常区域对照片清晰度、光照条件敏感，建议导入高分辨率、无明显反光的巡检照片。

5. **AI 诊断结果**：AI 诊断结论仅供参考，最终病害判定应以现场专业检测为准。
