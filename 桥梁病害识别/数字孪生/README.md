# 常泰长江大桥数字孪生平台

常泰长江大桥的网页端数字孪生展示平台：真实尺度三维重建 + 病害三维贴片可视化。**单文件离线网页，浏览器双击即开，无需安装任何软件、无需联网**；也可部署到公网网址在线访问。

## 主要功能

- **真实尺度三维重建**：主航道桥 (142+490+1176+490+142) m = 2440 m，空间钻石型主塔总高 352 m（放样数据与组件库 `主塔.py` 一致），双层钢桁梁（宽 39 m / 高 16 m），门式桥墩、承台桩基、斜拉索、护栏、轨道、接触网等 15+ 组构件
- **构件显隐**：左侧按上部结构 / 下部结构 / 附属设施分组复选框控制
- **病害三维贴片**：导入 JSON 后按构件关键词自动路由（塔 / 墩 / 承台 / 索 / 上下层桥面），点击贴片弹出详情卡（类型 / 程度 / 位置 / 尺寸 / AI 诊断），双击任意位置移动旋转中心
- **工程概况卡**：全长、跨径布置、桥型、塔高等真实数据
- **里程定位**：病害按 `stake_m` 字段或照片文件名桩号（`K12+345` 格式）沿桥排布

## 使用方法

1. 双击打开 `常泰长江大桥数字孪生.html`
2. 左侧面板：勾选/取消构件分组；"载入示例数据"查看病害贴片效果
3. 导入真实数据：点"导入 JSON"，选择「桥梁病害识别」插件"🌐 导出网页数据"按钮产出的 JSON 文件
4. 调试入口：URL 加 `#demo` 自动载入示例数据，`#demo-close` 单塔近景，`#demo-diamond` 钻石段特写

修改 `template.html` 后运行 `python build.py` 重新打包生成单文件。

## 数据格式（与插件导出对接）

顶层 `{ "bridge_name": ..., "records": [...] }`，每条记录字段：

| 字段 | 说明 |
| --- | --- |
| `disease` / `severity` | 病害类型（六类+已修复）/ 程度 |
| `component` | 构件名称，按关键词路由贴片面（含"塔"→塔柱、"墩"→墩身、"承台"→承台顶、"索"→斜拉索中段、"轨/下层"→下层桥面，默认→上层桥面） |
| `stake_m` | 沿桥里程（米，跨中为 0，范围 -1220 ~ +1220）；缺省时从 `photo_name` 解析桩号 |
| `photo_name` | 照片文件名，支持 `K12+345` / `ZK12+345.6` 形式桩号（锚点公式：**X = 桩号米 − 12220**，跨中 K12+220 ↔ X=0） |
| `height_m` | 病害中心高程（米），塔/墩竖直贴片用；缺省时塔默认 80 m、墩默认 20 m |
| `bbox` / `photo_w` / `photo_h` | 检测框像素坐标与照片尺寸，贴片大小按"照片覆盖"滑块换算 |
| `position` / `size` / `note` / `ai_diagnosis` / `time` | 详情卡展示字段 |

> **照片命名规范**：`桥名_K12+345_说明.jpg`。命名不带桩号的记录会沿桥均匀排布（不精确）。

## 注意事项

- 塔 / 墩 / 索竖直贴片默认朝 +Y 面，从另一侧看为半透明背面（DoubleSide，正常现象）
- 部署到公网：直接把这个单文件上传到服务器 / 对象存储即可，无任何后端依赖
- 模型几何为示意性重建，用于病害可视化展示，不作为工程设计依据
