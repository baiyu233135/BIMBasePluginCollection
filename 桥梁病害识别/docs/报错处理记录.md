# 桥梁病害识别 - 报错处理记录

## 1. 对话框无法启动

### 现象

点击"桥梁病害识别"按钮后没有反应，或报错后闪退。

### 原因

- 速构智维 转发脚本未找到 `桥梁病害识别/bridge_disease_launcher.py`。
- Qt 平台插件路径未正确设置。
- `disease_dialog.py` 中 import 路径错误。

### 处理方法

1. 确认 `桥梁病害识别/bridge_disease_launcher.py` 存在。
2. 查看 `桥梁病害识别/bridge_disease_debug.log` 日志。
3. 检查 速构智维/bridge_disease_launcher.py 中的转发路径是否正确。

## 2. 检测不到病害

### 现象

选择图片后运行检测，没有框出任何病害。

### 原因

- 图片质量问题。
- 模型权重 `yolov8n.pt` 不存在或路径错误。
- 置信度阈值过高。

### 处理方法

1. 使用清晰度更高的照片。
2. 确认 `models/yolov8n.pt` 存在。
3. 在 `disease_detector.py` 中降低置信度阈值。

## 3. 异常区域识别框太多或太少

### 现象

点击"自动识别异常区域"后，检测框过多（把正常纹理也框进去）或过少（漏掉明显裂缝/水渍）。

### 原因

- `cv_anomaly_detector.py` 默认参数针对常见 T 梁照片调优，但不同照片的光照、对比度差异较大。
- 最小面积 `min_area`、黑帽变换核大小、自适应阈值参数不适合当前照片。

### 处理方法

1. 在 `cv_anomaly_detector.py` 中调整以下默认参数：
   - `DEFAULT_MIN_AREA`：控制最小检测区域面积，过小会引入噪声，过大容易漏检。
   - `DEFAULT_BLACKHAT_KERNEL`：控制对细长裂缝的敏感度，越大对宽裂缝越敏感。
   - `DEFAULT_ADAPTIVE_BLOCK_SIZES` / `DEFAULT_ADAPTIVE_C_VALUES`：控制大面积暗区（渗水、污渍）检测。
2. 优先使用光线均匀、病害特征清晰的照片。
3. 如需更高精度，建议准备数据集训练专用 YOLO 病害检测模型。

## 4. 模型加载失败

### 现象

提示"模型文件不存在"或"加载模型失败"。

### 原因

- `DEFAULT_MODEL_PATH` 指向错误位置。
- ultralytics 未安装。

### 处理方法

1. 检查 `disease_detector.py` 中 `DEFAULT_MODEL_PATH` 是否指向 `models/disease_yolov8n.pt`。
2. 安装 ultralytics：`pip install ultralytics`。
3. 如没有专用模型，可训练或使用通用权重 `yolov8n.pt` 作为 fallback。

## 5. 报告生成失败

### 现象

点击"生成报告"后无响应或报错。

### 原因

- 缺少 `python-docx`。
- 图片路径包含特殊字符。
- 记录列表为空。

### 处理方法

1. 安装 `python-docx`：`pip install python-docx`。
2. 检查照片路径是否为有效路径。
3. 确保已添加至少一条病害记录。

## 6. BIMBase 投影失败

### 现象

点击"投影到BIMBase"后没有生成标记。

### 原因

- 未选中 BIMBase 构件。
- `bimbase_sync.py` 导入失败。
- `place()` 调用失败。

### 处理方法

1. 在 BIMBase 中选中要投影的构件。
2. 检查 `bimbase_query.py` 是否能正确导入 `bimbase_sync`。
3. 查看日志中的详细错误信息。

## 7. 拆分后 import 错误

### 现象

移动模块后出现 `ModuleNotFoundError: No module named 'utils.xxx'` 或 `dialogs.xxx`。

### 原因

- 文件已移动到 `桥梁病害识别/` 目录，但 import 路径未同步修改。

### 处理方法

1. 将所有 `from utils.xxx` 改为 `from xxx`。
2. 将 `from dialogs.disease_dialog` 改为 `from disease_dialog`。
3. 检查 `bimbase_query.py` 中是否正确添加了 `速构智维/` 到 `sys.path`。
