# 桥梁病害识别 - 测试文档

## 测试环境

- BIMBase V1.6.x
- Python 3.7 / 3.x
- PyQt5 已安装
- pyp3d 可用
- ultralytics、opencv-python、python-docx 已安装

## 功能测试

### 1. 入口转发测试

1. 在 BIMBase 中点击 速构智维 面板的"桥梁病害识别"按钮。
2. 预期结果：弹出"桥梁病害识别 — 手动录入"对话框。

### 2. T梁异常区域识别测试

1. 准备 T 梁照片（如 `数据参考源/桥隧数据源/T梁照片/00.png`、`01.png`）。
2. 在对话框中导入照片。
3. 点击"自动识别异常区域"。
4. 预期结果：
   - 照片上用红色框圈出异常区域。
   - 病害记录列表自动添加 `异常区域` 类型记录。
   - 每条记录显示像素坐标、尺寸、置信度对应的严重程度。
5. 可多次导入不同 T 梁照片重复测试，验证检测框数量是否合理。

### 3. 病害检测测试（YOLO 模式）

1. 准备一张包含裂缝的桥梁/隧道照片。
2. 在对话框中导入照片。
3. 选择模型权重 `models/disease_yolov8n.pt`（需自行训练）。
4. 点击"开始检测"。
5. 预期结果：照片上用框标出病害位置，列表显示病害类型和置信度。

### 4. CV Fallback 测试

1. 临时移除或重命名 `models/yolov8n.pt`。
2. 导入照片并检测。
3. 预期结果：使用 OpenCV 方法检测裂缝（可能效果不如 YOLO）。

### 5. 报告生成测试

1. 完成病害检测或手动添加病害记录。
2. 点击"生成报告"。
3. 预期结果：生成 Word 文档，包含项目概况、病害统计、详细信息。

### 6. BIMBase 投影测试

1. 在 BIMBase 中选中一个桥梁构件。
2. 在对话框中点击"投影到BIMBase"。
3. 预期结果：在构件表面或附近生成红色病害标记。

### 7. 扫描调试

```bash
python 桥梁病害识别/scan_debug.py
```

预期结果：在 BIMBase 命令行中打印当前实例参数，用于排查构件识别问题。

### 8. 投影测试

```bash
python 桥梁病害识别/test_projection.py
```

预期结果：测试 pyp3d 标记组件能否放置到 BIMBase。

### 9. 数据集提取测试

```bash
python 桥梁病害识别/training/extract_dataset.py
```

预期结果：

- 从 `数据参考源/桥隧数据源/*.docx` 和 `*.docm` 中提取图片。
- 生成 `桥梁病害识别/datasets/bridge_disease/` 目录结构。
- `labels.json` 和 `labels.csv` 包含来源文档、构件类型、病害类型、题注上下文。

### 10. 投影测试组件验证

> 原 4 个投影测试组件（投影测试T梁/横隔板/湿接缝/墩柱）已于 2026-08-24 删除。
> 病害投影验证请改用真实构件（如 组件测试/门式桥墩.py），步骤相同：

1. 在 BIMBase 中运行组件脚本（或“组件测试”面板点击对应按钮）：

   ```python
   exec(open('组件测试/门式桥墩.py', encoding='utf-8').read())
   ```

2. 在属性面板中修改参数，观察几何是否正确更新。
3. 导入对应病害照片，识别后选中组件并点击“投影到BIMBase”。
4. 预期结果：病害阴影/纹理/点云落在组件对应面上。

## 注意事项

- 测试前确保 API Key 和模型权重已配置。
- 照片清晰度直接影响检测效果。
- 如果 YOLO 推理较慢，可尝试降低图片分辨率。
- `extract_dataset.py` 依赖 `zipfile` 和 `lxml`（Python 内置），无需安装额外包。
