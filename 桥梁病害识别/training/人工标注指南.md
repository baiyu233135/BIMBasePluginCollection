# 桥隧病害照片人工标注指南

本指南说明如何为桥隧病害照片做 YOLO 目标检测标注，用于训练 `disease_yolov8n.pt` 模型。

---

## 一、需要标注什么

YOLO 目标检测需要为**每张图片中的每个病害区域**标注：

1. **病害类别**：裂缝、剥落、露筋、蜂窝麻面、渗水、锈蚀
2. **边界框**：病害区域的最小外接矩形（x 中心、y 中心、宽、高）

示例：

```text
0 0.512 0.383 0.256 0.102
1 0.213 0.645 0.189 0.078
```

- 第一列是类别编号（0=裂缝，1=剥落，...）
- 后面 4 列是归一化到 0~1 的边界框坐标

---

## 二、推荐标注工具

### 方案 A：CVAT（推荐，网页版，功能强）

**适用**：100 张以上、多人协作、需要审核的标注。

**安装/使用**：
1. 浏览器访问 https://app.cvat.ai/
2. 注册账号，新建任务（Task）
3. 上传图片文件夹
4. 新建标签（Label）：裂缝、剥落、露筋、蜂窝麻面、渗水、锈蚀
5. 逐张用矩形框标注病害区域
6. 导出格式选择 **YOLO 1.1**

**优点**：网页版、免费、支持预标注（可先用我们的伪标签自动跑一遍，再人工修正）

### 方案 B：LabelImg（本地桌面，简单易用）

**适用**：几十到几百张，单人快速标注。

**安装**：
```bash
pip install labelimg
labelimg
```

**使用**：
1. 打开图片目录：`桥梁病害识别/datasets/bridge_disease_yolo/images/train/`
2. 设置保存格式为 **YOLO**
3. 标签列表加载 `classes.txt`
4. 逐张标注，自动保存到 `labels/train/`

### 方案 C：Roboflow（云端，含数据增强）

**适用**：需要云端存储、自动划分训练集/验证集。

**使用**：
1. 访问 https://roboflow.com/
2. 上传图片
3. 在线标注
4. 导出 YOLOv8 格式

## 三、标注规范

### 3.1 病害类别映射

| 类别名 | YOLO 编号 | 常见照片内容 |
|---|---|---|
| 裂缝 | 0 | 细长裂纹，颜色深 |
| 剥落 | 1 | 混凝土表面脱落、掉角、露骨料 |
| 露筋 | 2 | 钢筋外露 |
| 蜂窝麻面 | 3 | 表面蜂窝状小孔、麻面 |
| 渗水 | 4 | 水渍、泛白、泛碱痕迹 |
| 锈蚀 | 5 | 钢筋/钢结构锈迹 |

### 3.2 标注要点

1. **框要贴紧病害区域**，不要包含过多正常背景
2. **一张照片可能有多个病害**，每个病害单独一个框
3. **细小裂缝**可以只框住最明显的区段，不必追求全长
4. **无法确定类型**时，标为“异常区域”（当前训练类别不含此类，可跳过或单独存放）
5. **纯背景/无病害照片**不需要标注，但应放入 `background/` 目录作为负样本

### 3.3 命名规则

建议按“构件_序号”命名，例如：

```text
T梁_0001.jpg
横隔板_0002.jpg
湿接缝_0003.jpg
墩柱_0004.jpg
```

标签文件与图片同名：

```text
T梁_0001.txt
横隔板_0002.txt
```

## 五、从伪标签到人工标注的过渡

当前已有 CV 自动生成的伪标签（`datasets/bridge_disease_yolo/`）。建议按以下步骤过渡：

1. **抽样检查**：随机抽取 50-100 张伪标签图片，用 CVAT 打开查看框位置是否合理。
2. **人工修正**：对框位置不准、类别错误、漏检的，逐个修正。
3. **重新导出**：修正后导出为 YOLO 格式，替换原伪标签。
4. **补充负样本**：把纯背景照片放入 `background/` 目录（不需要标注）。
5. **重新训练**：用人工修正后的数据集重新训练。

这样比从零开始标注效率高很多。

## 六、标注工作量参考

| 照片数量 | 预计耗时（单人） | 建议 |
|---|---|---|
| 100 张 | 2-3 小时 | 最小可用集 |
| 300 张 | 6-8 小时 | 推荐试点 |
| 500 张 | 10-15 小时 | 较好效果 |
| 1000 张 | 20-30 小时 | 生产级 |

**建议先标注 300 张**，重新训练后评估 mAP 是否提升，再决定是否继续扩大。

## 七、常见问题

### Q1: 一张照片里有很多细小裂缝，都要标吗？

A: 不需要。标注最明显的 1-3 个代表性裂缝即可，YOLO 会学习泛化。

### Q2: 病害区域边缘模糊，框多大合适？

A: 以肉眼能分辨的病害范围为准，宁大勿小，但不要框进太多正常区域。

### Q3: 同一张照片有剥落和裂缝，要分开标吗？

A: 要。每个病害单独一个框，分别选择对应类别。

### Q4: 照片里没有病害，需要标注吗？

A: 不需要。把这类照片放入 `background/` 目录作为负样本，训练时 YOLO 会自动学习“无病害”的判别。

### Q5: 伪标签的框都很密集，怎么修正？

A: 在 CVAT 中可以先用“自动标注”或导入伪标签，然后人工删除多余框、合并重叠框、调整类别。
